# イオン伝導体の基礎と設計指針 (工事中)

## 1. イオン伝導体の基本概念

### 1.1 イオン伝導体とは

固体中のイオンは、有限温度では平衡位置を中心に熱振動しています。絶縁体の場合、イオンは熱振動するだけで平衡位置に留まります。一方、イオン伝導体の場合は、イオンが平衡位置から別の位置へ移動することができます。ただし、イオンが移動するためには欠陥が必要です。

![絶縁体とイオン伝導体の違い](/learning/ionics/l1-insulator-vs-conductor.webp "Na<sup>+</sup>Cl<sup>−</sup>結晶格子での比較です。絶縁体（左）ではイオンは平衡位置のまわりで熱振動するだけですが、イオン伝導体（右）ではイオンが空いたサイト（点線の円）へ移動できます。")

### 1.2 基本的な電気伝導の式

イオン伝導率は、次の基本式で表されます。

**σ = zecμ**

ここで、各記号の意味は次の通りです。
- σ：イオン伝導率 [S cm<sup>-1</sup>]
- z：電荷数
- e：電気素量
- c：欠陥（キャリア）濃度
- μ：移動度（mobility）

移動度については、Einsteinの関係式

**μ = zeD/kT**

が成り立つので、これを基本式に代入すると

**σ = (ze)²cD/kT**

が得られます。さらに、拡散係数の温度依存性は

**D = D₀ × exp(-E<sub>mig</sub>/kT)**

と書けるため、最終的にイオン伝導率は次のアレニウス則に従います。

**σ = σ₀/T × exp(-E<sub>a</sub>/kT)**

## 2. 欠陥の種類と特性

### 2.1 内因性欠陥（Intrinsic Defect）

内因性欠陥とは、有限温度において、自身で完結する（系外の物質とのやりとりがない）反応によって生成する欠陥です。

#### 2.1.1 Frenkel欠陥のメカニズム

Frenkel欠陥の基本反応では、まず①イオンが格子間位置に移動して空孔を生成します。続いて、②隣接するイオンがその空孔位置に移動するか、③格子間イオンが隣の格子間位置へ移動します。この②または③（もしくは両方）によってイオンが移動します。なお、アニオンのFrenkel欠陥はAnti-Frenkel欠陥とも呼ばれます。

![Frenkel欠陥の生成とイオン移動](/learning/ionics/l1-frenkel-defect.webp "左：イオンが格子間位置へ移動して空孔（点線の円）を生成します（①）。右：隣接イオンが空孔へ移動する（②）か、格子間イオンが隣の格子間位置へ移動する（③）ことでイオンが動きます。")

#### 2.1.2 Schottky欠陥のメカニズム

Schottky欠陥の基本反応では、①正負のイオン対の空孔が生成し、②隣接するイオンがその空孔位置に移動することでイオンが移動します。

![Schottky欠陥の生成とイオン移動](/learning/ionics/l1-schottky-defect.webp "左：正負のイオン対の空孔が生成します（①）。右：隣接イオンが空孔位置へ移動することでイオンが動きます（②）。")

### 2.2 内因性欠陥を利用したイオン伝導

#### 2.2.1 活性化エネルギーの内訳

イオン伝導に要するエネルギー（活性化エネルギー）は、次のように書けます。

**E<sub>a</sub> = (1/2)E<sub>f</sub> + E<sub>mig</sub>**

ここで、各記号の意味は次の通りです。
- E<sub>f</sub>：欠陥形成エネルギー（defect formation energy）
- E<sub>mig</sub>：移動エネルギー（migration energy）

すなわち、平衡位置と隣接する平衡位置の間にはE_migの障壁があり、さらに欠陥の形成にE_fのエネルギーが必要となります。なお、E_fの係数は欠陥様式によって異なると考えられます。

![欠陥形成エネルギーと移動エネルギー](/learning/ionics/l1-ef-emig-energy.webp "Frenkel欠陥を介したイオン伝導のエネルギー図です。平衡位置のイオンを格子間へ移すのにE<sub>f</sub>、隣接平衡位置へ移動するのにE<sub>mig</sub>の障壁を越える必要があります。")

#### 2.2.2 欠陥濃度の計算

欠陥濃度には、次の関係式が成り立ちます。

**C<sub>i</sub> × C_v = N × exp(-E<sub>f</sub>/kT)**

電気的中性条件から **C<sub>i</sub> = C_v** が成り立つため、

**C_v = √N × exp(-E<sub>f</sub>/2kT)**

となります。イオン伝導率を導出するには、基本式

**σ = zecμ**

にEinsteinの関係式

**μ = zeD/kT**

を代入して

**σ = (ze)²cD/kT**

とし、さらに拡散係数

**D = D₀ × exp(-E<sub>mig</sub>/kT)**

を用います。最終的に、

**σ = (ze)²C_vD₀/kT × exp(-(E<sub>f</sub>/2 + E<sub>mig</sub>)/kT)**

**σ = σ₀/T × exp(-E<sub>a</sub>/kT)** （アレニウス則）

が得られます。

#### 2.2.3 アレニウスプロットの解析

アレニウスプロットでは、縦軸に log(σT / S cm<sup>-1</sup>)、横軸に 1000 T<sup>-1</sup> / K<sup>-1</sup> をとります。高温領域では内因性欠陥濃度が優勢となり、欠陥濃度は c ≈ exp(-E<sub>f</sub>/kT)、伝導率は σ ≈ exp(-(E<sub>f</sub>/2 + E<sub>mig</sub>)/kT) となるため、プロットの傾きは E<sub>mig</sub> + E<sub>f</sub>/2 に対応します。一方、低温領域では外因性欠陥濃度が優勢となり、c ≈ const.（温度依存なし）、σ ≈ exp(-E<sub>mig</sub>/kT) となるため、傾きは E<sub>mig</sub> に対応します。

![内因性欠陥が支配的な場合のアレニウスプロット](/learning/ionics/l1-arrhenius-intrinsic.webp "高温側（左上、青線）では内因性欠陥の生成が効いて傾きがE<sub>mig</sub> + E<sub>f</sub>/2になり、低温側（右下、赤線）では濃度一定の微量な外因性欠陥が支配して傾きがE<sub>mig</sub>になります。")

重要な点として、完全結晶は実在せず、大抵は微量の外因性欠陥が含まれています。そのため低温側では、制御しきれない微量の外因性欠陥（濃度一定）によって、キャリア濃度とイオン伝導率が支配されます。

### 2.3 外因性欠陥（Extrinsic Defect）

#### 2.3.1 具体例：Mg<sup>2+</sup>O<sup>2-</sup>結晶格子

例1として、高価数元素による置換を考えます。

**Mg²⁺ + Mg²⁺ → □ + Zr⁴⁺**

Mg<sup>2+</sup>の一つをZr<sup>4+</sup>で置換すると、もう一つのMg<sup>2+</sup>を空孔にすることができ、**Mg空孔（vacancy）**が生成します。

例2は、低価数元素による置換です。

**Mg²⁺ + Mg²⁺ → Na⁺ + Na⁺ + Mg²⁺_int**

2個のMg<sup>2+</sup>をNa<sup>+</sup>で置換すると、Mg<sup>2+</sup>を1個格子間に導入することができ、**格子間Mg（interstitial）**が生成します。

![MgO結晶格子への異価数元素置換](/learning/ionics/l1-mgo-extrinsic-defects.webp "左：Mg<sup>2+</sup>をZr<sup>4+</sup>で置換すると、もう一つのMg<sup>2+</sup>が空孔になります。右：2個のMg<sup>2+</sup>をNa<sup>+</sup>で置換すると、Mg<sup>2+</sup>が1個格子間に入ります。どちらも近接サイトで電荷が補償されている点に注目してください。")

#### 2.3.2 電気的中性条件（Electric Neutrality）

Paulingの第二法則（Pauling's second law）にあるように、局所的な電気的中性を満たす形で、大抵は近接サイトで電荷が補償されます。

### 2.4 外因性欠陥を利用したイオン伝導

#### 2.4.1 基本特性

外因性欠陥の場合、格子欠陥濃度cは異価数元素の置換濃度で規定され、温度によらず一定です。基本式

**σ = zecμ**

にEinsteinの関係式

**μ = zeD/kT**

を代入すると

**σ = (ze)²cD/kT**

となり、拡散係数

**D = D₀ × exp(-E<sub>mig</sub>/kT)**

を用いると、最終的に

**σ = (ze)²D₀/kT × exp(-E<sub>mig</sub>/kT)**

**σ = σ₀/T × exp(-E<sub>a</sub>/kT)** （アレニウス則）

が得られます。

#### 2.4.2 アレニウスプロット

この場合のアレニウスプロットは、三つの温度領域に分かれます。高温領域では内因性欠陥濃度が優勢となり、欠陥濃度は c ≈ exp(-E<sub>f</sub>/kT)、σ ≈ exp(-(E<sub>f</sub>/2 + E<sub>mig</sub>)/kT) で、傾きは E<sub>mig</sub> + E<sub>f</sub>/2 です。中温領域では、異価数元素置換で規定される外因性欠陥濃度が支配的となります。置換量がたとえ数%であっても、外因性欠陥は幅広い温度範囲で優勢なキャリアとなり、c ≈ const.（温度依存なし）、σ ≈ exp(-E<sub>mig</sub>/kT) で、傾きは E<sub>mig</sub>（+ E_as）です。低温領域では、コンタミレベル（極微量）の外因性欠陥が効いてきて、傾きは E<sub>mig</sub> + E<sub>f</sub>/2 となります。

![異価数元素置換した場合のアレニウスプロット](/learning/ionics/l1-arrhenius-extrinsic.webp "赤の実線が異価数元素置換で導入した外因性欠陥が支配する領域で、傾きはE<sub>mig</sub>（会合があればE<sub>as</sub>が加わる）です。置換量が数%でも、この領域は幅広い温度範囲に広がります。青の破線は内因性欠陥、赤の破線はコンタミレベルの外因性欠陥による寄与です。")

なお、異価数元素置換の場合は、ドーパントとキャリアの間に静電相互作用が働いて会合（キャリアトラップ）が生じるため、会合エネルギー（E_as）が活性化エネルギーに含まれることもあります。

## 3. 欠陥の表記方法：Kröger-Vink記法

### 3.1 基本記号

格子欠陥の記述には、次の記号を用います。

| 記号 | 意味 |
|------|------|
| V | 格子空孔（vacancy） |
| i | 格子間（interstitial） |
| e | 伝導電子 |
| h | 正孔（hole） |
| × | 電気的中性 |
| ● | 正電荷 |
| ' | 負電荷 |

### 3.2 具体的な反応式の例

**Case 1: BaF₂ + LaF₃ → Ba₀.₉La₀.₁F₂.₁**

Ba<sup>2+</sup>をLa<sup>3+</sup>で置換すると、格子間F<sup>-</sup>が生成します。

**Ba×_Ba + V×_i + LaF₃ → La●_Ba + F'_i + BaF₂**

このとき、正に帯電したドーパントと負に帯電した格子間Fの間には、静電相互作用（Coulombic interaction）が働きます。

**Case 2: BaF₂ + KF → Ba₀.₉K₀.₁F₁.₉**

Ba<sup>2+</sup>をK<sup>+</sup>で置換すると、F<sup>-</sup>空孔が生成します。

**Ba×_Ba + F×_F + KF → K'_Ba + V●_F + BaF₂**

このとき、負に帯電したドーパントと正に帯電したF空孔の間には、静電相互作用（Coulombic interaction）が働きます。

Kröger-Vink記法では欠陥の形式電荷を明示的に表記するため、電気的中性条件や静電相互作用を議論する際に便利です。

## 4. 異価数元素置換の勘所

### 4.1 基本原理

ここでは、Ba<sup>2+</sup>F<sup>-</sup>₂結晶格子へのF<sup>-</sup>欠陥の導入を例に考えます。

![BaF2結晶格子へのF−欠陥の導入](/learning/ionics/l1-baf2-aliovalent-defects.webp "Ba<sup>2+</sup>をK<sup>+</sup>で置換するとF<sup>−</sup>空孔（V<sub>F</sub><sup>•</sup>）が、La<sup>3+</sup>で置換すると格子間F<sup>−</sup>（F<sub>i</sub>′）が生じます。点線で囲んだように、欠陥は反対の電荷をもつドーパントの近くに束縛されやすくなります。")

#### 4.1.1 三つの重要原則

異価数元素置換を考えるうえでは、三つの重要な原則があります。第一に、欠陥がキャリアとなること。第二に、欠陥は局所的に束縛されていること（ドーパントとの静電相互作用や局所ひずみによる）。第三に、欠陥の束縛が弱いほど欠陥が動きやすいことです。

#### 4.1.2 設計指針

まず、格子間と空孔のどちらが動きやすいかは材料系に依存します。次に、欠陥の電荷は低い方が動きやすくなります。これは F = ε q₁q₂/r² で表されるように、電荷が小さい方が静電引力が弱いためです。例えば、Ba<sup>2+</sup>をLa<sup>3+</sup>で置換する場合（+1）よりも、Hf<sup>4+</sup>で置換する場合（+2）の方が格子間F<sup>-</sup>を強く束縛するため、F<sup>-</sup>が動けなくなります。さらに、ホスト格子（Ba<sup>2+</sup>）とドーパント（M<sup>3+</sup>, M<sup>+</sup>）のイオン半径差が小さいほど、局所ひずみが小さくなってF欠陥が動きやすくなり、また構造変形が小さいため多量に置換（欠陥ドープ）できます。

結論として、ホストイオンとイオン半径が近く、価数差が±1となる異価数元素を選ぶことで、高濃度のドープ（高いキャリア濃度）が可能になりやすく、欠陥（キャリア）の束縛も弱いため、イオン伝導率の向上が期待されます。

### 4.2 置換量依存性

#### 4.2.1 伝導率の典型的なドーパント依存性

イオン伝導率と活性化エネルギーの元素置換量依存性は、典型的には次のように整理できます。

| 領域 | 異価数元素濃度 | 特徴 | 活性化エネルギー | 説明 |
|------|----------------|------|------------------|------|
| ① | 0 mol% | 異元素置換無し | E<sub>mig</sub> + E<sub>f</sub> | 外因性欠陥がほとんど無いため、内因性欠陥を使う必要があり、その欠陥生成エネルギー（E<sub>f</sub>）が活性化エネルギーに含まれる |
| ② | 数mol% | 希薄な異元素置換 | E<sub>mig</sub> | イオン輸送に使われる欠陥の濃度は外因性欠陥濃度で決まり（温度によらず一定）、活性化エネルギーはおおよそ移動エネルギー（E<sub>mig</sub>）に相当する |
| ③ | 10mol%～ | 高濃度の異元素置換 | E<sub>mig</sub> + E_as | 高濃度のドーパントとの静電相互作用による会合（association）の形成エネルギー（E_as）が活性化エネルギーに含まれる |
| ④ | 高濃度 | 減少幅小 | なだらかな減少 | キャリア濃度は異元素置換濃度とともに単調に増加するため、高濃度領域での伝導率の低下はE_aの増加よりもなだらかになる（会合によるE_aの増加とキャリア濃度の増加が部分的に相殺する） |

このように、イオン伝導率は極大を持つ山型を示し、活性化エネルギーは最初に急激に減少した後、増加に転じます。

![イオン伝導率と活性化エネルギーの置換量依存性](/learning/ionics/l1-dopant-concentration-dependence.webp "よく使われる模式図です。黒線がイオン伝導率、青線が活性化エネルギーで、①〜④は上の表の領域に対応します。伝導率の低下（④）は、活性化エネルギーの増加よりもなだらかになります。")

### 4.3 イオン半径の指標：Shannonの有効イオン半径

イオン半径差を議論するときのサイズの指標には、Shannonの有効イオン半径（Shannon effective ionic radius）を使うと良いでしょう（R. D. Shannon, Acta Cryst. A32, 751 (1976)）。原子半径など他のサイズ指標もありますが、イオンのサイズはイオン半径で整理・議論されるのが一般的で、通常「イオン半径」といえばこれを指します。

一般的な傾向は次の通りです。
- 同族では、原子番号が大きいほどイオン半径が大きくなります（ランタノイド系列のみ逆の傾向を示し、ランタノイド収縮と呼ばれます）。
- 価数が正に大きいほど、電子雲が核に引きつけられ、イオン半径は小さくなります。
- 配位数が高いほど、イオン半径は大きくなります。

イオン半径は価数と配位数によって値が変わるので、目的の構造中での配位数・価数に対応した値を使いましょう（例：ペロブスカイトABX₃ではAが12配位、Bが6配位）。値を調べるには、[Shannonのイオン半径データベース](http://abulafia.mt.ic.ac.uk/shannon/ptable.php)が便利です。

### 4.4 Vegard則による固溶体形成の確認

Vegard則（Vegard's law）は、固溶体の格子定数と構成元素の濃度の間に比例関係が成り立つという経験則です。元素置換体の格子定数の変化は置換濃度と線形関係になり、その増減の傾向はイオン半径差でおおよそ説明できます。

例えば、イオン半径が相対的に大きな元素で置換した場合、①0〜20 mol%の範囲で格子定数と置換量が線形関係にあれば固溶体が形成されており、②20 mol%以上で格子定数が置換量によらず一定であれば、固溶限界は20 mol%と判断できます。実際にはこれほど綺麗なプロットにはならないことが多いので、エラーバー付きでプロットすると良いでしょう。

格子定数を計算しなくても、XRDピークの2θシフトから大まかな傾向を議論できます（Braggの式 nλ = 2d sinθ）。高角度側への連続的なピークシフトは格子収縮を伴う固溶体の形成を、ピークシフトの無い範囲は固溶範囲外を示します。ただし、XRDの回折計中心とサンプル表面がずれている場合（試料の盛りすぎなど）は、プロファイル全体が2θ方向にシフトすることがあります。この場合は、低角側のピークで2θ軸を合わせてから、高角側ピークの相対位置を議論します。

![Vegard則と固溶範囲の判断](/learning/ionics/l1-vegard-law.webp "左：イオン半径の大きな元素で置換した場合の格子定数の変化です。①の線形領域が固溶体、②の一定領域が固溶範囲外に当たります。右：置換量を増やしたときのXRDピークの模式図で、高角度側への連続的なシフトは格子収縮を伴う固溶体の形成、シフトが止まった範囲は固溶範囲外を示します。")

### 4.5 イオン半径と構造安定性：許容因子

イオン半径は、どの結晶構造が安定になるかの目安にもなります。代表例が、ペロブスカイトABX₃の許容因子（tolerance factor、Goldschmidt's factor）です。

**t = (r_A + r_X) / [√2 × (r_B + r_X)]**

ここで、r_A、r_B、r_XはそれぞれA、B、Xのイオン半径です。t = 1〜0.95ではイオン半径が釣り合い、立方晶ペロブスカイト（Pm-3m）構造が安定になります。tが1から外れると対称性が低下し、t ≈ 0.9では直方晶ペロブスカイト（GdFeO₃型、Pnma）、t > 1では六方晶ペロブスカイトになります。

![ペロブスカイトの許容因子](/learning/ionics/l1-tolerance-factor.webp "ペロブスカイトABX<sub>3</sub>の構造（左）と、許容因子tの考え方（右）です。A–X間の距離r<sub>A</sub> + r<sub>X</sub>と、B–X間の距離r<sub>B</sub> + r<sub>X</sub>の√2倍が等しいときにt = 1となり、イオン半径が釣り合います。")

このほか、特定の定比組成の化合物群を対象に、原子（またはイオン）のサイズをもとに構造地図を作成して、構造の傾向を整理する方法もあります。

### 4.6 元素置換は系統的に

元素置換を行うときは、まず「何を意図した置換か」を明確にします。例えば、格子サイズを変える置換（Si<sup>4+</sup> → Ge<sup>4+</sup>, Sn<sup>4+</sup>）、キャリア量を変える置換（Si<sup>4+</sup> + Li<sup>+</sup> → P<sup>5+</sup>）などです。ハイエントロピー化を狙う場合は、元素特性の分散が大きい組み合わせで置換します。次に「その影響がどの程度か」を確かめるため、置換量を0.1, 0.2, 0.3, …と系統的に変えて効果を確認します。

また、どのサイトを置換するのかを明示的に扱うことも大切です（結果的にどうなるかは別として）。同じ「M置換」でも、仕込み組成の段階でどのサイトを置き換えるつもりなのかを決めておくと、結果の解釈がぶれません。

![仕込み組成における置換サイトの考え方](/learning/ionics/l2-substitution-strategy.webp "Ba<sub>0.2</sub>Sn<sub>0.8</sub>F<sub>2</sub>を母組成とした例です。(i) Baサイト置換、(ii) Ba・Sn両サイト置換、(iii) Snサイト置換では、SnF<sub>2</sub>–BaF<sub>2</sub>–MF<sub>3</sub>（またはMF）擬三元系の中で仕込み組成が向かう方向がそれぞれ異なります。")

## 5. イオン移動の素過程

### 5.1 移動障壁（E<sub>mig</sub>; Migration Energy）

#### 5.1.1 二次元格子中の格子間原子の移動

**参考文献：**小岩昌宏、中嶋英雄、材料における拡散 格子上のランダム・ウォーク、内田老鶴圃 (2009)

イオンは最もエネルギーの低い反応経路を通過し、その反応経路上でエネルギーが極大となる空間座標を「鞍点（saddle point）」と呼びます。このときの移動障壁がE_migです。

### 5.2 遷移確率と拡散係数

#### 5.2.1 基本パラメータ

原子の振動数はDebye振動数 ≈ 10<sup>13</sup> s<sup>-1</sup>（周期 0.1 ps）程度であり、このDebye振動数で試行頻度ν₀を近似します。遷移確率は、安定位置と遷移状態のエネルギー差をE_migとすると、遷移状態にある確率 exp(-E<sub>mig</sub>/kT) で与えられます。したがって、1秒あたりに原子が遷移する頻度は

**ν = ν₀ exp(-E<sub>mig</sub>/kT)**

となり、拡散係数の最終式は

**D = ad²ν = D₀ exp(-E<sub>mig</sub>/kT)**

と表されます（aは隣接サイト数などで決まる係数）。重要な点として、原子の存在確率密度分布 ρ(x,y,z) / atom Å<sup>-3</sup> がわかれば、相対エネルギーE_migを求めることができます。

## 6. Kinetic Monte Carlo（KMC）法

### 6.1 基本概念と定義

モンテカルロとは、ランダムサンプリングのことです。モンテカルロを含む手法はいろいろあり、例えばランダムサンプリングによって実測値を再現するモデルを探索する逆モンテカルロ法や、レプリカ交換モンテカルロ法などが挙げられます。

### 6.2 計算手順

![KMCによる拡散係数計算の流れ](/learning/ionics/l2-kmc-procedure.webp "左：ある位置から4つの隣接サイトへ、障壁E<sub>1</sub>〜E<sub>4</sub>と移動距離d<sub>1</sub>〜d<sub>4</sub>で移動できる状況です。右：遷移確率P<sub>i</sub>で移動先を選ぶ操作を時間ステップ（1/ν<sub>0</sub> = 0.1 ps）ごとに繰り返し、平均二乗変位から拡散係数D = MSD/6tを求め、Nernst-Einstein式で伝導率に換算します。")

#### 6.2.1 各移動先への遷移確率

4つの隣接サイトへの障壁E₁, E₂, E₃, E₄がある場合を考えます。

**E₁を乗り越える確率：P₁ = exp(-E₁/kT)**

**E_iを乗り越え進む確率：P_i = exp(-E<sub>i</sub>/kT) / Σᵢ exp(-E<sub>i</sub>/kT)**

#### 6.2.2 シミュレーション

単位時間あたりのホッピングの試行頻度は、Debye振動数 ν₀ = 10<sup>13</sup> s<sup>-1</sup> で近似します。シミュレーションでは、各時間ステップ（1/ν₀ = 0.1 ps）ごとに隣接サイトへ移動するか否かを確率的に選択し、移動する場合は隣接サイトへ移動して変位dᵢを獲得します。

#### 6.2.3 拡散係数の算出

平均二乗変位（MSD）と時間tから D = MSD/6t として拡散係数を算出し、キャリア濃度からNernst-Einstein式を用いてイオン伝導率を計算します。

### 6.3 実用例：softBVソフトウェア

例えばsoftBVソフトウェアでは、Eや遷移経路、格子間サイトが求まるため、サイトをノード、経路をエッジとして、格子間サイトを経由するパスも加味したKMCを実行できます。

**参考文献：**H. Chen, L. L. Wong, S. Adams, Acta Crystallographica Sec. B, 75 (1), 18 (2019).

格子緩和やイオン間の相関を無視したラフな計算方法ではありますが、拡散の次元性の評価や、伝導率の絶対値の相対比較に便利です。

**手法自体はとても簡単ですが、あまり使われていません。**単純に知られていないのか、難解な印象から敬遠されているのかもしれません。

## 7. 拡散係数の導出と物質拡散

### 7.1 一次元ランダムウォーク

![一次元ランダムウォークと確率分布](/learning/ionics/l2-random-walk-1d.webp "上：左右に確率0.5ずつで1マス（d = 1）移動する一次元ランダムウォークです。下：時刻tに位置xにいる確率W(x,t)はガウス分布になり、拡散係数Dが大きいほど分布が広がります。平均位置は0のままなので、広がりは二乗変位で評価します。")

#### 7.1.1 なぜ単位が距離の二乗なのか：D (cm² s<sup>-1</sup>)

一次元のランダムウォーク（酔歩）を、次のように設定します。
- 右・左へ移動する確率：p(+1) = 0.5，p(-1) = 0.5
- 左への移動回数 nₗ，右への移動回数 nᵣ
- 正味の右方向への移動回数：m = nᵣ - nₗ
- 1回あたりの移動距離：d = 1
- 正味の移動距離：x = md

#### 7.1.2 統計的解析

移動距離xの平均値は

**⟨x⟩ = ∫_{-∞}^{∞} xW(x,t)dx = 0**

となります。平均移動距離は0となるため、これだけではどれだけ変位したかはわかりません。そこで、拡散によって粒子がどれくらいの距離を動いたか（分布がどの程度広がったか）を知るには、二乗変位x²の平均値を用います。

**⟨x²⟩ = ∫_{-∞}^{∞} x²W(x,N)dx = 2Dt**

#### 7.1.3 確率分布関数

時刻tに位置xにいる確率W(x,t)は、次式で与えられます。

**W(x,t) = 1/(2√πdt) exp(-x²/4Dt)**

#### 7.1.4 粒子のジャンプ統計

粒子が単位時間あたりν回ジャンプするとき、時間tにわたる総ジャンプ数は N = νt となり、D = νd²/2 が得られます。

### 7.2 多次元への拡張

| 次元 | 拡散係数の関係式 |
|------|------------------|
| 一次元 | D = ⟨x²⟩/2t |
| 二次元 | D = ⟨r²⟩/4t |
| 三次元 | D = ⟨r²⟩/6t |

**参考文献：**小岩昌宏、中嶋英雄、材料における拡散 格子上のランダム・ウォーク、内田老鶴圃 (2009)

### 7.3 Fickの法則

#### 7.3.1 Fickの第一法則（定常状態の拡散）

**J = -D ∂c/∂x**

物質の拡散流束は、濃度勾配に比例します。ここで、各記号の意味は次の通りです。
- J：流束（単位時間当たりに単位面積を通過する粒子数）[mol/m² s]
- D：拡散係数 [m²/s]
- c：粒子濃度 [mol/m³]

#### 7.3.2 外場印加時の修正

外場によって一方向に駆動される粒子の流束は、速度v [m/s]と粒子濃度c [mol/m³]を用いて vc [mol/m² s] と書けます。これを加えると、流束の式は

**J = -D ∂c/∂x + cv**

と修正されます。定常状態では流束J = 0となるため、

**D ∂c/∂x = cv**

が成り立ちます。

#### 7.3.3 Fickの第二法則（非定常状態の拡散）

**∂c/∂t = D ∂²c/∂x²**

この式は、拡散による濃度分布の時間発展を記述します。

### 7.4 Nernst-Einstein方程式の導出

#### 7.4.1 ボルツマン分布と力の関係

外場による原子のポテンシャルをφ(x)とすると、イオンの分布はボルツマン分布で表されます。

**c(x) = const. exp(-φ(x)/kT)**

両辺を微分すると

**dc/dx = -c dφ/kT dx**

となります。原子にかかる力（駆動力）Fは、ポテンシャルφ(x)の位置微分

**F = -dφ/dx**

であることから、

**dc/dx = cF/kT**

が得られます。

#### 7.4.2 流束の釣り合い条件

外場によって駆動される拡散流と、それを打ち消す濃度勾配駆動の拡散流（Fickの第一法則）が釣り合うとき、

**D ∂c/∂x = cv**

であり、流束は

**J = cv = D cF/kT**

となります。

#### 7.4.3 電場印加時

電場Eによって電荷qが受ける力は

**F = qE**

であるため、流束は

**J = cv = Dcq/kT E**

となり、電流密度は電荷×流束として

**i = qJ = q²cD/kT E**

と書けます。

#### 7.4.4 最終的なNernst-Einstein方程式

**σ = q²cD/kT**

**参考文献：**小岩昌宏、中嶋英雄、材料における拡散 格子上のランダム・ウォーク、内田老鶴圃 (2009)

## 8. トラッピング現象

### 8.1 歴史的背景と定義

トラッピングは現象としてなんとなく認識されていましたが、プロトン伝導体で明確に提唱されて以降、プロトン伝導体の分野で盛んに議論されている印象です。

**参考文献：**Y. Yamazaki, et al., Nat. Mater., 12, 647 (2013).

### 8.2 基本概念

トラッピングの原因は、ドーパントと欠陥の静電相互作用など、何らかの束縛です。エネルギー図で考えると、通常のエネルギー障壁Eに加えて、トラップによる追加のエネルギーE_Bが存在します。

![トラッピングのエネルギー図](/learning/ionics/l2-trapping-energy.webp "通常のサイト間の障壁はEですが、トラップ位置（網で示したサイト）ではさらにE<sub>B</sub>だけ深くなっています。トラップに捕まった粒子は、抜け出すのにE + E<sub>B</sub>を越える必要があります。")

### 8.3 滞留時間の計算

#### 8.3.1 基本パラメータ

基本パラメータとして、正規位置での滞在時間t_n、トラップ位置での滞在時間t_T、トラップ濃度cを定義します。粒子がN回ジャンプする（同じ距離を移動する）のに要する時間を、トラップ無しの場合t_U、トラップ有りの場合t'_Uとすると、移動距離が同じであることから次の関係式が成り立ちます。

**Dt_U = D't'_U**

#### 8.3.2 滞留時間

粒子の滞留時間は、配位数（そこへジャンプしうる近接サイトの数）zと振動因子ν₀を用いて、次式で表されます。

**t_n = (zν₀)⁻¹ exp(E/kT)**

**t_T = (zν₀)⁻¹ exp((E + E_B)/kT)**

#### 8.3.3 総滞留時間

総滞留時間は次のようになります。

**t_U = Nt_n**

**t'_U = N[(1-c)t_n + ct_T]**

### 8.4 みかけの拡散係数の導出

以上から、みかけの拡散係数は次式で与えられます。

**D' = D × 1/[(1-c) + c exp(E_B/kT)]**

### 8.5 温度依存性

温度依存性としては、低温では E<sub>a</sub> = E + E_B、高温では E<sub>a</sub> = E となります。

### 8.6 一般的な適用性

キャリアが点欠陥の場合、どのようなイオン伝導種でも共通してトラッピングは存在するはずです。ただし、欠陥が高濃度かつ不規則に分布した構造欠陥系では、トラッピング状態の定義が曖昧なため、それほど議論されていません。

**参考文献：**小岩昌宏、中嶋英雄、材料における拡散 格子上のランダム・ウォーク、内田老鶴圃 (2009)

## 9. ブロッキング効果とパーコレーション

### 9.1 ブロッキング効果の定義

ブロッキング効果はイオン伝導体にも共通する概念ですが、イオン伝導体の分野でこの用語が使われることは少ないようです。

#### 9.1.1 基本式

ブロックサイトの濃度がcのときの拡散係数は、次式で表されます。

**D<sub>b</sub>(c) = D(1 - bc)**

ここでbは、副格子の次元や連結数で決まるブロッキング係数です。

#### 9.1.2 次元依存性

低次元（1次元）の拡散ほど、ブロッキングによって無限拡散が妨げられやすく、高次元（2〜3次元）の拡散であれば迂回が可能です。例えば正方格子では、c = 0.5で無限拡散が妨げられる（D<sub>b</sub>(c) = 0）ので、b = 2となります。

#### 9.1.3 配位数の効果

配位数が高いほどブロッキング効果は小さくなり、c = 0.78以上で無限拡散が不可能となります。

**参考文献：**小岩昌宏、中嶋英雄、材料における拡散 格子上のランダム・ウォーク、内田老鶴圃 (2009)

---

### 9.2 実例：Li₁₀GeP₂S₁₂でのブロッキング効果

Li₁₀GeP₂S₁₂において、ab面内の拡散経路のLiを人工的に固定すると、自己拡散係数は0になります。ただし重要な点として、自己拡散係数が0であることは、イオン伝導率が0であることを意味しません。これはあくまでMDで観測される一次元経路の自己拡散係数が0になるということであり、面内拡散経路の中間サイトへの遷移を経る一種の活性化過程（Frenkel欠陥の生成）が、無限拡散に必須であるとも言えます。

**参考文献：**K. Miwa, R. Asahi, Solid State Ionics 361 (2021) 115567

---

### 9.3 パーコレーション理論

#### 9.3.1 基本概念

![8×8正方格子でのパーコレーション](/learning/ionics/l2-percolation-square-lattice.webp "赤い×はブロッキングサイトです。左：14/64サイトがブロック（通過可能78%）されていても、左端から右端へ抜ける経路があります（パーコレートする）。右：28/64サイトがブロック（通過可能56%）されると、途中で行き止まりになります（パーコレートしない）。")

8×8の正方格子での例を考えます。原子は格子点から隣接する格子点へ移動し、ブロッキングサイトの濃度がマクロな輸送特性を決めます。例1として、64サイト中14サイトがブロックされた場合は、通過可能なサイトが78%となり、パーコレートします。例2として、64サイト中28サイトがブロックされた場合は、通過可能なサイトが56%となり、パーコレートしません。

#### 9.3.2 パーコレーション閾値

通過可能なサイトが56%ではパーコレートしなかったことからわかるように、正方格子では通過可能なサイトが59%以上必要となります。

#### 9.3.3 パーコレーション閾値の理論値

| 次元 | 格子 | 配位数 | P(0,1) | 回帰確率 p_r | 正味訪問点 S_n | 臨界浸透確率 p_c(s) |
|------|------|--------|--------|--------------|----------------|---------------------|
| 1 | 直線 | 2 | ∞ | 1 | ~(8n/π)^{1/2} | 1 |
| 2 | 正方 sq | 4 | ∞ | 1 | ~πn/log n | 0.593 |
| 3 | 単純立方 sc | 6 | 1.51638 | 0.3405 | ~0.659n | 0.311 |
| 3 | 体心立方 bcc | 8 | 1.39320 | 0.2822 | ~0.717n | 0.246 |
| 3 | 面心立方 fcc | 12 | 1.34466 | 0.2563 | ~0.743n | 0.198 |
| 3 | 最密六方 hcp | 12 | 1.34466 | 0.2563 | ~0.743n | 0.204 |

**結論：**パーコレーションの閾値は、キャリア副格子の次元と隣接サイトの数で決まります。

**参考文献：**小岩昌宏、中嶋英雄、材料における拡散 格子上のランダム・ウォーク、内田老鶴圃 (2009)

### 9.4 実例：Li₀.₃₈₈Ta₀.₂₃₈La₀.₄₇₅Cl₃

Li₀.₃₈₈Ta₀.₂₃₈La₀.₄₇₅Cl₃は、3.0 mS cm<sup>-1</sup>の伝導率を示します。LaCl₃へのLi置換によって伝導率が向上し、Li濃度が0.25以上になると、LiチャンネルとLa空孔を介した3次元の伝導パスが形成されます。この材料は[LaCl₉] tricapped trigonal prism構造からなり、Li<sup>+</sup>は**Li1（channel sites）とLi2（La-vacancy sites）**に配置されます。移動先を上下2方向と面内6方向と仮定すると、パーコレーションの閾値は約25%となり、イオン伝導率が報告されている組成範囲（Li₀.₂₅）と対応します（bccではありませんが、8配位の値を参考にしています）。

結論として、骨格元素がキャリアと同じサイトを占有する場合は、パーコレーションの閾値に注意しましょう。

**参考文献：**Y. Yin, et al., Nature, 616, 77 (2023)

---

### 9.5 実例：パイロクロア型Li₂₋ₓLa₍₁₊ₓ₎/₃M₂O₆F

パイロクロア型AB₂O₆Fで、極めて高いイオン伝導率が報告されました（Li₁.₂₅La₀.₅₈Nb₂O₆F：bulk 7 mS cm<sup>-1</sup>）。我々も以前この系に取り組んでいましたが（LiSrNb₂O₆F：1.1 × 10<sup>-3</sup> mS cm<sup>-1</sup> at 673 K. J. Jpn. Soc. Powder Powder Metall. 2018, 65, 26−33.）、伝導率が低かったため、深掘りしませんでした。

では、なぜ伝導率がこれほど違うのでしょうか。その答えは、サイトのLi濃度がパーコレーションに必要な量に足りなかったこと、そしてブロッキング効果をもつSrの濃度が高すぎたことにあります。

**結論：パーコレーションの閾値は重要です。**

**参考文献：**A. Aimi, S. Yoshida, et al., Chem. Mater. 2024, 36, 3717−3725

---

### 9.6 実例：正極材料オリビン型LiFePO₄

オリビン構造（空間群：Pnma）はFeO₆八面体とPO₄四面体の骨格からなり、P-O結合が強固であるため構造安定性が高く、リチウムの一次元チャンネルを持ちます。反応は LiFePO₄ ⇄ FePO₄ + Li⁺ + e⁻ です。

![オリビン型LiFePO4の結晶構造](/learning/ionics/l1-olivine-lifepo4.webp "FeO<sub>6</sub>八面体（茶）とPO<sub>4</sub>四面体（紫）の骨格の間に、Li（緑）がb軸方向に一列に並んだ一次元チャンネル（緑の円）をつくります。")

b軸方向の一次元Liチャンネルでは、チャンネル中の欠陥に挟まれたLiは動けなくなります。その例がLiとFeのアンチサイト欠陥であり、ブロッキングによって利用できなくなる容量の割合は、おおよそ粒子サイズに対応します。結論として、粒子径を小さくすることで、一次元経路中で充放電に利用できるLiサイトの割合が増えます。

**参考文献：**R. Malik, G. Ceder, et al., Nano Lett. 2010, 10, 4123–4127

## 10. 混合効果

### 10.1 基本概念

骨格金属元素を混合すると、伝導率が向上します。

### 10.2 具体例：Li₄SiO₄系

Li₄SiO₄系では、複数種のカチオンを混ぜると伝導率が向上することが、計算から報告されています。

**参考文献：**Y. Deng, C. Masquelier, M. Saiful Islam, et al., ACS Appl. Mater. Interfaces 9, 7050 (2017).

---

### 10.3 ハイエントロピー効果

ハイエントロピーは、ここ2〜3年のバズワードです。配置エントロピーは次式で表されます。

**S_conf = -R Σ_{k=1}^n c_k ln(c_k)**

ここで、c_kはk番目のサイトの濃度です。また、混合エントロピーは次式で表されます。

**S_mix = -R Σ_{i=1}^m c_i ln(c_i) - R Σ_{j=1}^n c_j ln(c_j)**

ここで、各記号の意味は次の通りです。
- c_i：i番目のアニオン種の濃度
- m：アニオン種の数
- c_j：j番目のカチオン種の濃度
- n：カチオン種の数

結論として、いろいろと混ぜると良いのですが、実際にはそれほど単純でもありません。

**参考文献：**Xueliang Sun, et al., Adv. Mater., 2501544 (2025).

---

### 10.4 多元系展開での注意点

#### 10.4.1 キャリアサイトの多元化

キャリアサイトを多元化する場合、異なる元素が同じ結晶学サイトを占有するとブロッキング効果が生じます。そのため、性質が大きく異なる元素による多元化で特異点を探すべきです（Ag<sup>+</sup>, Cu<sup>+</sup>導電体におけるRb<sup>+</sup>など）。

#### 10.4.2 骨格元素の多元化

骨格元素を多元化する場合は、電荷秩序（電荷の不均一）を避けることが重要です。特に骨格元素がキャリアに配位する場合（F<sup>-</sup>伝導体など）は、より深いポテンシャル（deeper potential）を誘起してしまいます。第二近接であれば、電荷の不均一による静電相互作用は小さくなるので、良いかもしれません（LISICONなど？）。

#### 10.4.3 複数種のユニットの組み合わせ

複数種のユニットを組み合わせてintergrowth構造へ展開する場合は、相乗効果のコンセプトを念頭に置く必要があります。異種層の界面での高速伝導や、Frenkel欠陥形成エネルギーの低減といった効果が期待できれば良いのですが、そうでなければ、積層構造よりもブロック単体のバルクの方が、大抵は伝導率が高くなります。

## 11. 誘起効果（Inductive Effect）

### 11.1 基本概念

誘起効果とは、電気陰性度差によって生じる結合の分極、およびその分極が隣接する結合に及ぼす影響のことです。

### 11.2 メカニズム

#### 11.2.1 結合性と分極の関係

| M-Xの電気陰性度差 | M-X結合性 | 陰イオンX<sup>n-</sup>の負電荷(n) | X-Liのクーロン相互作用 F = εq₁q₂/r² |
|-------------------|-----------|---------------------------|-------------------------------------|
| 大 | イオン結合性 | 大 | 強 |
| 小 | 部分的に共有結合性 | 中 | 弱 |

#### 11.2.2 具体例：Mg<sup>2+</sup>O<sup>2-</sup> vs Zn<sup>1.9+</sup>O<sup>1.9-</sup>

結合がより共有結合的（more covalent）になると、陰イオンの負電荷は「大」から「中」へ、クーロン相互作用は「強」から「弱」へと変化します。結論として、電気陰性度差によって生じる分極が小さいほど、Li<sup>+</sup>の束縛が弱まり、Li<sup>+</sup>は動きやすくなります。

ただし、誘起効果はおそらく、多様な構造にわたる大域的な傾向を説明できるほど大きな効果ではありません。そのため、同じ結晶構造中での構成元素の違いに着目して議論されることが多いです（特に電解質）。

![誘起効果の模式図](/learning/ionics/l2-inductive-effect.webp "上段はイオン結合性の強いMg<sup>2+</sup>–O<sup>2−</sup>、下段は共有結合性が高いZn<sup>1.9+</sup>–O<sup>1.9−</sup>のイメージです。M–X結合の共有結合性が高まると陰イオンの有効負電荷が小さくなり、Li<sup>+</sup>とのクーロン相互作用が弱まって、Li<sup>+</sup>が動きやすくなります。")

### 11.3 実例1：K<sup>+</sup>伝導体

#### 11.3.1 Hollandite型K₂MgTi₇O₁₆

Hollandite型K₂MgTi₇O₁₆でMg<sup>2+</sup>をZn<sup>2+</sup>に置換すると、活性化エネルギーはE_a = 1.16 eVから0.54 eVへと低下します。電気陰性度はO (3.34) > Zn (1.65) > Mg (1.31)の順であり、Mg-OよりもZn-Oの方が共有結合性が強いため、Oの有効負電荷が小さくなり、K-Oの静電相互作用が小さくなるためです。

#### 11.3.2 二次元酸化物：K₀.₇(T₀.₃₅Sn₀.₆₅)O₂

二次元酸化物K₀.₇(T₀.₃₅Sn₀.₆₅)O₂では、T = Ca<sup>2+</sup>, Mg<sup>2+</sup>, Zn<sup>2+</sup>に対して、それぞれσ = 4.5×10<sup>-7</sup>, 1.6×10<sup>-6</sup>, 7.5×10<sup>-6</sup> S cm<sup>-1</sup>、E<sub>a</sub> = 0.54, 0.52, 0.45 eVとなります。

**参考文献：**J. Etourneau, et al., J. Alloys and Comp., 188, 1 (1992).

### 11.4 実例2：Li<sup>+</sup>伝導体

#### 11.4.1 Li₁₀GeP₂S₁₂ vs Li₁₀SnP₂S₁₂

Li₁₀GeP₂S₁₂とLi₁₀SnP₂S₁₂を比較すると、伝導率はLi₁₀GeP₂S₁₂の方が高く（High > Medium）なります。COHP（Crystal Orbital Hamilton Population）による化学結合性の評価では、COHPが低いほど共有結合性が強く、Sの負電荷が小さくなります。

#### 11.4.2 結合解析の結果

結合解析の結果、Sの正味の原子電荷（S net atomic charge）はGe-S結合 > Sn-S結合、M-S結合の分極（M-S bond polarity）はGe-S < Sn-Sとなります。Li<sup>+</sup>との引力が弱いほど（weaker attraction）Li<sup>+</sup>の移動度は高く、引力が強いほど（stronger attraction）Li<sup>+</sup>の移動度は低くなります。

**参考文献：**S. P. Culver, J. Morgan, W. G. Zeier, et al., J. Am. Chem. Soc., 142, 21210 (2020).

このことから、電気陰性度の高い金属を第三の骨格元素として採用すれば、M-Oの共有結合性が高まり、Li-Oの結合が弱まるはずです。**陽イオン伝導体**では、陰イオンに対して電気陰性度（EN）が僅かに低いMを選ぶと良いと考えられます（M-Xの共有結合性が高まり、Li-(X-M)の結合が弱まるため）。**陰イオン伝導体**では、X-M-FにおけるX-MのEN差が小さいと、Fが動きやすくなるかもしれません（I-Bi、S-Bi、Al-Bなど？）。

### 11.5 電極への応用例

#### 11.5.1 Li₂Fe₂(SO₄)₃と Li₂Fe₂(XO₄)₃ X=Mo, W

Li₂Fe₂(SO₄)₃とLi₂Fe₂(XO₄)₃（X=Mo, W）では、OCV（平衡電位）に約600 mVの差が生じます。電気陰性度はX<sup>n+</sup> > M<sup>m+</sup>、共有結合性はX-O > M-O、軌道分裂幅（結合性軌道と反結合性軌道のエネルギー差）はΔE(X–O) > ΔE(M–O)という関係にあります。X-O-Mでは、価電子帯上端（E_F）にあるM-O反結合性軌道（M t₂g–O p π結合）のエネルギー準位が、M-O-Mの場合よりも低下します。

なお、Fe<sup>2+</sup>（high spin）の軌道分裂では、t₂g軌道はdxy, dxz, dyz、e_g軌道はdx²-y², dz²からなります。

**参考文献：**
- A. K. Padhi, J. B. Goodenough, et al., J. Electrochem. Soc., 144(4), 1188 (1997).
- D. A. Kuznetsov, Y. Shao-Horn, et al., Joule, 2, 225 (2018).

## 12. ペロブスカイト型Li<sup>+</sup>伝導体

### 12.1 基本特性

La₂/₃₋ₓLi₃ₓTiO₃は、σ<sub>bulk</sub> ≈ 10<sup>-3</sup> S cm<sup>-1</sup>を示します。

**参考文献：**Y. Inaguma, et al., Solid State Commun., 86 (10), 689 (1993).

この材料は、c軸方向に二倍周期をもつペロブスカイト構造をとります。Aサイト（La）の欠陥と二次Jahn-Teller効果があり、Ti（d⁰）の空のt₂g（dyz, dzx）軌道とO 2p軌道のπ混成によるSOJTにより、TiはLa欠陥層の方向へ変位します。構造はLa-poor層とLa-rich層の交互配列からなり、格子間Li（interstitial Li）も存在します。Li-poor相（x ≈ 0.05, 上記の構造）は二次元伝導を、Li-rich相（x ≈ 0.11, Liがよりc軸方向に広く分布）は三次元伝導を示します。ただし、これはあくまで平均構造であり、実際にはLiとLaは近接配置をとりません。

### 12.2 二次Jahn-Teller（SOJT）効果

#### 12.2.1 基本メカニズム

SOJTの基本メカニズムは、Ti（d⁰）の空のt₂g軌道（LUMO）と被占有のO 2p軌道（HOMO）が混成して結合性のt₂g-O 2p混成軌道を形成し、元のHOMO準位よりΔEだけエネルギーが下がる（エネルギー利得が生じる）というものです。O 2p軌道とM t₂g軌道の準位差が小さいほど、SOJT変位によるエネルギー利得は大きくなります。

この傾向はイオン伝導率の序列 σ: Nb, Ti > Ta > Zr と対応しており、SOJT変位しやすい（3d-O 2p軌道の準位差が小さい）元素の方が、Li輸送時の活性化障壁の低減に有効であると予想されます。実際、M 4d-O 2p（M=Zr, Ta）よりもM 3d-O 2p（Nb, Ti）の方が、SOJT変位は大きくなります。

点群はSOJT歪みによりO_hからC₄ᵥへと変化します。このとき、B d t₂g LUMO（e: d_xy, d_yz）とO 2pπ t₁u HOMOは摂動（perturbation）によってΔEのエネルギー変化を受け、ΔE ∝ (E_LUMO-E_HOMO)⁻¹ の関係があります。

### 12.3 パーコレーション解析

AサイトにおけるLi<sup>+</sup>・空孔濃度が約31〜34%を境に、伝導率が向上します。拡散機構は、パーコレーションを考慮した空孔拡散機構です。

#### 12.3.1 副格子構造

ペロブスカイトのAサイトだけを考えた格子（Aサイト副格子）は単純格子であり、Liイオンの移動は単純格子におけるパーコレーション（浸透）として整理できます。実際、Li浸透のパーコレーション閾値と実験結果はよく対応します。

**参考文献：**Y. Inaguma, et al., Solid State Ionics., 86-88, 257 (1996).

**結論：**パーコレーションとその閾値は、マクロな輸送特性を支配するミクロな要因であり、他の材料系や合剤の比率設計でも役に立ちます。

**参考文献：**稲熊宜之, 日本結晶学会誌 58，62-72(2016)

## 14. ボトルネック・臨界半径

ペロブスカイトBaLiF₃での計算例を示します。基本パラメータは、a = 3.99 Å、r_Li = 0.76 Å、r_F = 1.33 Å、r_Ba = 1.61 Åです。A2Bからなる三角形をボトルネック面とすると、その面積は

**S = a²/2√2 = 5.66 Å²**

となります。臨界半径は、幾何学的な関係式

**(r_A + r<sub>c</sub>)² = (a/2)² + (a/√2 - r_B - r<sub>c</sub>)²**

から

**r<sub>c</sub> = [a²/4 + (a/√2 - r_B)² - r_A²] / [2(r_A + a/√2 - r_B)]**

と計算され、数値を代入すると

**r<sub>c</sub> = 0.77 Å ≪ r_F = 1.33 Å**

となります。つまり、ボトルネックを通過する際には骨格陽イオンとの大きな重なり反発が生じており、骨格元素の分極率（電子雲の歪みやすさ）や原子の変位能が重要であることが窺えます。

![BaLiF3のボトルネックと臨界半径](/learning/ionics/l2-bottleneck-critical-radius.webp "左：ペロブスカイトBaLiF<sub>3</sub>の構造と、F<sup>−</sup>が通過するBa–Ba–Liの三角形ボトルネックです。中：三角形の面積S = a<sup>2</sup>/2√2です。右：三つの陽イオンに接する円の半径が臨界半径r<sub>c</sub>で、0.77 Åとr<sub>F</sub> = 1.33 Åより大幅に小さいことがわかります。")

## 15. 逆ペロブスカイト型イオン伝導体

逆ペロブスカイト型イオン伝導体の基本組成は、A₃ChX（A = Li, Na, H、Ch = O、X = Cl, Br）です。伝導率はLi<sup>+</sup>で10<sup>-4</sup>~10<sup>-5</sup> S cm<sup>-1</sup>、Na<sup>+</sup>で10<sup>-6</sup>~10<sup>-7</sup> S cm<sup>-1</sup>程度です。Li₃OX（X = Cl or Br）では10<sup>-3</sup> S cm<sup>-1</sup>が報告されました（Zhao et al., 2012）。合成反応は次の通りです。

**LiCl + 2LiOH = Li₃OCl + H₂O**

報告されている最高伝導率は、Li₃OCl₀.₅Br₀.₅の1.94×10<sup>-3</sup> S cm<sup>-1</sup>です。ただし再現性が低く、プロトン伝導の寄与が疑われています。レビューでは、再現実験をもとに、Li<sup>+</sup>で10<sup>-4</sup>~10<sup>-5</sup> S cm<sup>-1</sup>、Na<sup>+</sup>で10<sup>-6</sup>~10<sup>-7</sup> S cm<sup>-1</sup>が実際の最高伝導率であると結論づけられています。

## 17. 超イオン導電体

狭義には、超イオン導電（superionic conductivity）は超伝導（superconductivity）と区別して用いられます。広義には、イオン伝導（ionic conductivity）を指します。我々の分野では「導電」という表記が一般的で、本来は超イオン導電体以外には「伝導」を使うべきですが、実際問題としては、どちらかに統一すればどちらでも良いでしょう。

### 17.1 α-AgI

#### 17.1.1 相転移

AgIは、147°Cでβ相（ウルツ鉱型構造、hcp）からα相（bcc）へ相転移します。

#### 17.1.2 β-AgI構造（低温相）

β-AgI構造（低温相）では、I<sup>-</sup>がhcp格子を組み、四面体（2b）位置が占有率1で占められています。

#### 17.1.3 α-AgI構造（高温相）

α-AgI構造（高温相）では、I<sup>-</sup>がbcc格子を組み、歪んだ四面体（12d）位置、八面体（6b）位置、平面三配位（24h）位置が存在します。Ag<sup>+</sup>は格子間隙の複数の結晶学サイトに部分占有で広く分布した平均構造をとります。このAg<sup>+</sup>の副格子融解が、超イオン導電をもたらします。

**参考文献：**工藤撤一、笛木和雄、固体アイオニクス、講談社（1986）

![α-AgIとβ-AgIの構造](/learning/ionics/l2-agi-structures.webp "上：高温相α-AgIではI<sup>−</sup>がbcc格子を組み、Ag<sup>+</sup>は歪んだ四面体（12d）、八面体（6b）、平面三配位（24h）の複数の位置に部分占有して広く分布します。下：低温相β-AgIではI<sup>−</sup>がhcp格子を組み、Ag<sup>+</sup>は四面体（2b）位置を占有率1で占めます。")

### 17.2 Ag₃SI

#### 17.2.1 相転移と構造変化

β-Ag₃SI（低温相）はPm-3mの逆ペロブスカイト型構造で、σ = 0.008 S cm⁻¹を示し、陰イオンが規則配列しています。一方、α-Ag₃SI（高温相）はIm-3mのα-AgI型構造で、σ = 0.3 S cm⁻¹を示します。陰イオンの不規則配列（Im-3m）とAg<sup>+</sup>の無秩序分布によって、高いイオン導電率が実現されます。

#### 17.2.2 構造

Ag₃SIでは、陰イオンのbccパッキング中をAg<sup>+</sup>が高速拡散します。Ag<sup>+</sup>は24h位置を占め、S<sup>2-</sup>/I<sup>-</sup>が配列しています。

**参考文献：**S. Hull, et al., J. Phys.: Condens. Matter, 13, 2295 (2001).

![β-Ag3SIとα-Ag3SIの構造とエネルギー地形](/learning/ionics/l2-ag3si-structures.webp "左：β-Ag<sub>3</sub>SI（Pm-3m、逆ペロブスカイト型）では陰イオンが規則配列し、Ag<sup>+</sup>のサイト間に高い障壁があります。右：α-Ag<sub>3</sub>SI（Im-3m、α-AgI型）では陰イオンが不規則配列し、Ag<sup>+</sup>（24h）が平坦なポテンシャル上に無秩序に分布するため、伝導率が0.008から0.3 S cm<sup>−1</sup>へ大きく向上します。")

### 17.3 RbAg₄I₅

RbAg₄I₅では、高温相を安定化させる目的で、Rb<sup>+</sup>, NH₄<sup>+</sup>などの置換が行われています。構造は、AgI₄四面体同士が面共有でネットワークを形成したものです。温度と伝導率の関係は、他の材料と比較して示されます。

![RbAg4I5の結晶構造](/learning/ionics/l2-rbag4i5-structure.webp "RbAg<sub>4</sub>I<sub>5</sub>の構造です。下の図のように、AgI<sub>4</sub>四面体同士が面を共有してつながり、Ag<sup>+</sup>が移動できる三次元のネットワークを形成しています。")

### 17.4 Rb₄Cu₁₆I₇Cl₁₃

Rb₄Cu₁₆I₇Cl₁₃は、CuCl - CuI - RbCl 擬三成分系の絨毯爆撃的な（網羅的な）探索で見いだされ、0.34 S cm⁻¹を示します。Cu(I/Cl)₄四面体同士が面共有でネットワークを形成し、一次元のらせん経路をとります（Cuの核密度分布が可視化されています）。

なぜRbなのかについては、KやNaではCuサイトを占有してサイトブロック効果が生じるため、またCsでは大きすぎてこの構造をとれない、あるいは経路が歪むためではないかと考えられます。

## 18. 高温相の安定化：酸化物イオン伝導体

高温で超イオン伝導体相をひとたび見いだせれば、次は元素置換によって低温での安定化を図ります。低温相γ-Bi₂O₃と高温相α-Bi₂O₃は、いずれも蛍石型構造（MX₂：Bi₄O₆□₂）を基本とし、酸素サイトの1/4が空孔です。両者の違いは空孔の並び方にあり、低温相γでは酸素と空孔が規則配列（ordering）しているのに対し、高温相αでは不規則に配列した高対称構造をとります。

G = H - TSより、高温では高エントロピー状態が安定化されるため、元素置換によって配置エントロピーを増大させることで、低温での安定化が可能です。

![γ-Bi2O3とα-Bi2O3の構造](/learning/ionics/l2-bi2o3-phases.webp "上：低温相γ-Bi<sub>2</sub>O<sub>3</sub>（単斜晶系）では酸素と空孔が規則配列しています。下：高温相α-Bi<sub>2</sub>O<sub>3</sub>（立方晶系）は蛍石型（Bi<sub>4</sub>O<sub>6</sub>□<sub>2</sub>）で、酸素サイトの1/4が空孔となり、酸素と空孔が不規則に配列した高対称構造です。")

**参考文献：**T. Takahashi, H. Iwahara, Mat. Res. Bull., 13, 1450 (1978), 工藤撤一、笛木和雄、固体アイオニクス、講談社（1986）

## 19. 超アニオン導電体：BIMEVOX & PbSnF₄

### 19.1 Bi₄V₂O₁₁（Aurivillius構造）

Bi₄V₂O₁₁（Aurivillius構造）は、σ₂₀₀°C = 3×10<sup>-4</sup> S cm⁻¹を示します。構造は、占有率1でおそらく動かないF層、部分占有で不規則配列したPv層、そして再び占有率1のF層という積層からなります。ここでは、V<sup>5+</sup>のSOJT効果が重要かもしれません。

### 19.2 PbSnF₄（層状蛍石構造）

PbSnF₄（層状蛍石構造）は、σᵣ.ₜ. = 3×10<sup>-2</sup> S cm⁻¹を示します。構造は、占有率1でおそらく動かないF(Pb)層、部分占有で不規則配列したF(Sn)層2枚、そして再び占有率1のF(Pb)層という積層からなります。こちらでは、Sn<sup>2+</sup>の孤立電子対の効果が重要かもしれません。

### 19.3 共通する特徴

![Bi4V2O11とPbSnF4の層状構造](/learning/ionics/l2-bimevox-pbsnf4.webp "左：Aurivillius構造のBi<sub>4</sub>V<sub>2</sub>O<sub>11</sub>、右：層状蛍石構造のPbSnF<sub>4</sub>です。青枠の陰イオン層は占有率1でおそらく動かず、赤枠の層では陰イオンが部分占有・不規則配列しています。いずれも変位能の高い骨格元素（V<sup>5+</sup>のSOJT、Sn<sup>2+</sup>の孤立電子対）を含みます。")

両者に共通する特徴は、ペロブスカイト（Pv）や蛍石（F）のブロックからなる層状構造であること、そして層間で陰イオンが高度に不規則配列していることです。また、V<sup>5+</sup>のSOJT（二次Jahn-Teller効果）やSn<sup>2+</sup>の孤立電子対（立体化学的活性）といった、原子（＋電子）の変位能が高い骨格元素を含んでいます。とりわけPbSnF₄において、なぜ層状構造がイオン伝導に有利なのかは、まだ十分に理解されていません。

**結論：**酸化物イオン伝導体とフッ化物イオン伝導体で最高の伝導率を示す構造は、別物ですがよく似ています。

## 20. Jahn-Teller効果とSecond-Order Jahn-Teller効果

![Jahn-Teller効果と二次Jahn-Teller効果](/learning/ionics/l2-jahn-teller-sojt.webp "左：d<sup>7</sup>, d<sup>9</sup>電子系の通常のJahn-Teller効果では、e<sub>g</sub>軌道の縮退が解けてapical方向にXが変位します。右：d<sup>0</sup>電子系の二次Jahn-Teller効果では、空のM t<sub>2g</sub>軌道と被占有のX 2p軌道が混成して結合性軌道がΔEだけ下がり、Mが中心から変位します。")

### 20.1 通常のJahn-Teller効果

#### 20.1.1 d⁷, d⁹電子系

d⁷, d⁹電子系では、±apical方向にXが変位します。軌道はe_g軌道（dx²-y², dz²）とt₂g軌道（dxy, dxz, dyz）に分裂し、エネルギー利得ΔEによる安定化が生じます。

---

### 20.2 Second-Order Jahn-Teller効果

#### 20.2.1 d⁰電子系での発現機構

d⁰電子系でSOJTが発現するための基本条件は、空のt₂g軌道（LUMO）と被占有のX 2p軌道（HOMO）があることです。混成のメカニズムは次の通りです。

**X p軌道とM t₂g軌道の準位差が小さいほど強く混成し、結合性軌道のエネルギーが低下する → SOJT発現**

#### 20.2.2 軌道準位図

軌道準位図では、エネルギー準位は上からe_g軌道、t₂g軌道、X 2p軌道（HOMO）の順に並びます。準位差ΔEが小さいほど混成が強くなり、結合性軌道のエネルギー低下が大きくなります。

## 21. 孤立電子対（Lone Pair Electron）

最外殻の5s², 6s²孤立電子対は、実空間上で非対称に局在化する傾向があります。軌道混成の観点では、これはns軌道と2p軌道がつくる反結合性軌道と、np軌道との混成軌道です。孤立電子対（lone pair）はns²電子というイメージですが、非対称な局在化はnp軌道との混成に由来します。Pb 6pは反結合性軌道（Pb 6s - O 2p）* + Pb 6p、Pb 6sは結合性軌道（Pb 6s - O 2p）に対応します。O 2p軌道と同様の相互作用を示すものとしては、Te 5p, Se 4p, S 3pやO 2pzが挙げられます。

| Tl 5s | -9.5 | Sn 5s | -10.5 | Sb 5s | -11.5 | I 5p | -7.5 |

## 22. LISICON型

LISICONは、Li superionic conductorの略です。Li₄SiO₄やLi₂.₅Al₀.₅SiO₄などがあり、同じ骨格のままキャリア量を変えることができます（固溶体の形成）。

### 22.1 固溶体の範囲

固溶体が得られる組成範囲は次の通りです。

- Li₄₊ᵧ(AlᵧSi₁₋ᵧ)O₄：0 < y < 0.4
- Li₄₊ₓSi₁₋ₓAlₓO₄：0 < x < 0.6

Li₄SiO₄からLi₂.₅Al₀.₅SiO₄へと組成を変化させることで、チャンネル構造が形成され、Liの伝導経路が開通します。

### 22.2 伝導率の組成依存性

100°Cで測定したlog(σ / S cm⁻¹)をリチウム量に対してプロットすると、Li₃SiO₄で最も低く、Li₂.₅Al₀.₅SiO₄で最も高い伝導率を示します。

**参考文献：**A. R. West著、遠藤、武田、井川、池田、伊藤、菅野 訳「ウエスト 固体化学入門」（講談社）

### 22.3 （参考）NASICON型

NASICONはNa superionic conductorの略で、NaZr₂(PO₄)₃を母体としたNa₁₊ₓZr₂P₃₋ₓSiₓO₁₂がσ = 10<sup>-4</sup> S cm<sup>-1</sup>（x = 2）を示します。Li伝導体としては同じ骨格のLiTi₂(PO₄)₃が知られています。キャリアのサイトは歪んだ6配位八面体、歪んだ8配位多面体、歪んだ10配位多面体からなり、これらが面共有で連結して伝導経路をつくります。構造は複雑で、直感的に理解するのは容易ではありません。

![NASICON型構造](/learning/ionics/l2-nasicon.webp "NASICON型構造の例です。MO<sub>6</sub>八面体（緑）とPO<sub>4</sub>四面体（青）が頂点を共有して骨格をつくり、その隙間のキャリアサイト（歪んだ6・8・10配位多面体）が面共有で連結しています。")

ここでは、硫化物の構造を理解するうえで基本となるLi₃PS₄の多形と、Li₇P₃S₁₁、LGPS型Li₉.₆P₃S₁₂を例に、硫黄の充填の仕方に注目して構造を眺めてみます。

### 23.2 Li₃PS₄の多形

Li₃PS₄には、温度によって三つの多形が存在します。低温相のγ-Li₃PS₄（Pmn2₁）は543〜647 Kでβ-Li₃PS₄（Pnma）に、さらに724〜811 Kでα-Li₃PS₄（Cmcm）に相転移します。計算による熱力学的安定性（E<sub>hull</sub>）は、γ相が0、β相が1 meV/atom以下、α相が4 meV/atom以下と、いずれも非常に近い値です。

![Li3PS4の多形と相転移](/learning/ionics/l3-li3ps4-polymorphs.webp "γ相（Pmn2<sub>1</sub>）→β相（Pnma）→α相（Cmcm）の順に高温相となります。γ相は固相法で合成でき伝導率は約10<sup>−6</sup> S cm<sup>−1</sup>、β相とα相は合成法の工夫で室温に取り出すと伝導率が大きく向上します。図中の番号は本文の参考文献に対応します。")

- **γ相**：固相法（773 K）で合成でき、σ ~ 10<sup>-6</sup> S cm<sup>-1</sup>です。DTAと高温XRDでは、昇温過程でγ→β、β→αの吸熱ピークが現れ、γ→β転移に対応して伝導率がジャンプします。一方、冷却過程ではα相から直接γ相に戻り、β相は現れません[1]。
- **β相**：液相法で合成されたナノポーラスβ-Li₃PS₄は1.6×10<sup>-4</sup> S cm<sup>-1</sup>[2]、ガラスのポストアニールでは2×10<sup>-4</sup> S cm<sup>-1</sup>[3]を示します。また、Li₃.₂₅Si₀.₂₅P₀.₇₅S₄では過剰なLiがβ相を安定化し、1.22 mS cm<sup>-1</sup>に達します[4]。
- **α相**：XRDによる初期の解析ではPbcnとされましたが[1]、後の中性子回折（NPD）でLiサイトが精密化され、Cmcmとされました[6]。ガラスを急速加熱するとα相が生成して室温で安定に存在し、圧粉体で1.3×10<sup>-3</sup> S cm<sup>-1</sup>を示します[3]。

**参考文献：**
[1] K. Homma, R. Kanno, et al., Solid State Ionics, 182, 53-58 (2011).
[2] Z. Liu, C. Liang, et al., J. Am. Chem. Soc., 135, 975-978 (2013).
[3] T. Kimura, A. Hayashi, et al., J. Am. Chem. Soc., 145, 14466-14474 (2023).
[4] L. Zhou, L. F. Nazar, et al., Chem. Mater., 31, 7801-7811 (2019).
[5] R. L. Kam, G. Ceder, et al., Chem. Mater., 35, 9111-9126 (2023).（多形の熱力学的安定性の計算）
[6] K. Kaup, L. F. Nazar, et al., J. Mater. Chem. A, 8, 12446 (2020).

#### 23.2.1 γ-Li₃PS₄：硫黄の六方最密充填

γ-Li₃PS₄は、硫黄が六方最密充填（ABAB積層）を組み、その四面体サイトをP<sup>5+</sup>とLi<sup>+</sup>が占有した構造です。四面体同士は頂点を共有し、四面体の頂点はすべてc軸のプラス方向を向いています（T+と表記）。β-Li₃PO₄（Pmn2₁）と同じ構造です。六方最密充填ABABはウルツ鉱型構造、立方最密充填ABCABCは閃亜鉛鉱型構造の骨格であり、低温相のβ-AgIもウルツ鉱型構造であることを思い出しておきましょう。

![γ-Li3PS4の結晶構造](/learning/ionics/l3-gamma-li3ps4.webp "左：c軸方向から見たγ-Li<sub>3</sub>PS<sub>4</sub>で、緑がLiS<sub>4</sub>四面体、紫がPS<sub>4</sub>四面体です。右上：一層（z = −0.05〜0.35）だけを切り取った図、右下：横から見ると四面体の頂点がすべてc軸のプラス方向（T+）を向いていることがわかります。")

実際、γ-Li₃PS₄とβ-AgI（P6₃mc）のシミュレーションXRDパターンを比べると、よく似ています。c軸は同じ向きのベクトルで、002反射が対応しています。002反射近傍の3本のピークは、Li₃PS₄では分裂しています。また、AgIの方が格子が大きいためピークは低角側にシフトし、Li₃PS₄の低角の反射はLiとPの規則配列に由来します。

![γ-Li3PS4とβ-AgIの比較](/learning/ionics/l3-gamma-li3ps4-vs-agi.webp "γ-Li<sub>3</sub>PS<sub>4</sub>（上）とβ-AgI（下）の構造とシミュレーションXRDパターンです。どちらも陰イオンの六方最密充填の四面体サイトを陽イオンが占める構造で、002反射が対応しています。下の表は、陰イオン1個あたりに換算した体積の比較です。")

#### 23.2.2 β-Li₃PS₄

β-Li₃PS₄も硫黄の（歪んだ）六方最密充填構造で、四面体サイトをP<sup>5+</sup>とLi<sup>+</sup>が、八面体サイトをLi<sup>+</sup>が占有しています。b軸とc軸の格子の取り方はγ-Li₃PS₄と同じで、a軸方向の周期が異なります。XRDパターンはβ相の方がピークが多く、15〜18°付近の2本のピークが特徴的です。

![β-Li3PS4の結晶構造](/learning/ionics/l3-beta-li3ps4.webp "左：β-Li<sub>3</sub>PS<sub>4</sub>（Pnma）の構造です。右上：γ相とβ相のシミュレーションXRDパターンの比較で、β相は15〜18°の2本のピークが特徴です。右下：a軸方向から見ると、硫黄が歪んだ六方最密充填（赤い六角形）を組んでいることがわかります。")

#### 23.2.3 α-Li₃PS₄

α-Li₃PS₄（Cmcm）はβ相の空間群Pnmaの超群にあたります。PS₄四面体ユニットがfcc的に配置し、Liは四面体サイトに入ります。硫黄の六方最密充填に積層欠陥が入ったもの、と見ることもできます。XRDパターンはβ相とよく似ており、16°付近の分裂ピークの有無でおおまかに判別できますが、怪しい解釈も散見されるので注意が必要です。

![α-Li3PS4の結晶構造](/learning/ionics/l3-alpha-li3ps4.webp "左：α-Li<sub>3</sub>PS<sub>4</sub>（Cmcm）の構造です。右：α相とβ相のシミュレーションXRDパターンはよく似ており、16°付近のピークの分裂の有無がおおまかな判別の目安になります。")

### 23.3 Li₇P₃S₁₁

Li₇P₃S₁₁（P-1、通称7311）は、ガラスセラミックスの代表例です。70Li₂S-30P₂S₅ガラスを結晶化させると得られ、σ = 3.2 mS cm<sup>-1</sup>を示します（F. Mizuno, M. Tatsumisago, et al., Adv. Mater., 17, 918 (2005)）。同じ組成でも固相反応ではLi₄P₂S₆（いわゆる426）が生成します。構造は、PS₄四面体が頂点共有でつながったP₂S₇ユニットを含む低対称構造で、XRDパターンも複雑です。ただし硫黄の並びに注目すると、Li₇P₃S₁₁も硫黄の六方最密充填（ABAB、二周期の積層）として見ることができます。

![Li7P3S11の硫黄の充填](/learning/ionics/l3-li7p3s11-hcp.webp "Li<sub>7</sub>P<sub>3</sub>S<sub>11</sub>の硫黄（黄色）を大きな球で描いた図です。上：赤い六角形で示したように硫黄が最密に並んだ層があり、下：その層が二周期で積み重なった六方最密充填（ABAB）になっています。")

Li₇P₃S₁₁は、Li₂S–P₂S₅擬二元系の探索から見いだされました。近い組成の80Li₂S・20P₂S₅で7.2×10<sup>-4</sup> S cm<sup>-1</sup>が報告され（A. Hayashi, et al., Electrochem. Commun., 5, 111-114 (2003)）、その後Li₇P₃S₁₁に到達しています。

### 23.4 LGPS型Li₉.₆P₃S₁₂

Li₉.₆P₃S₁₂（LGPS型構造、P4₂/nmc）は、四面体サイトをP<sup>5+</sup>とLi<sup>+</sup>が、八面体サイトもLi<sup>+</sup>が占有した構造です。LGPS型構造は硫黄のbcc格子をもつとされ、bcc格子中のイオン伝導が有利であることが指摘されています（Y. Wang, G. Ceder, et al., Nat. Mater., 14, 1026 (2015)）。Pを原料に用いて価数を制御した組成で、固相法ではLi₄P₂S₆とγ-Li₃PS₄になりますが、メカノケミカル処理と結晶化を組み合わせると合成できます。伝導率は1.2×10<sup>-3</sup> S cm<sup>-1</sup>（相対密度76%）です。Si, Ge, Snなどの金属元素を含まないので、負極界面でのSEI形成に対応する不可逆容量が小さいという特長があります（Y. Kato, S. Hori, R. Kanno, et al., Nat. Energy, 1, 16030 (2016)）。

一方、別の方向から眺めると、LGPS型構造は歪んだ硫黄の六方最密充填（ABAB、二周期の積層）にも見えます。

![Li9.6PS4の硫黄の充填](/learning/ionics/l3-li96ps4-hcp.webp "LGPS型Li<sub>9.6</sub>PS<sub>4</sub>（= Li<sub>9.6</sub>P<sub>3</sub>S<sub>12</sub>）の硫黄（黄色）を大きな球で描いた図です。左：横から見ると最密層が二周期で積み重なり、右：層を上から見ると赤い六角形のように歪んだ最密充填になっています。bcc格子とされる構造も、見方によってはhcpとして理解できます。")

LGPS構造の組成空間について、14族元素（Si, Ge, Sn）を含む組成はLi負極に対して不安定ですが高い伝導率を示すため、セパレータ層や正極用途に向いています。一方、15族のPはLi負極界面でLi₃Pを生成し、これが電子絶縁性かつイオン伝導性のSEIとして働くため、負極用途に向いています（Y. Kato, S. Hori, R. Kanno, Adv. Energy Mater., 10, 2002153 (2020)）。実際、硫化物固体電解質の実用上の電位窓は熱力学的な計算だけでは説明がつかず、還元生成物Li₃Pの低い電子伝導性（見かけ上3Li<sup>+</sup> + P<sup>3−</sup>のイオン結晶）がSEIとしてLi負極界面に形成され、逐次的な分解を抑制していると考えられています（Y. Zhu, X. He, Y. Mo, ACS Appl. Mater. Interfaces, 7, 23685 (2015), DOI: 10.1021/acsami.5b07517）。15族でありながら14族元素に似た形式電荷をとりうるPの低価数領域は、まだまだ未開拓です。

### 23.5 LGPS型LPSXの組成空間

Li₁₀GeP₂S₁₂（1.2×10<sup>-2</sup> S cm<sup>-1</sup>）を出発点として、Geを含まないLi–P–S–X（X = O, ハロゲン）系のLGPS型相がさまざまな置換の組み合わせで報告されています。Li<sup>+</sup> + Ge<sup>4+</sup> → P<sup>5+</sup>の置換で得られるはずのLi₉P₃S₁₂は得られておらず、P<sup>5+</sup> → Li<sup>+</sup> + P<sup>4+</sup>（または2Li<sup>+</sup> + P<sup>3+</sup>）の考え方でLi₉.₆P₃S₁₂が、さらにS<sup>2−</sup> → O<sup>2−</sup>の置換や、V_Li + V_X → Li<sup>+</sup> + X<sup>−</sup>によるハロゲンの導入で多くの組成が見いだされてきました。ハロゲンを含む組成は名目上アニオン過剰（Li_nM₃X₁₂₊δ）となり、その構造はまだ議論が続いています。

![LGPS型LPSXの組成空間](/learning/ionics/l3-lpsx-composition-space.webp "Li<sub>10</sub>GeP<sub>2</sub>S<sub>12</sub>を起点に、どのような置換でLi–P–S–X系のLGPS型相が報告されてきたかを整理した図です。各枠に組成、伝導率、合成条件（ssは固相法、BMはボールミル後の熱処理）と文献を示しています。赤字は特に伝導率の高い組成です。")

同じLi–P–S–Br–I系では、Li₇P₂S₈Iに高温相と低温相があり、低温相がLGPSライクで伝導率が高く、高温相はLi₄PS₄Iと同型で伝導率が低い（0.4〜2.1 mS cm<sup>-1</sup>）ことが報告されています。メカノケミカル処理後に160 °Cで60 h処理すると低温相、260 °Cで6 h処理すると高温相が得られ、さらにBr置換によって相転移温度が変化し、低温相の結晶性も向上します（Li₇P₂S₈Br₀.₅I₀.₅の低温相で、冷間プレス試料4.7 mS cm<sup>-1</sup>；Wang, et al., Energy Storage Materials, 19, 80-87 (2019)）。Li₁₀P₃S₁₂Br₁₋ₓIₓではx = 0.4で伝導率が最大となります（Indrawan, ACS Appl. Mater. Interfaces, 2024）。

### 23.6 最近見いだされた硫化物の例

- **Li₁.₉₇Si₀.₉₇P₀.₀₃S₃（P4₂2₁2）**：Li₂SiS₃にわずかに過剰なP<sup>5+</sup>を加えることで新規相が得られ、2.4 mS cm<sup>-1</sup>の高いイオン伝導率を示します。Si₂S₆二量体を含み、硫黄は六方最密充填（ABAB）を組んでいます（W. Huang, R. Kanno, et al., J. Am. Chem. Soc., 144, 4989-4994 (2022)）。
- **Li₂₁Ge₈P₃S₃₄**：伝導率の低いLi₂GeS₃（10<sup>-8</sup> S cm<sup>-1</sup>）を出発点に、Li₂₋ₓGe₁₋ₓPₓS₃を探索したところ、x = 0.25〜0.333で高いイオン伝導率と新規相（＋GeS₂）が現れました。GeS₂の少ない組成で合成しても依然GeS₂が残ったため、構造解析で組成を決め、Li₂₁Ge₈P₃S₃₄を同定しています。室温で10<sup>-3</sup> S cm<sup>-1</sup>級の伝導率を示します（J. Roh, S.-T. Hong, et al., Angew. Chem. Int. Ed., 64, e202500732 (2025)）。

既知の組成のまわりでも、丁寧に探せばまだ新しい相が見つかることを示す例です。

## 24. パッキングとLiの移動障壁

リチウムイオンの移動については、bcc格子の方がfcc格子よりも移動障壁が低いこと（bcc shows lower migration energy than fcc lattice for lithium-ion migration）が報告されています（Wang, Nature Materials, 14, 1026 (2015)）。移動経路はT-O-T（四面体-八面体-四面体）で、エネルギープロファイルは約0.4 eVです。fcc格子とbcc格子で移動障壁を比較することで、bcc構造の優位性が示されています。

## 26. イオン伝導体設計指針の総合まとめ

### 26.1 基本要件（「ウエスト固体化学 基礎と応用」より引用）

1. 高いキャリア数（多数の可動イオン）を有すること
2. イオンが移動可能な空孔が多数存在すること
3. 空孔及び被占有位置において、可動イオンが同程度のポテンシャルを有し、またこのサイト間の拡散経路のポテンシャル障壁が低いこと
4. 可動イオンが長距離拡散可能な、連結した可動イオンのチャンネルが存在する骨格構造を有すること
5. 骨格構造を形成するイオンが大きく分極できること

### 26.2 追加的要件

6. 骨格イオンとの静電相互作用が弱いこと
7. 骨格がbcc（body-centered cubic）パッキングであること、また玉突き的な集団運動が重要であることなど

**参考文献：**Y. Mo, et al., Nat. Mater., 14, 1026 (2015). X. He, et al., Nat. Commun., 8, 15893 (2017).

### 26.3 キャリアカチオン

| イオン種 | 室温伝導率 | 分極率 | 静電相互作用 |
|----------|------------|--------|--------------|
| Li<sup>+</sup>, Na<sup>+</sup> | σᵣ.ₜ. ≈ 10<sup>-2</sup> S cm<sup>-1</sup> | 分極率低 | - |
| Cu<sup>+</sup>, Ag<sup>+</sup> | σᵣ.ₜ. ≈ 10<sup>-1</sup> S cm<sup>-1</sup> | 分極率高 | - |

### 26.4 キャリアアニオン

| イオン種 | 特性 | 静電相互作用 |
|----------|------|--------------|
| F<sup>-</sup>, H<sup>-</sup> | σᵣ.ₜ. ≈ 10<sup>-2</sup> S cm<sup>-1</sup> | 静電相互作用弱 |
| H<sup>+</sup>, O<sup>2-</sup> | 400~600°C以上で高速拡散 | 静電相互作用強 |

### 26.5 骨格アニオン

骨格アニオンについては、伝導率がおおむね次の順になります。

σ：S<sup>2-</sup> ≥ X<sup>-</sup>（Cl, Br, I）> O<sup>2-</sup>

### 26.6 具体的な設計指針

#### 26.6.1 パーコレーション

パーコレーションの観点からは、キャリア副格子を他の元素が占有する場合、キャリアの濃度（空孔を含む）が約20〜33%以上あるかを確認します。

#### 26.6.2 骨格元素の選択

骨格元素としては、変位能の高い元素を使います。誘電体からイオン伝導体に展開された例は多く（Li<sup>+</sup>伝導体LLTOやO<sup>2-</sup>伝導体Na₀.₅Bi₀.₅TiO₃など）、誘電体をベースに元素置換するのも良さそうです。具体的には、s²電子系の孤立電子対や、八面体中心のd⁰電子系の二次Jahn-Teller（SOJT）効果を利用すると良く、孤立電子対（LP）としてはSn<sup>2+</sup>, Pb<sup>2+</sup>, Bi<sup>3+</sup>など、SOJTとしてはTi<sup>4+</sup>, V<sup>5+</sup>, Zr<sup>4+</sup>, Nb<sup>5+</sup>, Ta<sup>5+</sup>, (Sc<sup>3+</sup>)などが該当します。

#### 26.6.3 結晶構造

結晶構造の観点からは、定比組成の結晶構造に欠陥（空孔・格子間）が入りやすいか、また間隙が多いかに着目します。最密充填構造以外を選ぶ方がベターですが、最密充填構造でも構いません（大抵は他の要因の影響の方が大きいため）。

#### 26.6.4 設計の優先順位

設計の優先順位としては、誘起効果（inductive effect）は狙い通りにならない（他の要素が影響する）ことが多いので、最後に考えます。

### 26.7 全体的な設計戦略

以上をまとめると、次のようになります。

**高い分極率をもつ可動イオン・骨格イオン、弱い静電相互作用、高いキャリア（空孔・格子間）濃度、そして適切な伝導パスの形成が重要です。**

| 要因分類 | 決定要素 |
|----------|----------|
| 構成元素でおおよそ決まる | 高い分極率の可動/骨格イオン、弱い静電相互作用 |
| 結晶構造で決まる | 高いキャリア（空孔/格子間）濃度、適切なパス形成 |

これらの指針は、イオン伝導体どうしを大まかに比較する際の目安となり、幅広い材料設計に適用できます。

## 27. 材料探索と合成の実際

### 27.1 イオン伝導体探索のアプローチ

イオン伝導体の探索には、(i) 既知材料の元素置換、(ii) 構造に基づく探索、(iii) 組成に基づく探索といった、考え方の異なるいろいろなアプローチがあります。(i)ほど簡単・短期間で決定論的ですが、新規性は低くなりがちです。(iii)ほど難しく長期間を要し、材料発見は確率論的になりますが、新規性は高くなりえます。どのアプローチで良い特性が得られるかは、やってみないとわかりません。イオン伝導率の向上に有効な元素置換、構造選定、組成選定の指針（本ページの前半で述べたもの）など、過去の「攻略情報」を参考に効率的に探索しましょう。とはいえ、試行錯誤も材料探索の醍醐味です。

![イオン伝導体探索の三つのアプローチ](/learning/ionics/l2-exploration-approaches.webp "(i) 既知材料の元素置換、(ii) 構造に基づく探索、(iii) 組成に基づく探索を、難易度、時間、材料発見の性質（決定論的か確率論的か）、新規性、特性の観点で比べた図です。特性がどれで良くなるかは事前にはわかりません。")

### 27.2 伝統的な物質探索：対象の選定と網羅的合成

古典的な探索は、(1) 材料探索の対象（擬三元系など）を選び、(2) その中を網羅的に合成する、という方法です。古典的ではありますが、このように縦断爆撃的に探索することで、Cu<sup>+</sup>伝導体とLi<sup>+</sup>伝導体のそれぞれで最も高いイオン伝導率を示す材料が見いだされてきました。

- Cu<sup>+</sup>伝導体：CuCl–CuI–RbCl擬三元系の探索からRb₄Cu₁₆I₇Cl₁₃（0.34 S cm<sup>-1</sup>）が見いだされました（T. Takahashi, J. Electrochem. Soc., 126, 1654 (1979)）。
- Li<sup>+</sup>伝導体：Li₂S–GeS₂–P₂S₅系の探索から、thio-LISICON（Li₃.₂₅Ge₀.₂₅P₀.₇₅S₄、2.2×10<sup>-3</sup> S cm<sup>-1</sup>）、Li₁₀GeP₂S₁₂（1.2×10<sup>-2</sup> S cm<sup>-1</sup>）、アルジロダイト型Li₇Ge₃PS₁₂（2.5×10<sup>-4</sup> S cm<sup>-1</sup>）が見いだされています（R. Kanno, et al., J. Electrochem. Soc., 148, A742 (2001)；N. Kamaya and R. Kanno, et al., Nat. Mater., 10, 682 (2011)；Y. Inoue, et al., J. Solid State Chem., 246, 334 (2017)）。
- Li₇P₃S₁₁もLi₂S–P₂S₅擬二元系の探索から見いだされました（23.3節）。
- 電極材料では、LiCo₁/₃Ni₁/₃Mn₁/₃O₂が3d遷移金属の組み合わせの探索の中で見いだされています（T. Ohzuku, Y. Makimura, Chem. Lett., 30, 642 (2001)）。ただし、電極の網羅的探索は、デバイス評価のコストが高く評価軸も多様なため、最も難しいのかもしれません。

### 27.3 計算や予測を取り入れた探索

最近は、計算や予測を探索に組み込む例が増えています。代表例が酸ハロゲン化物LiMOCl₄（M = Nb, Ta）で、既知構造の元素置換の計算から提案されました（Y. Tanaka, et al., Angew. Chem. Int. Ed., 62, e202217581 (2023)）。LiTaOCl₄は約12 mS cm<sup>-1</sup>の伝導率を示します。

![LiMOCl4の探索の流れ](/learning/ionics/l2-oxyhalide-search-flow.webp "既知構造の価数を割り当てて同じ酸化数の元素で置換し、置換後の組成をLi–Nb/Ta–O–Clに限定したうえで、DFTによる構造最適化、E<sub>hull</sub> ≤ 50 meV atom<sup>−1</sup>による安定性の絞り込み、DFT-MDによる拡散の評価へと進みます。組成を限定する段階に、研究者の知見が効いています。")

この探索では、LiVOF₄（mp-850188）のアナログとしてLiMOCl₄（E<sub>hull</sub> = 30 meV atom<sup>-1</sup>）が提案され、DFT-MD（NVTアンサンブル、時間刻み2 fs、70 ps、各格子長10 Å以上のスーパーセル）で拡散が確認されました。全温度でD ≥ 10<sup>-5</sup> cm² s<sup>-1</sup>であり、70 psの計算ではMSD = 10<sup>-5</sup> cm² s<sup>-1</sup> × 70×10<sup>-12</sup> s × 10<sup>16</sup> Å² cm<sup>-2</sup> = 7 Å²となるので、「MSD ≥ 7 Å²」はスクリーニングの閾値の参考になります。合成はLiOH + Nb(Ta)Cl₅ → LiNb(Ta)OCl₄ + HCl（gas）の反応で、ZrO₂の5 mmボールを用いて500 rpmで40 hボールミルしています。きれいなストーリーですが、論文には書かれない試行錯誤もあったのかもしれません。

その後、Li₃Ta₃O₄Cl₁₀が13.7 mS cm<sup>-1</sup>を示すことが報告されました（F. Zhao, et al., Science, 2025）。発見の経緯は明記されていませんが、LiTaOCl₄の合成の最適化と構造解析を経てこの組成にたどり着いたのではないかと考えられます。また、LiNbOCl₄では、骨格の柔軟性と不規則性が高いイオン伝導率に重要であることが報告されており（B. Singh, L. F. Nazar, et al., J. Am. Chem. Soc., 146, 17158-17169 (2024)）、明示はされていないものの、二次Jahn-Teller的なダイナミクスが関わっているように見えます。

ハロゲン化物Li<sup>+</sup>伝導体の流れも振り返っておきます。1970〜1980年代にLiM₂Cl₄（~10<sup>-6</sup> S cm<sup>-1</sup>）、1990〜2000年代にLi–M–Br系（10<sup>-3</sup> S cm<sup>-1</sup>）が報告され、2018年にLi₃YCl₆, Li₃YBr₆が報告されて再び注目を集めました（T. Asano, et al., Adv. Mater., 30, 1803075 (2018)）。X線構造解析だけではLiサイトの精密化が難しいため、BVEL（bond-valence energy landscape）のエネルギー極小点からLiの平衡位置を、そのつながりから拡散経路と移動障壁を議論しています。アレニウスプロットの変曲はLi副格子の秩序–無秩序変化に対応し、アニオン副格子の無秩序化がLi副格子の無秩序化を低温化させることも指摘されています（S. Wang, Y. Mo, et al., Angew. Chem. Int. Ed., 62, e202215544 (2023)）。

ほかにも、結晶構造予測とE_hullの予測からY–Sr–Ca–Ga–O系で新規相を2種見いだした例（C. Collins, M. J. Rosseinsky, et al., Nature, 546, 280-284 (2017)）があり、Rosseinskyらのレビュー（D. Antypov, M. J. Rosseinsky, et al., Acc. Chem. Res., 58, 1355-1365 (2025)）では「結晶構造予測はあくまでツールであり、真の構造を出力しない可能性もあるが、特定組成に安定構造が存在することの示唆を与える」と述べられています。我々も、組成からイオン伝導率を予測して擬三元系を選び、フッ化物イオン伝導体（BaSn系タイソナイト）やヒドリドイオン伝導体の探索に取り組んでいます（N. Matsui, R. Kanno, et al., ACS Appl. Energy Mater., 6, 11663-11671 (2023)；T. Hirose, N. Matsui, R. Kanno, et al., Science, 389, 1252-1255 (2025)）。

### 27.4 原料の混合・粉砕

ボールミルは、試料の粉砕、アモルファス化、メカノケミカル合成に使います。目的は大きく三つで、原料粉末を微細化して反応を促進する（原子の拡散距離が短くなり、低温化や短時間での反応が可能になる）こと、アモルファスを合成してポストアニールによる結晶化で準安定相を狙うこと、高エネルギーで操作して直接結晶相を合成する（メカノケミカル合成）ことです。

![ボールミルの条件の目安](/learning/ionics/l3-ball-milling.webp "ポットとボールの材質はZrO<sub>2</sub>やWCです。容積の1/3を粉末、1/3をボールとし、通常は2〜3 g程度の試料と10 mmφのボール18個程度を使います。ボールが小さいほどアモルファス化しやすく、大きいほど衝突エネルギーが高くなり、メカノケミカル的に結晶相が生成することもあります。")

試料が少なすぎるとZrO₂がコンタミするため、特に高回転数の場合は最低1 gは必要です。アモルファス化の目安は380 rpm以上、3 mmφ以下のボールです。均質に混合するには、事前に乳鉢で5分以上混合しておくと良く、面倒ならポット内で粉末だけをスパチュラで軽く混ぜてから、100 rpm程度で30分混合する方法もあります。

### 27.5 焼成と焼成温度の決め方

硫化物を例にすると、焼成はペレットに成型してガラス管に真空封入（~10 Pa）して行います。耐熱温度の目安はパイレックスで~550 °C、石英で~1000 °Cです（切断面が青〜緑色ならパイレックス、完全に無色なら石英）。通常は、試料と管との反応を防ぐためにカーボンコートやカーボンるつぼを用います。密閉系の合成なので、揮発成分の蒸気圧は合成温度で規定され、開放系のような逐次的な揮発は防げます。Arフロー合成は合成量が多いのが魅力ですが、ガス中の微量酸素が常に供給されるうえ、開放系で高温では揮発による組成ずれが起こりやすいため、探索では基本的に使いません。硫化物の合成雰囲気は生成相にシビアに影響するので、容器やるつぼの事前乾燥は必須で、到達真空度も重要です。

![焼成条件の決め方](/learning/ionics/l3-firing-dta-flow.webp "左：ボールミル（BM）で得たアモルファス試料と、手混合（Handmix）した混合原料のそれぞれでDTAを測定し、結晶化温度や相転移・溶融温度を確認します。右：その結果から、BM＋低温アニール、通常の固相反応＋徐冷、高温相を室温に残すためのクエンチといった焼成条件を決めます。")

図の右側の焼成条件について補足します。BM＋低温アニールでは、アモルファスからの結晶化によって、通常の固相反応では得られない相が得られることがあります（ガラスセラミックスと呼ばれることもありますが、ここではあくまで「アモルファス原料のアニールで得られる結晶相」と呼びます）。高温相をクエンチで室温に安定化できるのは、キャリアイオン以外の原子の拡散による（拡散律速の）相変化の場合で、急冷で拡散を凍結できます。一方、原子のわずかな変位による相変化は、クエンチでは止められません。

DTAの使い方としては、アモルファス試料の昇温で結晶化（発熱）温度を確認できますが、これは熱力学的な状態図には対応しない可能性があります。熱力学的に安定な室温安定相については、昇温（冷却）過程の吸熱（発熱）ピークから高温相転移や溶融を判断し、状態図を理解します。温度はピークトップではなく立ち上がり温度（ベースラインとの交点を線形フィッティングで求める）で読みます。溶融温度まで測ってみるのも有効ですが、むやみに高温まで測ると破裂の危険があるので、近い組成を参考にしましょう。アンプルに真空封入して測定すると、揮発を抑えられ大気下でも測定できますが、重量変化は測定できません。新規組成であれば、まずDTAを測定することで焼成条件を決められます。迷ったら、アモルファス試料と500 °C焼成品の二種で測定しておくと良いでしょう。

DTAの代わりに高温XRDを使うと、合成に対応した相とその生成温度が直接得られます。見栄えが良く論文の図としてもおすすめですが、温度制御は大まかで、放射光で測定する場合は測定の機会が限られます。

### 27.6 研究の進め方

理論や背景をしっかり把握して議論することは大切ですが、詳細な理論にこだわりすぎて大域的な目的を忘れないようにしましょう。"Done is better than perfect"（Mark Zuckerberg）を意訳すれば、「多分うまくいくから実装（実験）してみよう」「とにかく実装（合成）、理論・精度は二の次」となります。電池特性や材料特性の向上といった大域的な目的の達成には、実験的な試行錯誤が必須です。

![理論と試行錯誤のバランス](/learning/ionics/l2-theory-vs-trial.webp "研究時間に対する目的特性の伸びのイメージです。理論だけにこだわる（赤）と成果が出るまでに時間がかかり、試行錯誤だけ（青）でも伸び悩む時期が長くなりがちです。必要最小限の理論と実装を組み合わせる（黒）と、早く目的特性に近づけるというイメージです。")

情報過多の時代に、初心者が自力で情報の取捨選択をするのはほぼ無理です。有識者に積極的に質問・雑談・議論するのが手っ取り早く、その議論を手がかりに自分で深掘り・横展開していきましょう。
