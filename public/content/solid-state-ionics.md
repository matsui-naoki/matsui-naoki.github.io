# イオン伝導体の基礎と設計指針：詳細解説 (工事中)

## 1. イオン伝導体の基本概念

### 1.1 イオン伝導体とは

固体中のイオンは、有限温度では平衡位置を基点に熱振動しています。絶縁体の場合、イオンはこの熱振動をするだけで平衡位置に留まります。一方、イオン伝導体の場合はイオンが平衡位置から移動することができます。ただし、イオンが動くためには欠陥が必要です。

### 1.2 基本的な電気伝導の式

イオン伝導率は以下の基本式で表されます。

**σ = zecμ**

ここで：
- σ：イオン伝導率 [S cm<sup>-1</sup>]
- z：電荷数
- e：電気素量
- c：欠陥（キャリア）濃度
- μ：移動度（mobility）

移動度にはアインシュタイン関係式

**μ = zeD/kT**

が成り立つので、これを基本式に代入すると

**σ = (ze)²cD/kT**

が得られます。さらに、拡散係数の温度依存性は

**D = D₀ × exp(-E_mig/kT)**

と書けるため、最終的にイオン伝導率は次のアレニウス則に従います。

**σ = σ₀/T × exp(-E_a/kT)**

## 2. 欠陥の種類と特性

### 2.1 内因性欠陥（Intrinsic Defect）

内因性欠陥とは、「有限温度で生じる、自身で完結する（系外物質とやりとりの無い）反応」により生成する欠陥です。

#### 2.1.1 Frenkel欠陥の詳細メカニズム

Frenkel欠陥の基本反応では、まず①イオンが格子間位置に移動して空孔を生成します。続いて、②隣接イオンがその空孔位置に移動するか、③格子間イオンが隣の格子間位置へ移動します。この②または③（もしくは両方）によりイオンが移動します。なお、アニオンのFrenkel欠陥はAnti-Frenkel欠陥とも呼ばれます。

#### 2.1.2 Schottky欠陥の詳細メカニズム

Schottky欠陥の基本反応では、①正負のイオン対の空孔が生成し、②隣接イオンがその空孔位置に移動することでイオンが移動します。

### 2.2 内因性欠陥を利用したイオン伝導の詳細

#### 2.2.1 活性化エネルギーの内訳

イオン伝導に要するエネルギー（活性化エネルギー）は、次のように書けます。

**E_a = (1/2)E_f + E_mig**

ここで：
- E_f：欠陥形成エネルギー（defect formation energy）
- E_mig：移動エネルギー（migration energy）

すなわち、平衡位置と隣接平衡位置の間にはE_migの障壁があり、さらに欠陥の形成にE_fのエネルギーが必要となります。なお、E_fの係数は欠陥様式により異なります（はず）。

#### 2.2.2 欠陥濃度の詳細計算

欠陥濃度には次の関係式が成り立ちます。

**C_i × C_v = N × exp(-E_f/kT)**

電気的中性条件から **C_i = C_v** が成り立つため、

**C_v = √N × exp(-E_f/2kT)**

となります。イオン伝導率を導出するには、基本式

**σ = zecμ**

にEinstein方程式

**μ = zeD/kT**

を代入して

**σ = (ze)²cD/kT**

とし、さらに拡散係数

**D = D₀ × exp(-E_mig/kT)**

を用います。最終的に

**σ = (ze)²C_vD₀/kT × exp(-(E_f/2 + E_mig)/kT)**

**σ = σ₀/T × exp(-E_a/kT)** （アレニウス則）

が得られます。

#### 2.2.3 アレニウスプロットの詳細解析

アレニウスプロットでは、縦軸に log(σT / S cm<sup>-1</sup>)、横軸に 1000 T<sup>-1</sup> / K<sup>-1</sup> をとります。高温領域では内因性欠陥濃度が優勢となり、欠陥濃度は c ≈ exp(-E_f/kT)、伝導率は σ ≈ exp(-(E_f/2 + E_mig)/kT) となるため、プロットの傾きは E_mig + E_f/2 に対応します。一方、低温領域では外因性欠陥濃度が優勢となり、c ≈ const.（温度依存なし）、σ ≈ exp(-E_mig/kT) となるため、傾きは E_mig に対応します。

重要な点として、完全結晶は実在せず、微量の外因性欠陥が大抵含まれるので、低温側では制御しきれない微量な外因性欠陥（濃度一定）にキャリア濃度・イオン伝導率が支配されます。

### 2.3 外因性欠陥（Extrinsic Defect）の詳細

#### 2.3.1 具体例：Mg<sup>2+</sup>O<sup>2-</sup>結晶格子

例1として、高価数元素による置換を考えます。

**Mg²⁺ + Mg²⁺ → □ + Zr⁴⁺**

Mg<sup>2+</sup>をZr<sup>4+</sup>で置換すると、もうひとつのMg<sup>2+</sup>を空孔にでき、**Mg空孔（vacancy）**が生成します。

例2は、低価数元素による置換です。

**Mg²⁺ + Mg²⁺ → Na⁺ + Na⁺ + Mg²⁺_int**

2個のMg<sup>2+</sup>をNa<sup>+</sup>で置換すると、Mg<sup>2+</sup>を1個格子間に導入でき、**格子間Mg（interstitial）**が生成します。

#### 2.3.2 電気的中性条件（Electric Neutrality）

Pauling's second lawにあるように、局所的電気中性を満たす形で、大抵は近接サイトで電荷補償されます。

### 2.4 外因性欠陥を利用したイオン伝導の詳細

#### 2.4.1 基本特性

外因性欠陥の場合、格子欠陥濃度cは異価数元素置換濃度で規定され、温度によらず一定です。基本式

**σ = zecμ**

にEinstein方程式

**μ = zeD/kT**

を代入すると

**σ = (ze)²cD/kT**

となり、拡散係数

**D = D₀ × exp(-E_mig/kT)**

を用いると、最終的に

**σ = (ze)²D₀/kT × exp(-E_mig/kT)**

**σ = σ₀/T × exp(-E_a/kT)** （アレニウス則）

が得られます。

#### 2.4.2 アレニウスプロットの詳細

この場合のアレニウスプロットは、三つの温度領域に分かれます。高温領域では内因性欠陥濃度が優勢となり、欠陥濃度は c ≈ exp(-E_f/kT)、σ ≈ exp(-(E_f/2 + E_mig)/kT) で、傾きは E_mig + E_f/2 です。中温領域では、異価数元素置換で規定される外因性欠陥濃度が支配的となります。たとえ数%であっても幅広い温度で優勢なキャリア濃度となり、c ≈ const.（温度依存なし）、σ ≈ exp(-E_mig/kT) で、傾きは E_mig（+ E_as）です。低温領域ではコンタミレベルの外因性欠陥（極微量）が効いてきて、傾きは E_mig + E_f/2 となります。

重要な注記として、異価数元素置換の場合はドーパント-キャリア間の静電相互作用が働いて会合（キャリアトラップ）が発生するため、会合エネルギー（E_as）が活性化エネルギーに含まれることもあります。

## 3. 欠陥の表記方法：Kröger-Vink記法

### 3.1 基本記号

格子欠陥の記述手法として以下の記号を使用します。

| 記号 | 意味 |
|------|------|
| V | 格子空孔（vacancy） |
| i | 格子間（interstitial） |
| e | 伝導電子 |
| h | 正孔（hole） |
| × | 電気的中性 |
| ● | 正電荷 |
| ' | 負電荷 |

### 3.2 具体的な反応式例

**Case 1: BaF₂ + LaF₃ → Ba₀.₉La₀.₁F₂.₁**

Ba<sup>2+</sup>をLa<sup>3+</sup>で置換すると、格子間F<sup>-</sup>が生成します。

**Ba×_Ba + V×_i + LaF₃ → La●_Ba + F'_i + BaF₂**

このとき、正に帯電したドーパントと負に帯電した格子間Fの間に静電相互作用（Coulombic interaction）が働きます。

**Case 2: BaF₂ + KF → Ba₀.₉K₀.₁F₁.₉**

Ba<sup>2+</sup>をK<sup>+</sup>で置換すると、F<sup>-</sup>空孔が生成します。

**Ba×_Ba + F×_F + KF → K'_Ba + V●_F + BaF₂**

このとき、負に帯電したドーパントと正に帯電したF空孔の間に静電相互作用（Coulombic interaction）が働きます。

Kröger-Vink記法の利点は、欠陥の形式電荷を明示的に表記することで、電気的中性条件や静電相互作用を議論する際に便利なことです。

## 4. 異価数元素置換の勘所

### 4.1 基本原理の詳細解析

Ba<sup>2+</sup>F<sup>-</sup>₂結晶格子のF<sup>-</sup>欠陥導入を例に考えます。

#### 4.1.1 三つの重要原則

異価数元素置換を考える上では、第一に欠陥がキャリアとなること、第二に欠陥は局所的に束縛されていること（ドーパントとの静電相互作用や局所ひずみ）、第三に欠陥の束縛が弱いほど欠陥が動きやすいこと、という三つの重要原則があります。

#### 4.1.2 設計指針の詳細

まず、格子間と空孔のどちらが動きやすいかは材料系に依存します。次に、欠陥の電荷は低い方が動きやすくなります。これは F = ε q₁q₂/r² で表されるように、電荷が小さい方が静電引力が弱いためです。例えばBa<sup>2+</sup>のLa<sup>3+</sup>置換（+1）より、Hf<sup>4+</sup>置換（+2）の方が格子間F<sup>-</sup>を強く束縛して、F<sup>-</sup>が動けなくなります。さらに、ホスト格子（Ba<sup>2+</sup>）とドーパント（M<sup>3+</sup>, M<sup>+</sup>）のイオン半径差が小さいほど、局所ひずみが小さくF欠陥が動きやすくなり、また構造変形が小さいため多量に置換（欠陥ドープ）できます。

結論として、ドーパントとホストイオンは、イオン半径が近く±1価の異価数元素置換を選ぶことで、高ドープ（キャリア濃度高）の可能性が高く、欠陥（キャリア）の束縛も弱く、イオン伝導率向上が期待されます。

### 4.2 置換量依存性の詳細解析

#### 4.2.1 典型的な伝導率のドーパント依存性

よく使われる図として、イオン伝導率と活性化エネルギーの元素置換量依存性があります。

| 領域 | 異価数元素濃度 | 特徴 | 活性化エネルギー | 説明 |
|------|----------------|------|------------------|------|
| ① | 0 mol% | 異元素置換無し | E_mig + E_f | 外因性欠陥が（ほとんど無い）ので、内因性欠陥を使う必要があり、その欠陥生成エネルギー（E_f）が活性化エネルギーに含まれる |
| ② | 数mol% | 希釈な異元素置換 | E_mig | イオン輸送に使われる欠陥の濃度は外因性欠陥濃度で決まり（温度によらず一定）、活性化エネルギーは、おおよそ移動エネルギー（E_mig）に相当する |
| ③ | 10mol%～ | 高濃度の異元素置換 | E_mig + E_as | 高濃度ドーパントとの静電相互作用による会合（association）の形成エネルギー（E_as）が活性化エネルギーに含まれる |
| ④ | 高濃度 | 減少幅小 | なだらかな減少 | キャリア濃度は異元素置換濃度により単調に増加するため、高濃度領域での伝導率低下はE_a増加よりなだらか（会合によるE_a増加とキャリア濃度増加の部分相殺） |

このグラフでは、イオン伝導率は極大を持つ山型を示し、活性化エネルギーは最初急激に減少した後に増加します。

## 5. イオン移動の素過程の詳細

### 5.1 移動障壁（E_mig; Migration Energy）の詳細

#### 5.1.1 二次元格子中の格子間原子の移動

**参考文献：**小岩昌宏、中嶋英雄、材料における拡散 格子上のランダム・ウォーク、内田老鶴圃 (2009)

基本概念として、イオンは最も低いエネルギーの反応経路を通過し、その反応経路上のエネルギー極大を示す空間座標を「鞍点（Saddle point）」と呼びます。このときの移動障壁がE_mです。

### 5.2 遷移確率と拡散係数の詳細

#### 5.2.1 基本パラメータ

原子の振動数はDebye Frequency ≈ 10<sup>13</sup> s<sup>-1</sup>（= 0.1 ps周期）程度であり、このDebye周波数で試行頻度ν₀を近似します。遷移確率は、安定位置から遷移状態のエネルギー差をE_migとすると、遷移状態にある確率 exp(-E_mig/kT) で与えられます。したがって、1秒あたりに原子が遷移する頻度は

**ν = ν₀ exp(-E_mig/kT)**

となり、拡散係数の最終式は

**D = ad²ν = D₀ exp(-E_mig/kT)**

と表されます（aは隣接サイト数等で決まる係数）。重要な点として、原子の存在確率密度分布 ρ(x,y,z) / atom Å<sup>-3</sup> が解れば、相対エネルギーE_migが求まります。

## 6. Kinetic Monte Carlo（KMC）手法の詳細

### 6.1 基本概念と定義

モンテカルロとは、ランダムサンプリングのことです。モンテカルロが含まれる手法は色々あり、例えばランダムサンプリングにより実測値を再現するモデルを探索する逆モンテカルロや、レプリカ交換モンテカルロなどが挙げられます。

### 6.2 詳細な計算手順

#### 6.2.1 各移動先への遷移確率

4つの隣接サイトE₁, E₂, E₃, E₄がある場合を考えます。

**E₁を乗り越える確率：P₁ = exp(-E₁/kT)**

**E_iを乗り越え進む確率：P_i = exp(-E_i/kT) / Σᵢ exp(-E_i/kT)**

#### 6.2.2 シミュレーション詳細

単位時間あたりのホッピング頻度はDebye Freq. ν₀ = 10<sup>13</sup> s で近似します。シミュレーションでは、各時間ステップ（1/ν₀ = 0.1 ps）ごとに隣接サイトへ移動するか否かを確率論的に選択し、移動する場合は隣接サイトへ移動して変位量dᵢを獲得します。

#### 6.2.3 拡散係数の算出

平均二乗変位と時間から D = MSD/6t として拡散係数を算出し、キャリア濃度からNernst-Einstein式でイオン伝導率を計算します。

### 6.3 実用例：softBVソフトウェア

例えばsoftBVソフトウェアでは、Eや遷移経路、格子間サイトが求まるため、それらをノード、経路をエッジとして、格子間サイトを経由したパスも加味したKMCを実行できます。

**参考文献：**H. Chen, L. L. Wong, S. Adams, Acta Crystallographica Sec. B, 75 (1), 18 (2019).

格子緩和やイオン相関を無視したラフな計算方法ではありますが、拡散の次元性や伝導率の絶対値の相対比較として便利です。

## 7. 拡散係数の導出と物質拡散の詳細

### 7.1 一次元ランダムウォークの詳細解析

#### 7.1.1 なぜ単位が二乗距離？：D (cm² s<sup>-1</sup>)

一次元のランダムウォーク（酔歩）を次のように設定します：
- p(+1) = 0.5，p(-1) = 0.5
- 左移動回数 nₗ，右移動回数 nᵣ
- 正味の右方向回数 m = nᵣ - nₗ
- 単位移動距離 d = 1
- 正味の移動距離 x = md

#### 7.1.2 統計的解析

移動距離xの平均値は

**⟨x⟩ = ∫_{-∞}^{∞} xW(x,t)dx = 0**

となります。平均移動距離は0となるため、どれだけ変位したかは分かりません。そこで、拡散により粒子がどれくらいの距離を動いたか（どの程度分布が広がったか）を知るには、二乗変位x²の平均値を用います。

**⟨x²⟩ = ∫_{-∞}^{∞} x²W(x,N)dx = 2Dt**

#### 7.1.3 確率分布関数

時間tにxにいる確率W(x,t)は次式で与えられます。

**W(x,t) = 1/(2√πdt) exp(-x²/4Dt)**

#### 7.1.4 粒子のジャンプ統計

粒子が単位時間あたりν回ジャンプするとき、時間tにわたる総ジャンプ数は N = νt となり、D = νd²/2 が得られます。

### 7.2 多次元への拡張

| 次元 | 拡散係数の関係式 |
|------|------------------|
| 一次元 | D = ⟨x²⟩/2t |
| 二次元 | D = ⟨r²⟩/4t |
| 三次元 | D = ⟨r²⟩/6t |

**参考文献：**小岩昌宏、中嶋英雄、材料における拡散 格子上のランダム・ウォーク、内田老鶴圃 (2009)

### 7.3 Fickの法則の詳細

#### 7.3.1 Fickの第一法則（定常状態の拡散）

**J = -D ∂c/∂x**

物質の拡散流束は濃度勾配に比例します。

パラメータ定義：
- J：流束（単位時間当たりの単位面積を通過する粒子数）[mol/m² s]
- D：拡散係数 [m²/s]
- c：粒子濃度 [mol/m³]

#### 7.3.2 外場印加時の修正

外場により一方向に駆動される粒子の流束は、速度v [m/s]と粒子濃度c [mol/m³]を用いて vc [mol/m² s] と書けます。これを加えた修正された式は

**J = -D ∂c/∂x + cv**

となり、定常状態では流束J = 0となるため

**D ∂c/∂x = cv**

が成り立ちます。

#### 7.3.3 Fickの第二法則（非定常状態の拡散）

**∂c/∂t = D ∂²c/∂x²**

この式は、拡散による濃度分布の時間発展を記述します。

### 7.4 Nernst-Einstein方程式の詳細導出

#### 7.4.1 ボルツマン分布と力の関係

外場による原子のポテンシャルをφ(x)とすると、イオン分布はボルツマン分布で表現されます。

**c(x) = const. exp(-φ(x)/kT)**

両辺を微分すると

**dc/dx = -c dφ/kT dx**

となります。原子にかかる力（駆動力）Fはポテンシャルφ(x)の位置微分

**F = -dφ/dx**

ですから、したがって

**dc/dx = cF/kT**

が得られます。

#### 7.4.2 流束の平衡条件

外場駆動の拡散と、それを打ち消し合う濃度勾配駆動の拡散流（Fickの第一法則）が釣り合うとき

**D ∂c/∂x = cv**

であり、流束は

**J = cv = D cF/kT**

となります。

#### 7.4.3 電場印加時

外場Eにより電荷qが受ける力は

**F = qE**

ですから、流束は

**J = cv = Dcq/kT E**

となり、電流密度は電荷×流束として

**i = qJ = q²cD/kT E**

と書けます。

#### 7.4.4 最終的なNernst-Einstein方程式

**σ = q²cD/kT**

**参考文献：**小岩昌宏、中嶋英雄、材料における拡散 格子上のランダム・ウォーク、内田老鶴圃 (2009)

## 8. トラッピング現象の詳細

### 8.1 歴史的背景と定義

トラッピングは現象としてなんとなく認識されていましたが、プロトン伝導体で明確に提唱されて以降、プロトン界隈で盛んに議論されている印象です。

**参考文献：**Y. Yamazaki, et al., Nat. Mater., 12, 647 (2013).

### 8.2 基本概念

トラッピングの原因は何かしらの束縛、例えばドーパントと欠陥の静電相互作用などです。エネルギー図で考えると、通常のエネルギー障壁Eに加えて、トラップによる追加エネルギーE_Bが存在します。

### 8.3 滞留時間の詳細計算

#### 8.3.1 基本パラメータ

基本パラメータとして、正規位置の滞在時間t_n、トラップ位置の滞在時間t_T、トラップ濃度cを定義します。粒子のN回ジャンプ（同じ移動距離）に要する時間を、トラップ無しの場合t_U、トラップ有りの場合t'_Uとすると、同じ移動距離のため次の関係式が成り立ちます。

**Dt_U = D't'_U**

#### 8.3.2 滞留時間の計算

粒子の滞留時間は、配位数（そこへジャンプしうる近接サイト数）zと振動因子ν₀を用いて次式で表されます。

**t_n = (zν₀)⁻¹ exp(E/kT)**

**t_T = (zν₀)⁻¹ exp((E + E_B)/kT)**

#### 8.3.3 総滞留時間

総滞留時間は次のようになります。

**t_U = Nt_n**

**t'_U = N[(1-c)t_n + ct_T]**

### 8.4 みかけの拡散係数の導出

みかけの拡散係数は次式で与えられます。

**D' = D × 1/[(1-c) + c exp(E_B/kT)]**

### 8.5 温度依存性

温度依存性としては、低温では E_a = E + E_B、高温では E_a = E となります。

### 8.6 一般的適用性

キャリアが点欠陥の場合、いかなるイオン伝導種でも共通してトラッピングは存在するはずです。ただし、欠陥が高濃度かつ不規則分布した構造欠陥系では、トラッピング状態の定義が曖昧なため、それほど議論されていません。

**参考文献：**小岩昌宏、中嶋英雄、材料における拡散 格子上のランダム・ウォーク、内田老鶴圃 (2009)

## 9. ブロッキング効果とパーコレーションの詳細

### 9.1 ブロッキング効果の定義

ブロッキング効果はイオン伝導体でも共通の概念ですが、このフレーズで使われることは少ないようです。

#### 9.1.1 基本式

ブロックサイト濃度cの時の拡散係数は次式で表されます。

**D_b(c) = D(1 - bc)**

ここでbは、副格子の次元/連結数で決まるブロッキング係数です。

#### 9.1.2 次元依存性

低次元（1）拡散ほどブロッキングが無限拡散を妨げ、高次元（2-3）拡散であれば迂回可能です。例えば正方格子であれば、c = 0.5で無限拡散を妨げる（D_b(c) = 0）ので b = 2 となります。

#### 9.1.3 配位数効果

配位数が高いほどブロッキング効果は低くなり、c = 0.78以上で無限拡散不可となります。

**参考文献：**小岩昌宏、中嶋英雄、材料における拡散 格子上のランダム・ウォーク、内田老鶴圃 (2009)

---

### 9.2 実例：Li₁₀GeP₂S₁₂でのブロッキング効果

Li₁₀GeP₂S₁₂において、人工的にab面内拡散経路のLiを固定化すると、自己拡散係数は0になります。ただし重要な点として、自己拡散係数が0であることはイオン伝導率が0であることを意味しません。あくまでMDで観測される一次元経路の自己拡散係数が0になるということであり、面内拡散経路の中間サイトへの遷移を経る一種の活性化過程（フレンケル欠陥生成）が無限拡散に必須とも言えます。

**参考文献：**K. Miwa, R. Asahi, Solid State Ionics 361 (2021) 115567

---

### 9.3 パーコレーション理論の詳細

#### 9.3.1 基本概念

8×8正方格子での例を考えます。原子は格子点から隣接格子点へ移動し、ブロッキングサイトの濃度がマクロな輸送特性を決めます。例1として14/64がブロックされた場合、通過可能サイトは78%となり、パーコレートします。例2として28/64がブロックされた場合、通過可能サイトは56%となり、パーコレートしません。

#### 9.3.2 詳細なパーコレーション閾値

56%の通過可能サイトではパーコレートしなかったことから、通過可能サイトは59%以上必要となります。

#### 9.3.3 パーコレーション閾値の理論値

| 次元 | 格子 | 配位数 | P(0,1) | 回帰確率 p_r | 正味訪問点 S_n | 臨界浸透確率 p_c(s) |
|------|------|--------|--------|--------------|----------------|---------------------|
| 1 | 直線 | 2 | ∞ | 1 | ~(8n/π)^{1/2} | 1 |
| 2 | 正方 sq | 4 | ∞ | 1 | ~πn/log n | 0.593 |
| 3 | 単純立方 sc | 6 | 1.51638 | 0.3405 | ~0.659n | 0.311 |
| 3 | 体心立方 bcc | 8 | 1.39320 | 0.2822 | ~0.717n | 0.246 |
| 3 | 面心立方 fcc | 12 | 1.34466 | 0.2563 | ~0.743n | 0.198 |
| 3 | 最密六方 hcp | 12 | 1.34466 | 0.2563 | ~0.743n | 0.204 |

**結論：**パーコレーションの閾値は、キャリア副格子の次元と隣接サイト数で決まります。

**参考文献：**小岩昌宏、中嶋英雄、材料における拡散 格子上のランダム・ウォーク、内田老鶴圃 (2009)

---

### 9.4 実例：Li₀.₃₈₈Ta₀.₂₃₈La₀.₄₇₅Cl₃

Li₀.₃₈₈Ta₀.₂₃₈La₀.₄₇₅Cl₃は3.0 mS cm<sup>-1</sup>の伝導率を示します。LaCl₃へのLi置換により伝導率が向上し、Li濃度が0.25以上で、Li channelとLa空孔を介した3Dパスを形成します。この材料は[LaCl₉] tricapped trigonal prism構造からなり、Li<sup>+</sup>イオンは**Li1 (channel sites)とLi2 (La-vacancy sites)**に配置されます。上下2 + 面内6方向の移動先と仮定すると、パーコレーションの閾値は約25%となり、イオン伝導率の報告範囲（Li₀.₂₅）と対応します（bccではないが、8配位を参考に…）。

結論として、骨格元素がキャリアと同サイトを占有する場合、パーコレーションの閾値に注意しましょう。

**参考文献：**Y. Yin, et al., Nature, 616, 77 (2023)

---

### 9.5 実例：パイロクロア型Li₂₋ₓLa₍₁₊ₓ₎/₃M₂O₆F

パイロクロアAB₂O₆Fで極めて高いイオン伝導率が報告されました（Li₁.₂₅La₀.₅₈Nb₂O₆F：bulk 7mS cm<sup>-1</sup>）。我々も以前この系に取り組んでいましたが（LiSrNb₂O₆F：1.1 × 10<sup>-3</sup> mS cm<sup>-1</sup> at 673 K. J. Jpn. Soc. Powder Powder Metall. 2018, 65, 26−33.）、伝導率が低く、深掘りしませんでした。

では、なぜ伝導率がこんなにも違うのでしょうか。その答えは、サイトのLi濃度がパーコレーションするためには足りなかったこと、そしてブロッキング効果のあるSr濃度が高すぎたことにあります。

**結論:パーコレーションの閾値は大事**

**参考文献：**A. Aimi, S. Yoshida, et al., Chem. Mater. 2024, 36, 3717−3725

---

### 9.6 実例：正極材料オリビン型LiFePO₄

オリビン構造（空間群：Pnma）は、FeO₆八面体とPO₄四面体の骨格からなり、P-O結合が強固で構造安定性が高く、リチウムの一次元チャンネルを持ちます。反応は LiFePO₄ ⇄ FePO₄ + Li⁺ + e⁻ です。

b軸方向のLiチャンネルでは、1Dチャネル中の欠陥で挟まれたLiは動けません。その例としてLiとFeのanti-site欠陥があり、ブロッキングにより利用出来ない容量割合は、おおよそ粒子サイズに対応します。結論として、粒子径減少により1D経路中の充放電に利用可能なLiサイト割合が増えます。

**参考文献：**R. Malik, G. Ceder, et al., Nano Lett. 2010, 10, 4123–4127

## 10. 混合効果

### 10.1 基本概念

骨格金属元素を混合すると、伝導率が向上します。

#### 10.2 具体例：Li₄SiO₄系

Li₄SiO₄系では、計算から複数種のカチオンを混ぜると伝導率が向上するとの報告があります。

**参考文献：**Y. Deng, C. Masquelier, M. Saiful Islam, et al., ACS Appl. Mater. Interfaces 9, 7050 (2017).

---

### 10.3 ハイエントロピー効果

ハイエントロピーは、ここ2-3年のバズワードです。

配置エントロピー：**S_conf = -R Σ_{k=1}^n c_k ln(c_k)**

c_k：k-thサイトの濃度

混合エントロピー：**S_mix = -R Σ_{i=1}^m c_i ln(c_i) - R Σ_{j=1}^n c_j ln(c_j)**

- c_i：i-thのアニオン種の濃度
- n：アニオン種の数
- c_j：j-thのカチオン種の濃度
- n：カチオン種の数

結論として、色々と混ぜると良いのですが、そんなに単純でもありません。

**参考文献：**Xueliang Sun, et al., Adv. Mater., 2501544 (2025).

---

### 10.4 多元系展開での注意点

#### 10.4.1 キャリアサイトの多元化

キャリアサイトを多元化する場合、同じ結晶学サイトを占有するとブロッキング効果が出ます。そのため、大きく性質の異なる多元化で特異点を探すべきです（Ag<sup>+</sup>, Cu<sup>+</sup>導電体のRb<sup>+</sup>など）。

#### 10.4.2 骨格元素の多元化

骨格元素を多元化する場合は、電荷秩序（不均一）を避けることが重要です。特に骨格元素がキャリアに配位する場合、deeper potentialを誘起します（F<sup>-</sup>伝導体）。第二近接であれば電荷不均化の静電相互作用は減るので、良いかもしれません（LISICON?）。

#### 10.4.3 複数種のユニットの組み合わせ

複数種のユニットを組み合わせてintergrowth構造へ展開する場合は、相乗効果のコンセプトを念頭に置く必要があります。異層界面の高速伝導やFrenkel欠陥形成エネルギー低減といった効果が期待できれば良いのですが、さもなくば、積層よりブロック単体バルクの方が伝導率は大抵高くなります。

## 11. 誘起効果（Inductive Effect）の詳細

### 11.1 基本概念

誘起効果とは、電気陰性度差により生じる分極、また、その分極の程度が隣接結合に及ぼす影響のことです。

### 11.2 メカニズムの詳細

#### 11.2.1 結合性と分極の関係

| M-Xの電気陰性度差 | M-X結合性 | 陰イオンX^{n-}の負電荷(n) | X-Liのクーロン相互作用 F = εq₁q₂/r² |
|-------------------|-----------|---------------------------|-------------------------------------|
| 大 | イオン結合性 | 大 | 強 |
| 小 | 部分的に共有結合性 | 中 | 弱 |

#### 11.2.2 具体例：Mg<sup>2+</sup>O<sup>2-</sup> vs Zn<sup>1.9+</sup>O<sup>1.9-</sup>

more covalentな結合になると、負電荷は高から中へ、クーロン相互作用は強から弱へと変化します。結論として、電気陰性度差により生じる分極が小さいほど、Li<sup>+</sup>の束縛が弱まります（動きやすい）。

ただし、多様な構造にわたる大域的な傾向を説明できるほどの効果ではなく（おそらく）、同じ結晶構造中の構成元素の違いに着目して議論されることが多いです（特に電解質）。

### 11.4 実例1：K<sup>+</sup>伝導体

#### 11.4.1 Hollandite型K₂MgTi₇O₁₆

Hollandite型K₂MgTi₇O₁₆でMg<sup>2+</sup>をZn<sup>2+</sup>に置換すると、活性化エネルギーはE_a = 1.16 → 0.54 eVへと低下します。電気陰性度はO (3.34) > Zn (1.65) > Mg (1.31)であり、Mg-OよりZn-Oの方が共有結合性が強いため、Oの有効負電荷が小さくなり、K-Oの静電相互作用が小さくなります。

#### 11.4.2 二次元酸化物：K₀.₇(T₀.₃₅Sn₀.₆₅)O₂

二次元酸化物K₀.₇(T₀.₃₅Sn₀.₆₅)O₂では、T = Ca<sup>2+</sup>, Mg<sup>2+</sup>, Zn<sup>2+</sup>に対して、σ = 4.5×10<sup>-7</sup>, 1.6×10<sup>-6</sup>, 7.5×10<sup>-6</sup> S cm<sup>-1</sup>、E_a = 0.54, 0.52, 0.45 eVとなります。

**参考文献：**J. Etourneau, et al., J. Alloys and Comp., 188, 1 (1992).

### 11.5 実例2：Li<sup>+</sup>伝導体

#### 11.5.1 Li₁₀GeP₂S₁₂ vs Li₁₀SnP₂S₁₂

Li₁₀GeP₂S₁₂とLi₁₀SnP₂S₁₂を比較すると、伝導率はσ High > Mediumとなります。COHP (Crystal Orbital Hamilton Population)による化学結合性評価では、COHPが低いほど共有結合性が強く、Sの負電荷が小さくなります。

#### 11.5.2 結合解析結果

結合解析の結果、S net atomic charge eはGe-S結合 > Sn-S結合、M-S bond polarity eはGe-S < Sn-Sとなります。引力が弱いほど（Weaker attraction）Li<sup>+</sup> mobilityは高く、引力が強いほど（Stronger attraction）Li<sup>+</sup> mobilityは低くなります。

**参考文献：**S. P. Culver, J. Morgan, W. G. Zeier, et al., J. Am. Chem. Soc., 142, 21210 (2020).

このことから、電気陰性な金属を第三骨格元素として採用すれば、M-Oの共有結合性が高まり、Li-Oの結合が弱まるはずです。**陽イオン伝導体**では、陰イオンに対して僅かにENが低いMを選ぶと良いと考えられます（covalency in M-X, then weak Li-(X-M) bonding）。**陰イオン伝導体**では、X-M-FのX-MのEN差が小さいとFが易動しやすいかもしれません（I-Bi, S-Bi, Al-B?）。

### 11.8 電極への応用例

#### 11.8.1 Li₂Fe₂(SO₄)₃と Li₂Fe₂(XO₄)₃ X=Mo, W

Li₂Fe₂(SO₄)₃とLi₂Fe₂(XO₄)₃（X=Mo, W）では、OCV（平衡電位）に約600 mVの差が生じます。電気陰性度はX^{n+} > M^{m+}、共有結合性はX-O > M-O、軌道分裂幅（結合性-反結合性軌道）はΔE(X–O) > ΔE(M–O)という関係にあります。X-O-Mでは、価電子帯上端（E_F）のM-O反結合性軌道（M t₂g–O p π結合）のエネルギー順位が、M-O-Mのそれより低下します。

なお、Fe<sup>2+</sup> high spinの軌道分裂では、t₂g軌道はdxy, dxz, dyz、e_g軌道はdx²-y², dz²からなります。

**参考文献：**
- A. K. Padhi, J. B. Goodenough, et al., J. Electrochem. Soc., 144(4), 1188 (1997).
- D. A. Kuznetsov, Y. Shao-Horn, et al., Joule, 2, 225 (2018).

## 12. ペロブスカイト型Li<sup>+</sup>伝導体の詳細

### 12.1 基本特性

Li₂/₃₋ₓLi₃ₓTiO₃は、σ_bulk ≈ 10<sup>-3</sup> S cm<sup>-1</sup>を示します。

**参考文献：**Y. Inaguma, et al., Solid State Commun., 86 (10), 689 (1993).

この材料はc軸二倍周期ペロブスカイト構造をとります。Aサイト（La）欠陥と二次Jahn-Teller効果があり、Ti（d⁰）の空のt₂g（dyz, dzx）軌道とO2p軌道のπ混成によるSOJTにより、TiはLa欠陥層方向へ変位します。構造はLa-poor層とLa-rich層の交互配列からなり、Interstitial Liも存在します。Li-poor相（x ≈ 0.05, 上記構造）は二次元伝導を、Li-rich相（x ≈ 0.11, Liがよりc軸方向に広く分布）は三次元伝導を示します。ただし、これはあくまで平均構造であり、実際はLiとLaは近接配置をとりません。

### 12.3 二次Jahn-Teller（SOJT）効果の詳細

#### 12.3.1 基本メカニズム

SOJTの基本メカニズムは、Ti（d⁰）の空のt₂g軌道（LUMO）と被占有O2p軌道（HOMO）が混成して結合性t₂g-O2p混成軌道を形成し、元のHOMO準位よりΔE分のエネルギー利得が生じるというものです。O2pとM t₂g軌道の準位差が小さいほど、SOJT変位のエネルギー利得は大きくなります。

これはイオン伝導率の傾向 σ Nb, Ti > Ta > Zr と対応しており、SOJT変位しやすい（3d-O2p軌道の準位差が小さい）方が、Li輸送時の活性化障壁の低減に有効と予想されます。実際、M4d-O2p（M=Zr, Ta）よりM3d-O2p（Nb, Ti）の方がSOJT変位は大きくなります。

点群はSOJT歪みによりO_hからC₄ᵥへと変化します。このときBd t₂g LUMOはe d_xy, d_yz、O 2pπ t₁u HOMOはperturbationによりΔEを受け、ΔE∝ (E_LUMO-E_HOMO)⁻¹ の関係があります。

### 12.4 パーコレーション解析

Li<sup>+</sup>Aサイト空孔濃度が約31-34%を境に、伝導率が向上します。拡散機構は、パーコレーションを考慮した空孔拡散機構です。

#### 12.4.1 副格子構造

ペロブスカイトのAサイトだけを考えた格子（Aサイト副格子）は単純格子であり、Liイオンの移動は単純格子におけるパーコレーション（浸透）で整理可能です。実際、Li浸透のパーコレーション閾値と実験結果が対応します。

**参考文献：**Y. Inaguma, et al., Solid State Ionics., 86-88, 257 (1996).

**結論：**パーコレーションとその閾値は、マクロな輸送特性を支配するミクロ要因であり、他の材料系や合剤比率設計でも役に立ちます。

**参考文献：**稲熊宜之, 日本結晶学会誌 58，62-72(2016)

## 13. アニオン伝導体：ペロブスカイト関連構造の詳細

#### 13.1.1 ペロブスカイトABX₃

## 14. ボトルネック・臨界半径の詳細

ペロブスカイトBaLiF₃での計算例を示します。基本パラメータは、a = 3.99 Å、r_Li = 0.76 Å、r_F = 1.33 Å、r_Ba = 1.61 Åです。A2Bからなる三角形をボトルネック面積とすると

**S = a²/2√2 = 5.66 Å²**

となります。臨界半径は、幾何学的関係式

**(r_A + r_c)² = (a/2)² + (a/√2 - r_B - r_c)²**

から

**r_c = [a²/4 + (a/√2 - r_B)² - r_A²] / [2(r_A + a/√2 - r_B)]**

と計算され、数値を代入すると

**r_c = 0.77 Å ≪ r_F = 1.33 Å**

となります。つまり、ボトルネック通過時には骨格陽イオンとの大きな重なり反発が生じており、骨格元素の分極率（電子雲の歪みやすさ）や原子変位能の重要性が窺えます。

## 15. 逆ペロブスカイト型イオン伝導体の詳細

逆ペロブスカイト型イオン伝導体の基本組成は、A₃ChX（A = Li, Na, H, Ch = O, X = Cl, Br）です。伝導率はLi<sup>+</sup>で10<sup>-4</sup>~10<sup>-5</sup> S cm<sup>-1</sup>、Na<sup>+</sup>で10<sup>-6</sup>~10<sup>-7</sup> S cm<sup>-1</sup>程度です。Li₃OX（X = Cl or Br）では10<sup>-3</sup> S cm<sup>-1</sup>が報告されました（Zhao. et al., 2012）。

**LiCl + 2LiOH = Li₃OCl + H₂O**

最高伝導率は、Li₃OCl₀.₅Br₀.₅の1.94×10<sup>-3</sup> S cm<sup>-1</sup>です。ただし再現性が低く、プロトン伝導の寄与が疑われています。Reviewでは、再現実験を元に、Li<sup>+</sup>で10<sup>-4</sup>~10<sup>-5</sup> S cm<sup>-1</sup>、Na<sup>+</sup>で10<sup>-6</sup>~10<sup>-7</sup> S cm<sup>-1</sup>が実際の最高の伝導率と結論されています。

## 17. 超イオン導電体の詳細

狭義には、超イオン導電（superionic conductivity）は超伝導（superconductivity）と区別して用いられます。広義には、イオン伝導（Ionic conductivity）を指します。我々は「導電」が一般的で、超イオン導電体以外は伝導を使うべきですが、実際問題、統一すればどちらでも良いでしょう。

### 17.2 α-AgIの詳細

#### 17.2.1 相転移の詳細

α-AgIは、147°Cでβ相ウルツ構造（hcp）からα相（bcc）へ相転移します。

#### 17.2.2 β-AgI構造（低温相）

β-AgI構造（低温相）では、I<sup>-</sup>がhcp格子を組み、四面体（2b）位置が占有率1で占められています。

#### 17.2.3 α-AgI構造（高温相）

α-AgI構造（高温相）では、I<sup>-</sup>がbcc格子を組み、歪んだ四面体（12d）位置、八面体（6b）位置、平面三配位（24h）位置が存在します。Ag<sup>+</sup>は格子間隙の複数の結晶学サイトに部分占有で広く分布した平均構造をとります。このAg<sup>+</sup>の副格子融解が、超イオン導電をもたらします。

**参考文献：**工藤撤一、笛木和雄、固体アイオニクス、講談社（1986）

### 17.3 Ag₃SIの詳細

#### 17.3.1 相転移と構造変化

β-Ag₃SI（低温相）はPm-3mの逆ペロブスカイト型で、σ = 0.008 S cm⁻¹を示し、陰イオンが規則配列しています。一方、α-Ag₃SI（高温相）はIm-3mのα-AgI型で、σ = 0.3 S cm⁻¹を示します。陰イオンの不規則状態（Im-3m）とAg<sup>+</sup>の無秩序状態により、高イオン導電率が実現されます。

#### 17.3.2 構造の詳細

AgSIでは、陰イオンのbccパッキングにおいてAg<sup>+</sup>が高速拡散します。Ag<sup>+</sup>は（24h）位置を占め、S<sup>2-</sup>/I<sup>-</sup>が配列しています。

**参考文献：**S. Hull, et al., J. Phys.: Condens. Matter, 13, 2295 (2001).

### 17.4 RbAg₄I₅の詳細

RbAg₄I₅では、高温相を安定化させる目的でRb<sup>+</sup>, NH₄<sup>+</sup>などの置換が行われています。構造は、AgI₄四面体同士が面共有でネットワークを形成したものです。温度と伝導率の関係が、他の材料と比較して示されます。

### 17.5 Rb₄Cu₁₆I₇Cl₁₃の詳細

Rb₄Cu₁₆I₇Cl₁₃は、CuCl - CuI - RbCl 擬似三成分系の絨毯爆撃的な探索で見いだされ、0.34 S cm⁻¹を示します。Cu(I/Cl)₄四面体同士が面共有でネットワークを形成し、一次元らせん経路をとります（Cuの核密度分布が可視化されています）。

なぜRbなのかについては、KやNaはCuサイト占有によるサイトブロック効果があるため、またCsは大きすぎてこの構造をとれない・経路が歪むためではないかと考えられます。

**参考文献：**
- T. Takahashi, J. Electrochem. Soc., 126, 1654 (1979).
- K. Oikawa, R. Kanno, F. Izumi, et al., Materials Science Forum, 443-444, 337 (2004).

## 18. 高温相の安定化：酸化物イオン伝導体の詳細

高温超イオン伝導体相をひとたび見いだせれば、元素置換で低温安定化を図ります。低温相γ-Bi₂O₃（単斜晶系）は、酸素と空孔の規則配列構造です。一方、高温相α-Bi₂O₃（立方晶系）は蛍石型構造（MX₂：Bi₄O₆□₂）で、1/4の酸素サイトが空であり、酸素と空孔が不規則配列した高対称構造をとります。

G = H - TSより高温では高エントロピー状態が安定化されるため、元素置換による配置エントロピー増大で低温安定化が可能です。

**参考文献：**T. Takahashi, H. Iwahara, Mat. Res. Bull., 13, 1450 (1978), 工藤撤一、笛木和雄、固体アイオニクス、講談社（1986）

## 19. 超アニオン導電体：BIMEVOX & PbSnF₄の詳細

#### 19.1.1 Bi₄V₂O₁₁（Aurivillius構造）

Bi₄V₂O₁₁（Aurivillius構造）は、σ₂₀₀°C = 3×10<sup>-4</sup> S cm⁻¹を示します。構造は、占有率1でおそらく動かないF層、部分占有で不規則配列したPv層、そして再び占有率1のF層という積層からなります。ここでは、V<sup>5+</sup>のSOJT効果が重要かもしれません。

#### 19.1.2 PbSnF₄（層状蛍石構造）

PbSnF₄（層状蛍石構造）は、σᵣ.ₜ. = 3×10<sup>-2</sup> S cm⁻¹を示します。構造は、占有率1でおそらく動かないF(Pb)層、部分占有で不規則配列したF(Sn)層2枚、そして再び占有率1のF(Pb)層という積層からなります。こちらは、Sn<sup>2+</sup>の孤立電子対効果が重要かもしれません。

### 19.2 共通特徴の分析

両者に共通する特徴は、ペロブスカイト（P）、蛍石（F）ブロックの層状構造であること、そして層間で陰イオンが高度に不規則配列していることです。また、V<sup>5+</sup>のSOJT（二次Jahn-Teller効果）やSn<sup>2+</sup>の孤立電子対（立体化学的活性）といった、原子（+電子）変位能の高い骨格元素を含みます。とりわけPbSnF₄でなぜ層状構造がイオン伝導に有利なのかは、まだ十分に理解されていません。

**結論：**酸化物イオンとフッ化物イオン伝導体の最高値を示す構造は別物だが似ている…

## 20. Jahn-Teller効果とSecond-Order Jahn-Teller効果の詳細

### 20.1 通常のJahn-Teller効果

#### 20.1.1 d⁷, d⁹電子系

d⁷, d⁹電子系では、±apical方向にXが変位します。軌道はe_g軌道（dₓ²₋ᵧ², dᵤ²）とt₂g軌道（dₓᵧ, dₓᵤ, dᵧᵤ）に分裂し、エネルギー利得ΔEによる安定化が生じます。

---

### 20.2 Second-Order Jahn-Teller効果の詳細

#### 20.2.1 d⁰電子系での発現機構

d⁰電子系でのSOJT発現には、空のt₂g軌道（LUMO）と被占有X 2p軌道（HOMO）が基本条件となります。混成メカニズムは次の通りです。

**X p軌道 と M t₂g軌道の準位差が小さいほどより混成して**
**結合性軌道のエネルギーが低下 → SOJT発現**

#### 20.2.2 軌道準位図

軌道準位図では、エネルギー順位は上からe_g軌道、t₂g軌道、X2p軌道（HOMO）の順に並びます。準位差ΔEが小さいほど混成が強くなり、結合性軌道のエネルギー低下が大きくなります。

## 21. 孤立電子対（Lone Pair Electron）の詳細

最外殻5s², 6s²孤立電子対は、実空間上に非対称的に局在化する傾向があります。軌道混成の観点では、これはnsと2p軌道がつくる反結合性軌道とnp軌道の混成軌道です。孤立電子対（lone pair）はns²電子のイメージですが、非対称的な局在化の由来はnp軌道との混成によるものです。Pb 6pはAnti-bonding（Pb 6s - O 2p）* + Pb 6p、Pb 6sはBonding（Pb 6s - O 2p）に対応します。O 2p軌道との相互作用としては、Te 5p, Se 4p, S 3pやO 2pzが挙げられます。

原子軌道エネルギー（LDA近似）は以下の通りです。

### 21.3 ペロブスカイト型CsPb₀.₉K₀.₁F₂.₉での実例

ペロブスカイト型CsPb₀.₉K₀.₁F₂.₉は、σ = 3×10<sup>-3</sup> S cm⁻¹、E_a = 7.9 kJ mol⁻¹を示します。ここでは、Pb 6s孤立電子対の遷移による移動障壁の低減が生じています。反応座標に沿ったエネルギープロファイルは、CsSrF₃で約35 kJ mol⁻¹、CsPbF₃で約10 kJ mol⁻¹と、大幅に低減されます。PbF₅ → PbF₆ → PbF₅という配位変化を伴って**V_F（F空孔）**が移動し、**LP（孤立電子対）**が動的に変位します。このように、立体化学的に活性な孤立電子対の変位が、イオン伝導率向上に寄与します。

## 23. LISICON型の詳細

LISICONは、Li superionic conductorの略です。Li₄SiO₄やLi₂.₅Al₀.₅SiO₄などがあり、同骨格でキャリア量を変えることが出来ます（固溶体の形成）。

## 25. パッキングとLi移動障壁

リチウムイオンの移動については、bcc格子の方がfcc格子よりも移動障壁が低いこと（bcc shows lower migration energy than fcc lattice for lithium-ion migration）が報告されています（Wang, Nature Materials, 14, 1026 (2015)）。移動経路はT-O-T（四面体-八面体-四面体）で、エネルギープロファイルは約0.4 eVです。fcc格子とbcc格子での移動障壁の比較により、bcc構造の優位性が実証されています。

# 27. イオン伝導体設計指針の総合まとめ

## 27.1 基本要件（「ウエスト固体化学 基礎と応用」より引用）

1. 高いキャリア数（多数の可動イオン）を有すること
2. イオンが移動可能な空孔が多数存在すること
3. 空孔及び被占有位置において、可動イオンが同程度のポテンシャルを有し、またこのサイト間の拡散経路のポテンシャル障壁が低いこと
4. 可動イオンが長距離拡散可能な、連結した可動イオンのチャンネルが存在する骨格構造を有すること
5. 骨格構造を形成するイオンが大きく分極できること

## 27.2 追加的要件

6. 骨格イオンとの静電相互作用が弱いこと
7. bcc（body-centered cubic）パッキングが適した骨格であること、玉突き集団運動が重要など

**参考文献：**Y. Mo, et al., Nat. Mater., 14, 1026 (2015). X. He, et al., Nat. Commun., 8, 15893 (2017).

### 27.3.1 キャリアカチオン

| イオン種 | 室温伝導率 | 分極率 | 静電相互作用 |
|----------|------------|--------|--------------|
| Li<sup>+</sup>, Na<sup>+</sup> | σᵣ.ₜ. ≈ 10<sup>-2</sup> S cm<sup>-1</sup> | 分極率低 | - |
| Cu<sup>+</sup>, Ag<sup>+</sup> | σᵣ.ₜ. ≈ 10<sup>-1</sup> S cm<sup>-1</sup> | 分極率高 | - |

#### 27.3.2 キャリアアニオン

| イオン種 | 特性 | 静電相互作用 |
|----------|------|--------------|
| F<sup>-</sup>, H<sup>-</sup> | σᵣ.ₜ. ≈ 10<sup>-2</sup> S cm<sup>-1</sup> | 静電相互作用弱 |
| H<sup>+</sup>, O<sup>2-</sup> | 400~600°C以上で高速拡散 | 静電相互作用強 |

### 27.3.3 骨格アニオン

σ：S<sup>2-</sup> ≥ X<sup>-</sup>（Cl, Br, I）> O<sup>2-</sup>

## 27.4 具体的設計指針の詳細

### 27.4.1 パーコレーション関連

パーコレーションの観点からは、キャリア副格子を他の元素が占有する場合、キャリアの濃度（空孔含む）が約20-33%以上あるかを確認します。

### 27.4.2 骨格元素の選択

骨格元素としては、変位能の高い元素を使います。誘電体からイオン伝導体に展開された例が多く（Li<sup>+</sup>伝導体LLTOやO<sup>2-</sup>伝導体Na₀.₅Bi₀.₅TiO₃など）、誘電体をベースに元素置換するのも良さそうです。具体的には、s²電子系の孤立電子対や八面体中心d⁰電子系の二次Jahn-Teller（SOJT）を使うと良く、LPとしてはSn<sup>2+</sup>, Pb<sup>2+</sup>, Bi<sup>3+</sup>など、SOJTとしてはTi<sup>4+</sup>, V<sup>5+</sup>, Zr<sup>4+</sup>, Nb<sup>5+</sup>, Ta<sup>5+</sup>, (Sc<sup>3+</sup>)などが該当します。

### 27.4.3 結晶構造関連

結晶構造の観点からは、定比組成の結晶構造の場合に欠陥（空孔・格子間）が入りやすいか、また間隙が多いかに着目します。最密充填構造以外を選ぶとベターですが、最密充填構造でも構いません（他の要因が大抵影響します）。

#### 27.4.4 設計優先順位

設計の優先順位としては、Inductive effectは狙い通りとならない（他の要素が影響する）ことが多いので、最後に考えます。

### 27.5 全体的な設計戦略

つまり・・・

**高い分極率の可動/骨格イオン、弱い静電相互作用、高いキャリア（空孔/格子間）濃度、適切なパス形成が大事**

| 要因分類 | 決定要素 |
|----------|----------|
| 構成元素でおおよそ決まる | 高い分極率の可動/骨格イオン、弱い静電相互作用 |
| 結晶構造で決まる | 高いキャリア（空孔/格子間）濃度、適切なパス形成 |

イオン伝導体ごとの大まかな比較として、これらの指針は広範囲の材料設計に適用可能です。
