# イオン伝導体の結晶構造解析 (工事中)

## X線回折と中性子回折の比較

### X線回折

X線回折の最大の利点は、実験室のXRD装置やSPring-8などの放射光施設といった測定装置へのアクセスが容易な点です。一方で欠点もあり、電子数の少ない軽元素の検出が難しいこと、Si<sup>4+</sup>とP<sup>5+</sup>のように電子数の近いイオンは識別できないこと、さらにX線吸収端より高エネルギー側の波長を使うと蛍光X線がバックグラウンドの増加をもたらすことが挙げられます。

### 中性子回折

中性子回折は、X線と比較して軽元素の解析に適しており、周期表上で隣り合う元素を識別できるという利点があります。その一方で、吸収断面積が大きい原子は測定できないことに加え、装置へのアクセスが一般的に容易ではないことが欠点となります。

## Braggの回折条件

**nλ = 2dsinθ**

光路差（2dsinθ）が波長の整数倍（nλ）に等しいとき、回折波が同位相となり強め合います。ここで、λは波長、dは格子面間隔、θは入射角、nは整数です。

## X線回折（XRD）測定

固定波長のX線（Cu K<sub>α1</sub> = 1.541 Å）を入射角θでスキャンし、検出器を入射X線に対して2θとなるようスキャンします。θ-2θをスキャンしながら、強め合う回折波をピークとして検出します（ピーク位置2θに対応する格子面間隔 d = nλ/(2sinθ) が存在することに対応します）。

X線回折図形からは、ピークの2θから格子面間隔dが、強度から格子面を構成する元素情報（電子数）が、そしてピークの数から結晶構造特有の規則性が、それぞれ得られます。

## X線回折（XRD）測定 - 相同定

### 合成→相同定手順

仕込み組成：BaNaCaF<sub>5</sub> – NaF – Ba<sub>0.5</sub>Ca<sub>0.5</sub>F<sub>2</sub>

データベースと一致するパターンを検索します。多少のピーク位置の差は許容して、おおよそ一致するパターンを検索するアルゴリズムです。

**検索手順：**

1. まずは以下で検索
   - アニオンを必ず含む（フッ化物であればF、酸化物であればO、硫化物であればS）
   - 構成金属元素：わからない
   - それ以外の全元素：含まれない

2. 該当がなければ
   - アニオンを必ず含む（フッ化物であればF、酸化物であればO、硫化物であればS）
   - それ以外の全元素：わからない

### 内蔵データベース

| データベース | 特徴 |
|------------|------|
| ICDD | 回折パターンデータベース、構造無し、指数付け済み回折パターンのみ。指数付けの確からしさ（構造同定まで、or 指数付けのみ or 不完全な指数付け）に注意 |
| ICSD | 構造データベース。最も主要なデータベース。シミュレーションパターンを使うことになる |

データベースに無い新規相の場合、まずは単相化が必要です。場合により温度も変えながら、新規相が出現する組成を決定します。単相化後に指数付けを行い、全てのピークを指数付けできたら、相同定が一旦完了します。その後、未知構造解析を行い、新規相の構造を明らかにします。

## 結晶子サイズの解析

Mo粉末の結晶子サイズとプロファイルの関係を見ると、結晶子サイズが小さいほどピークはブロードになります。粒径がSEM/TEMや粒度分布計で求まるのに対し、結晶子サイズはX線回折ピークの半値幅から求めることができます。

### シェラーの式

**D = Kλ / (βcosθ)**

ここで、Dは結晶子サイズ、Kはシェラー定数（結晶子の外形を立方体と仮定したK = 0.94をよく使います）、βは半値幅、θはBragg角です。

### 注意点

解析にはK<sub>α1</sub>のみを用います（K<sub>α1,2</sub>からデータ処理を行います）。また、装置由来の半値幅の広がりは、LaB<sub>6</sub>等で得られる半値幅bを用いて β = √(B<sup>2</sup>-b<sup>2</sup>) と補正します。実用的に解析可能な結晶子サイズは1nm〜100nm程度であり、100nm以上では装置ごとに値が異なるため正確な計算は困難です。さらに、格子ひずみでもブロードニングが生じる点に注意が必要です。

## 粉末X線回折測定の基礎

### 結晶系（Crystal system）

単位格子の形状は以下のように分類されます。

| 結晶系 | 格子定数の関係 | 格子角の関係 |
|--------|---------------|-------------|
| 立方晶系（cubic） | a = b = c | α = β = γ = 90° |
| 正方晶系（tetragonal） | a = b ≠ c | α = β = γ = 90° |
| 直方晶系（orthorhombic） | a ≠ b ≠ c | α = β = γ = 90° |
| 単斜晶系（monoclinic） | a ≠ b ≠ c | α = γ = 90°, β ≠ 90° |
| 三斜晶系（triclinic） | a ≠ b ≠ c | α ≠ β ≠ γ ≠ 90° |
| 六方晶系（hexagonal） | a = b ≠ c | α = β = 90°, γ = 120° |
| 菱面体晶系（rhombohedral） | a = b = c | α = β = γ = 120° |

（三方晶系（trigonal）：a = b ≠ c, α = β = 90°, γ = 120°）

### ブラベー格子（Bravais lattice）

ブラベー格子は合計14種類あります。

**立方晶系**
- 単純立方格子（cP）
- 体心立方格子（cI）
- 面心立方格子（cF）

**正方晶系**
- 単純正方格子（tP）
- 体心立方格子（tI）

**直方晶系**
- 単純直方格子（oP）
- 底心直方格子（oC, oA, oB）
- 体心直方格子（oI）
- 面心直方格子（oF）

**単斜晶系**
- 単純単斜格子（mP）
- 底心単斜格子（mC, mA, mB）

**六方晶系**
- 単純六方格子（hP）

**菱面体晶系**
- 単純菱面体格子（rP）

記号はそれぞれ、P: Primitive、I: Body centered、F: Face centered、C: C-face centeredを表します。

## ミラー指数

ミラー指数 h k l は、結晶方位・面を指定するための表記です。特定の面は（h k l）、等価な面の集合は {h k l}、特定の方位は [h k l]、等価な方位の集合は <h k l> と表記します。またXRDでは、Bragg反射の回折指数を括弧なしの h k l で表します。

## 空間群

14種類のブラベー格子に対称操作を組み合わせることで、230種類の空間群が導かれます。全空間群の情報はInternational Tables for Crystallography Aにまとめられています。

### 空間群の表記 Wxyz（P4/mmm, Fm-3mなど）

空間群の表記Wxyzにおいて、Wはブラベー格子（P: Primitive, I: Body-, F: Face-, A: A-face-, B: B-face-, C: C-face centered, R: rhombohedral）を表します。xは主軸（[001]軸）の対称操作、yは主軸と異なる軸回りの対称操作（立方晶 [111], 正方晶 [100], それ以外 [010]）、zはさらに別の軸回りの対称操作（正方晶、立方晶 [110]）を表します。

### 対称操作の表記

| 記号 | 意味 |
|------|------|
| 1, 2, 3, 4, 6 | 回転軸 |
| m | 鏡映面 |
| 2<sub>1</sub> | 2回らせん軸 |
| 4<sub>2</sub> | 4回らせん軸 |
| a, b, c | 映進（グライド）面（軸方向に1/2並進+鏡映） |
| n | 対角映進面 |
| d | ダイヤモンド映進面 |
| - | 反転 |
| / | 軸と直交関係（例：4/m：4回軸と、直交する鏡映面） |

### 空間群から結晶系を見分ける方法

- 対称操作2個目（y）に3回（反）軸：立方晶系
- 対称操作1個目（x）に4回軸：正方晶系
- 対称操作1個目（x）に6回軸：六方晶系
- 対称操作1個目（x）に3回（反）軸 ∩ R：菱面体晶系
- 対称操作1個目（x）に3回（反）軸 ∩ P：三方晶系
- 対称操作1個表記かつ2回（螺旋）軸：単斜晶系
- いずれでもない対称操作3個表記：直方晶系

## 空間群の決定

### From scratch
1. 指数付け
2. 空間群候補の自動検索（*注意：自動提案された空間群が正しいか、3以降で検証するべき）
3. 指数付け結果に対して、消滅反射と観測反射を整理（手動）
4. 消滅則と照らし合わせて対称操作の有無を判断していく
5. 消滅則を満たす空間群の最終候補を決定（FOXと答え合わせ、FOXが必ずしも正解とは限らない）
6. その中でもっとも低い対称性の空間群でRietveld解析を行う（どの対称操作を考慮しないか、を押さえておく）
7. 精密化後の構造・座標を眺めて、考慮しなかった対称操作を導入しても問題がないか考える→必要に応じて対称操作を入れて再解析

推奨ツールはFOX、Conographです。

### From related structure（同骨格構造の対称性違いがある場合）
1. 低角度側に反射があるか：長周期の超構造か判断
2.1. 単位格子が同じ場合：既知の空間群のT部分群（Translationengleiche subgroups）を探す
2.2. 単位格子が異なる場合（n倍周期）：既知の空間群のK部分群（Klassengleiche subgroups）を探す→大抵うまくいかないのでfrom_scratchで探すことが多い

部分群（subgroup）–超群（supergroup）の関係はInternational Table A1でまとめられています。詳しく勉強したい場合は、対称性セミナーの受講を強く推奨します。

## International Tables for Crystallography Aの見方

International Tables for Crystallography Aでは、各サイトについて**多重度**、**Wyckoff記号**、**席対称性**が記載されています。多重度は単位格子内に何個の等価なサイトがあるかを表します。Wyckoff記号は単なる識別記号であり、それ自体に意味はありません。席対称性は、サイトを中心とした周辺環境の対称性を表します。例えば8iは、結晶学的に等価な8個のサイトに対応します。

互いに等価なサイトは結晶学的等価サイト（crystallographically equivalent）、そうでないサイトは結晶学的非等価サイト（crystallographically non-equivalent）と呼びます。また消滅則については、特殊位置に原子が存在する場合に追加で発生する消滅則がある点に注意します。

## 結晶構造解析

### Le Bail解析
Le Bail解析では、格子定数、プロファイルパラメーター、バックグラウンドを精密化することで、指数付けの妥当性の検証と格子定数の算出を行います。

### Rietveld解析
Rietveld解析では、上記に加えて構成原子（イオン）の内部座標、占有率、原子変位因子（温度因子）を精密化します。想定されるモデルの妥当性を、Rietveld解析による構造精密化を通じて検証します。

解析プロセスとしては、まず初期構造モデルから、構造パラメーター、プロファイル関数、バックグラウンド関数、粒子サイズなどを用いて理論回折パターンを計算します。これを実測回折パターンと比較し、パターン残差を最小化（共役勾配法）することで精密化構造が得られ、その良し悪しは信頼度因子（R<sub>wp</sub>…）で評価します。さらに、F<sub>obs</sub>、F<sub>calc</sub>、F<sub>diff</sub>、Fourier合成、MEM密度分布解析も可能です。

## Rietveld構造解析結果

回折パターンの表示では、赤点が実測値 I<sub>obs</sub>、実線が計算値 I<sub>calc</sub>、フラッグが理論Bragg反射位置（上から主相、第二相）、青線が残差曲線 I<sub>obs</sub> – I<sub>calc</sub> を表します。残差曲線が平坦なほど、構造モデルが実測XRDパターンをよく再現できていることになります。

精密化するパラメータには、原子（イオン）が占有する割合（確率）である占有率（g）、分率座標である内部座標（x y z）、熱振動の大きさを表す温度因子（B）があります。信頼度因子については、R<sub>wp</sub>（weighted pattern）が5%程度ならパターンの良い一致、R<sub>F</sub>やR<sub>B</sub>が5%程度なら良い構造精密化が出来ていると判断します。

同じ結晶学サイトを占有する原子同士のパラメーターには、線形制約条件を課して精密化します。精密化されたパラメータは括弧付きで誤差を表示します（e.g. 4.86(13) = 4.86±0.13）。

例えばLiが48hサイトを占有率0.288で占有する場合、単位格子内に48個の結晶学的等価サイトが存在し、そのうち約14サイトをリチウムがランダムに占有していることになります。これはLi<sup>+</sup>が高度に無秩序分布した構造であり、Li伝導に有利です。また、Liが他の金属元素より広く熱振動していることもわかります。

## 結晶構造解析からわかること

### 可動イオンの格子内分布：内部座標、占有率

内部座標と占有率からは、平衡位置をつなぐイオン伝導経路を議論できます。さらに、最大エントロピー法（MEM）解析等から可動イオンの確率密度分布を解析することで、遷移状態を含めたイオン伝導経路の可視化が可能となり、（Advanced）MEM-OPPによる移動障壁推定へと発展させることができます。

### 可動イオンの熱振動：温度因子、局所的な移動度を反映

温度因子は局所的な移動度を反映しており、大きな温度因子ほど局所的によく動くことを意味します。（Advanced）一粒子ポテンシャル（OPP）による移動障壁推定も可能です。

### 骨格イオン構造：ボトルネック、可動イオンのチャネル構造

骨格構造からは、イオン伝導に適した骨格構造であるかを判断でき、律速となる幾何的なボトルネックの定量が可能です。これは原子価結合法を用いたエネルギーランドスケープ計算と移動障壁推定につながります。

## 温度因子

温度因子 or 原子変位パラメーター（atomic displacement parameter）は、原子の平衡位置からの変位確率を表します。

**ρ(r) = ∫ p(t - r)ρ(r)dr**

この式には、平均電子密度、変位分布関数、電子密度が対応します。調和振動の場合、変位分布は正規分布で表されます。

p(r) = 1/(2π)<sup>3/2</sup>σ<sup>3</sup> exp(-r<sup>2</sup>/2σ<sup>2</sup>)

**平均原子散乱因子**

f(k) = f(k)exp(-2π<sup>2</sup>k<sup>2</sup>σ<sup>2</sup>) = f(k)exp(-B(sinθ/λ)<sup>2</sup>)

k = 2sinθ/λ
B = 8π<sup>2</sup>σ<sup>2</sup>

ここで、Bは等方性温度因子（Isotropic ADP）、分散σ<sup>2</sup>は正規分布の標準偏差σの二乗です。非等方性の場合はβ<sub>ij</sub>（非等方性温度因子、anisotropic ADP）を用います。

**非等方性温度因子の式：**

f(hkl) = k exp{-(h<sup>2</sup>β<sub>11</sub> + k<sup>2</sup>β<sub>22</sub> + l<sup>2</sup>β<sub>33</sub> + 2hkβ<sub>12</sub> + 2hlβ<sub>13</sub> + 2klβ<sub>23</sub>)}

熱振動を回転楕円体で考えると（等方的分布）、Probability of 50%のThermal ellipsoid（熱振動楕円体）として表現されます。

温度因子の目安としては、軽元素で0.5〜2 Å<sup>2</sup>、重元素で0.2〜0.5 Å<sup>2</sup>程度の大きさの温度因子となります。

温度因子が大きいほど確率密度分布はなだらかになり、高確率に平衡位置から離れた位置まで変位します。これはポテンシャルフラットニング（平坦化）に対応します。温度因子が高いほどイオンの局所的な動きやすさを反映しており、異方性温度因子の大きさ（熱振動楕円体の形状）からイオン拡散経路を推定することができます。

表記法には注意が必要です。B<sub>eq</sub>とB<sub>iso</sub>は等しくありません。B<sub>eq</sub>は異方性温度因子を平均化したものであり、B<sub>iso</sub>はB<sub>11</sub> = B<sub>22</sub> = B<sub>33</sub>（B<sub>12, 13, 23</sub> = 0）とした場合に対応します。また、B = 8π<sup>2</sup>σ<sup>2</sup>、U = B/8π<sup>2</sup> = σ<sup>2</sup>の関係があります。

## 一粒子ポテンシャル法（One Particle Potential: OPP）

Einsteinモデル（個々の原子が独立に振動）のもと、原子が平衡位置から変位（r）する際、周りの原子からの相互作用を熱振動ポテンシャルで表現します。

**opp(r) = -kT ln(pdf(r - r<sub>0</sub>) / pdf(r<sub>0</sub>))**

確率密度関数（probability density function: pdf）は温度因子のフーリエ変換です。

**B(k) = ∫ p(r)exp(ikr)d<sup>3</sup>r**

pdf(p(r))は、平衡位置の周囲に振動している孤立原子が、平衡位置の周囲で単位体積あたりに見出される確率の空間的、時間的平均を表します。

通常OPPは、格子の熱膨張による僅かな効果は別として、温度にほとんど独立です。一方で超イオン導電体では、熱振動の振幅が平衡位置の間の距離と同程度に大きくなる場合があります。すなわち、平衡位置の中間でもpdfは値を持ち、隣接するイオンのOPPは互いに重なり合うので、重なる点の値からイオンの動きに対するポテンシャルの障壁の高さを推定することが可能です。このように、温度因子から確率密度、ポテンシャルへ変換するAdvanced解析が可能です。

## 密度分布の扱い方

密度分布は、実空間の3次元（xyz）に密度（ρ）を加えた4次元の情報として扱います。密度には種類があり、NPDでは核散乱長（fm）密度（ρ / fm Å<sup>-3</sup>）、XRDでは電子（e, not SI unit…）密度（ρ<sub>e-</sub> / e Å<sup>-3</sup>）、MDや温度因子のフーリエ変換では原子存在確率密度（ρ<sub>Li</sub> / Å<sup>-3</sup>）が得られます。

二次元スライス（xy）なら、密度をz軸や色スケールで表示可能です。三次元空間上に密度分布を図示するには、"等値面（isosurface）表示+格子断面に密度の色スケール表示"が便利です。

voxelサイズが大きいほど、voxelあたりの統計は高まりますが、密度分布図が荒くなります。そのため、voxelの1辺の長さは0.05 Åあたりがおすすめです。特にXRD、NPDから得られた密度分布では、対象原子以外の不要な情報を拾わない等値面を設定するとよいでしょう。

## フーリエ合成

逆空間から実空間へのフーリエ変換により、フーリエ合成が可能です。XRDからは電子密度分布が、NPDからは核（散乱長）密度分布が得られます。

**差フーリエ合成**

差分強度から差フーリエ合成を行うことで、Rietveld初期モデルで見逃していた原子の過不足情報を表すことができます。差フーリエ合成密度分布で得られた過剰密度に新たなサイトを割り当てて再解析する、といった使い方をします。

特に、差フーリエ合成は構造モデルの修正に便利です。正確には強度ではなく結晶構造因子Fを元にフーリエ合成を行います。なお、フーリエ級数の打ち切り誤差に起因したゴースト（本質的ではない人工的な副産物）の密度分布に注意が必要です。

## 最大エントロピー法（Maximum Entropy Method, MEM）

観測情報を満足し、未観測情報に関してはバイアスを最もかけない形で解（電子密度、核密度）を得る手法です。

熱力学のエントロピーの概念を情報理論に導入・発達させた推論手法であり、画像処理分野で良く用いられます。その解析手法を材料科学分野に逆輸入したものです（高度解析でこういった逆輸入は結構あります。面白いですね）。

結晶構造解析においては、観測情報が結晶構造因子F(obs)と対応する統計誤差σ、未観測情報が真の結晶構造因子F(calc)に対応し、統計誤差σの範囲内でF(obs)に一致する未知の結晶構造因子F(calc)を求めます。

ざっくばらんに言うと、総電子数や対称性の要請を満足する形で、voxel（pixelの3次元版）に対して電子（核）密度を割り当て、実測値の統計誤差の範囲に収まるように、試行錯誤して確からしい解へ導く手法です。

**目的変数1（相対誤差）：**
C = (1/N)Σ<sub>k</sub>|F<sub>cal</sub>(k) - F<sub>obs</sub>(k)|<sup>2</sup>/σ<sup>2</sup>(k)

F<sub>cal</sub>(k) = VΣ<sub>r</sub>ρ(r)exp(-2πir・k)

**目的変数2（情報エントロピー）：**
S = -Σ<sub>r</sub>ρ'(r)ln(ρ'(r)/τ'(r))

目的変数1を最小化（|計算値–実測値|<sup>2</sup>/偏差）、目的変数2を最大化（エントロピー最大）します。つまり、統計誤差の範囲に収まる再現精度で、高エントロピー（広がった分布、ぼやけた画像）な電子密度を求めます。

### 解析上のパラメータ
1. E：Scaling factor σF * E
2. Number of F<sub>hkl</sub>（≒ d region）
3. Resolution：Number of mesh

Eを1以上にすることで（通常1〜3）、標準偏差を大きく見積もり、解析を早期に（強制的に）収束させます。MEMのR値がRietveldの値以下となるようにします。また、出来るだけ多くのhkl反射を拾うことで、高解像度の電子密度が得られます。少ないhkl反射では、ぼやけすぎた密度が得られるので要注意です。TOF回折（NPD）では d > 0.5 Åのデータを用います。High-Q（small-d）は、（1）熱散漫因子の影響、（2）密集ピークが分離困難、（3）バックグラウンド分離が困難の理由で、構造因子Fを正確に抽出することが困難だからです。

解析の妥当性は、密度分布が解釈可能か、R値が低いか、（|F<sub>cal</sub>–F<sub>obs</sub>|/σ）<sup>2</sup>の分布が半値幅の狭いGaussian正規分布か、で判断します。

### 用途：イオン導電体のイオン拡散経路の可視化

LSGMの様々な温度における核密度分布、CeO<sub>2</sub>やα-Bi<sub>2</sub>O<sub>3</sub>の788℃における（110）など、様々な伝導体で活用例があります。

留意点として、中性子回折データを用いることが望ましいです。その理由は、（1）XRDで得られる電子密度分布から、電子雲の広がりと原子の運動性を切り分けることは困難であるのに対し、核密度分布は結合電子などの電子雲の非調和成分情報を含まないこと、（2）Li<sup>+</sup>やO<sup>2-</sup>、F<sup>-</sup>などの軽元素が高コントラストに探測できることです。また、イオン伝導率が10<sup>-2</sup> S cm<sup>-1</sup>程度以上の温度域の回折データが望ましく、イオンの遷移過程が充分に回折データに含まれる（結晶構造因子Fに含まれる）必要があります。

さらに、MEMの確率密度分布（pdf）から一粒子ポテンシャルを求めることもできます。

## Advanced: 未知構造解析

未知構造解析は、初期構造モデルの決定に対応します。これまでに得られた結晶学的データ（格子定数、空間群）と反射強度から、初期構造モデルを決定します。

アプローチには、単結晶と同様の逆空間法（直接法）、パターンを再現する原子配置を探索する実空間法、そして双対空間法があります。

回折は結晶構造のフーリエ変換であり、結晶構造から回折強度へは容易に変換できます。しかし、回折強度は位相を失っているため、回折強度から結晶構造への直接変換はできません（位相問題）。だからこそ、未知構造解析はむずかしいのです。初期構造モデルが決まれば、（粉末回折の場合）Rietveld解析へ進みます。

とある実例では、低角のデータのみで解析を行いたい状況でした。低角側にピークが多く、高角度側のピークの重なりの分離が困難だったためです。また、モデルの自由度の低さは先行研究のデータからある程度カバーでき、組成から多面体やその配置を予測できました。以上の理由から、実空間法を選択しました。

## 結合原子価総和（Bond-Valence Sum, BVS）法

BVSは、原子の酸化数（原子価）を周辺原子との結合に割り当てる考え方です。配位数と結合長がわかれば、各結合の結合原子価の総和として、中心原子の価数を簡便に見積もることができます。

**bond valence = exp((R<sub>0</sub> - R)/B)**

ここで、R<sub>0</sub>とBは経験的パラメーター、Rは結合長です。

例えば、Si<sup>4+</sup>がO<sup>2-</sup>と1.61 Åで結合している場合、exp((1.624 - 1.61)/0.37) = 1.04となり、1.04（価数/結合）×4（結合）= +4.16と見積もられます。形式電荷と原子価結合法で求めた価数が近ければ、解析結果（原子間距離）の妥当性の裏付けとなります。

### BV energy landscape（BVEL）

BVS価数が形式電荷と一致する位置をエネルギー 0 eV（最安定）とし、形式電荷からずれるほどエネルギーが増大するとみなします。

BVELは、結晶構造中のエネルギーランドスケープを高速に計算でき、骨格構造さえわかれば、イオンの平衡位置、移動経路、遷移サイト、移動障壁を計算可能です。Rietveld解析の初期モデル中のLi配列決定や、精密化後の見落としサイトの有無の判断などにも便利です。ただし、簡便が故に定量精度は低く（Morse型ポテンシャル型力場）、緩和や分極は考慮されません。あくまで参考値です（特に非酸化物）。

ツールとしては、Stefan Adamsグループの**SoftBV**が使いやすいです。

## 結晶構造を説明

結晶構造は、骨格原子の充填/配列様式と、可動イオンが占める多面体で説明できます。代表的な充填様式には、FCC：Face-centered cubic（面心立方、立方最密充填）、HCP：Hexagonal closed packing（六方最密充填）、BCC：Body-centered cubic（体心立方）があります。

### 蛍石型Ba<sub>0.6</sub>La<sub>0.4</sub>F<sub>2.4</sub>（Fm-3m）

Ba<sup>2+</sup>/La<sup>3+</sup>のFCC骨格中で、四面体中心の8c位置にF<sup>-</sup>が占有率1で、八面体中心の4b位置にF<sup>-</sup>が占有率0.4で占有しています。FtetとFtetは辺（稜）共有、FoctとFtetは面共有で連結しています。

### 逆α-AgI型Ba<sub>0.5</sub>Ca<sub>0.35</sub>Na<sub>0.15</sub>D<sub>1.85</sub>（Im-3m）

Ba<sup>2+</sup>/Ca<sup>2+</sup>/Na<sup>+</sup>のBCC骨格中で、八面体中心の6b位置にD<sup>-</sup>が占有率xxで、四面体中心の12d位置にD<sup>-</sup>が占有率xxで占有しています。BCC骨格中をD<sup>-</sup>が高度にディスオーダー（無秩序分布）した構造です。

## 回折から得られる構造情報：時間・空間平均

回折から得られる情報は、時間（測定時間 msec〜minスケール）・空間（unit cellへのたたみ込み表現）平均情報です。

時間スケールについて考えると、露光時間スケールはps – ns – μs – ms – s – minに及びます。Lab XRDやSXRDでの測定時間とイオンホッピングの時間スケールを比較すると、単位格子あたり0.1 hopping / ps、すなわち10<sup>11</sup> hopping / sとなります。

p = Nexp(-E/kT)にN = 1、T = 298 Kを代入すると、E = 0 eVでp = 1、E = 0.1 eVでp = 2×10<sup>-2</sup>、E = 0.2 eVでp = 4×10<sup>-4</sup>となります。つまり、0.2 eVのエネルギー障壁を超える瞬間を観測する確率は4×10<sup>-4</sup>にすぎません。

回折はDynamics（動力学）そのものを検出しているわけではなく、あくまでstatistic（統計的）な分布を検出しています。分布からdynamics（動力学）とstatics（静力学）な振る舞いを議論するにとどめます。

## 時間・空間平均上のサイトスプリットの解釈

サイトスプリットとは、例えば占有率0.5で二分割することで、熱振動楕円体では表現しきれない、複数の平衡位置の重ね合わせによる空間的な広がりを表現する方法です。Case 1（時間平均）とCase 2（空間平均）の例のように、これはあくまでstatisticsな情報であり、dynamicsとstaticsのメカニズムを識別できません。

## まとめ：イオンの拡散経路の解析手法

### 実験：放射光X線/中性子回折データのRietveld構造解析

Rietveld解析によりキャリアイオンの温度因子（原子変位パラメーター）を解析します。熱振動楕円体として熱振動をモデル化するのが異方性原子変位パラメーターであり、変位の方位からイオンの移動方位がわかります。各隣接サイト間の移動をつなぎ合わせてつながる長距離の拡散パスを見つけ出すことで、拡散経路を推定します。

### 計算：エネルギーランドスケープ計算、反応経路探索、分子動力学計算

**Voxelに対するポテンシャル計算↔NEBによる反応経路探索**

結晶構造中の可動イオンのエネルギーランドスケープは、結晶構造中の各voxel（pixelを3次元に拡張した3次元メッシュ）に位置するイオンiと周辺原子jのポテンシャルの総和を割り当て、各voxelにおけるイオンiのポテンシャルを求めることで得られます。ポテンシャルとしては、静電ポテンシャル+重なり反発を表すMorse potentialや、結合原子価法に基づく理想的な結合長をポテンシャルの極小値としてMorse potentialの形式へと拡張したBond valence energy（BVE）が用いられます。

**Nudged Elastic Band法**は、特定のポテンシャルを用いて、最小エネルギー障壁の移動経路を探索する手法です。NEB法は経路探索アルゴリズムであり、第一原理計算や他のポテンシャルと組み合わせて使われます。周辺原子の座標も最適化可能であり、イオンの移動過程の周辺原子の僅かな原子変位（緩和）の寄与も加味できます。

**分子動力学計算**では、結晶構造中の可動イオンのDynamics（イオンの移動+平衡位置を中心とした熱振動）を観測します。高温でのイオンのdynamicsを観測することで、統計的な情報を求めることができます。具体的には、イオンの平均二乗変位（MSD）を求め、MSD-dtの傾きから自己拡散係数が得られ、イオン伝導率を計算可能です。また、全計算時間におけるvoxelごとにイオンが存在する頻度から確率密度分布が求まり、Boltzman分布に基づき確率密度分布からイオンのポテンシャルが求まります。

## まとめ：放射光X線or中性子回折データを用いたRietveld構造解析とシミュレーションの連動

結晶構造を決定する際は、以下を確認します。

- ☑目的の元素置換通りの占有率が得られるか
- ☑電気的中性が満たされるか
- ☑原子間距離はイオン半径的に妥当か

解析が上手く出来ない場合はモデルの見直しを行います。差フーリエ合成やMEM解析から、見逃している情報（格子間サイトや誤った占有率など）を探しに行きます。

### 高濃度な欠陥の場合 or ラフに傾向を把握する場合

最もラフに計算する場合はBVELを用います。BVELからエネルギーの極小値を示す座標を探して、平衡位置をざっくりと推定することが可能です。また、MD計算から確率密度分布を求め、平衡位置や拡散経路に関する情報を得ることもできます。

構造が決まれば、まずは精密化された構造をもとに拡散経路を議論してみます。イオン伝導率が高い場合、拡散イベントが高頻度で生じ、それらの情報が回折データ中に平均化された形で含まれるため、MEM解析からイオン拡散由来の分布を可視化することが可能です。

### 希釈な欠陥組成の場合

定比組成の構造のsupercell中から可動イオンを1個挿入or除去し（欠陥次第）、その欠陥の移動経路をNEBで計算します。これは反応素過程を解釈することにつながります（メカニズム理解）。

実験と計算の連携という観点では、実験は構造解析の参考情報として利用可能であり、計算では計算の入力構造、またはその初期モデルとして利用します。
