# 固体電解質と二次電池の電気化学測定 (工事中)

## イオン伝導率の定義

イオン伝導率σ（S cm<sup>-1</sup>）は、比抵抗ρ（Ω cm）の逆数として定義され、イオンの流れやすさを表す指標です。定義には広義と狭義があり、本セミナーでは広義のイオン伝導率（Ionic conductivity）を使用します。狭義では超イオン導電率（superionic conductivity）と呼ばれ、超伝導（superconductivity）と区別されます。

イオン伝導率は以下の式で表されます：

**σ = 1/ρ = d/A × 1/R**

ここで：
- σ：イオン伝導率（S cm<sup>-1</sup>）
- ρ：比抵抗（Ω cm）
- A：表面積（cm<sup>2</sup>）
- d：長さ（cm）
- R：抵抗（Ω）

## 抵抗の測定方法

抵抗の測定には、交流インピーダンス（電気化学インピーダンス、EIS）を使用します。

## 幾何サイズの測定

焼結体の場合は、両面を十分に研磨した上で、ノギスやマイクロメータで幾何サイズを計測します。ペレットが歪な場合は、複数回計測の平均値を使用します。一方、圧粉体の場合は、プレス加圧成型を行い、その高さを計測します。

## 直流法による抵抗測定の難しさ

直流電圧（電流）を印加した際の電流（電圧）値から、オームの法則（V = IR）より全抵抗R<sub>dc</sub>を算出する方法には、以下の問題があります：

**R<sub>dc</sub> = R<sub>wire</sub> + R<sub>ei</sub> + R<sub>b</sub> + R<sub>gb</sub>**

| 抵抗成分 | 説明 | 除外方法 |
|---------|------|---------|
| R<sub>wire</sub> | 配線抵抗 | ノンブロッキング電極、4端子電極で除外可能 |
| R<sub>ei</sub> | 電極界面抵抗 | ノンブロッキング電極、4端子電極で除外可能 |
| R<sub>b</sub> | 粒内抵抗（bulk） | 直流測定では分離不可 |
| R<sub>gb</sub> | 粒界抵抗（grain boundary） | 直流測定では分離不可 |

また、適切な試料作製の困難さも課題となります。

## 交流法による抵抗測定

交流電圧（電流）を印加し、応答電流（電圧）からインピーダンスZを計測します。

**Z = Z<sub>wire</sub> + Z<sub>b</sub> + Z<sub>gb</sub> + Z<sub>ei</sub>**

交流電圧の周波数を変えながらインピーダンスを計測することで、以下のように各成分を観測できます：

| 周波数領域 | 時間スケール | 観測される成分 |
|-----------|------------|--------------|
| 高周波数 | 短時間スケール | 配線抵抗、バルク抵抗 |
| 中周波数 | 中時間スケール | ＋粒界抵抗 |
| 低周波数 | 長時間スケール | ＋電極界面抵抗 |

イメージ（正確性は別）として、高周波数では変位のみが、低周波数ではイオン移動が観測されます。

## 電気回路とインピーダンスの基礎

### 回路素子の特性

| 素子 | 変数 | リアクタンス | 関係式 | 位相差 |
|-----|------|------------|--------|--------|
| レジスタ | レジスタンス R（Ω） | - | V = IR | 0° |
| キャパシタ | キャパシタンス C（F） | 容量性リアクタンス X<sub>C</sub> | V = (1/C)∫Idt | -90° |
| インダクタ | インダクタンス L（H） | 誘導性リアクタンス X<sub>L</sub> | V = L(dI/dt) | +90° |

## レジスタ(R)の特性

**Z<sub>R</sub> = R**

例えばR = 50 Ωのように、単体では測定レンジ外の高周波数側の配線抵抗やバルク抵抗成分として用いることが多いです。

## キャパシタ(C)の特性

**Z<sub>c</sub> = 1/(jωC) = -j(1/ωC)**

極限値を考えると、高周波数側では lim<sub>ω→∞</sub>(-j(1/ωC)) = 0、低周波数側では lim<sub>ω→0</sub>(-j(1/ωC)) = -j∞ となります。キャパシタは、ブロッキング電極（キャリアと反応しない電極）を表します。

## R//C並列回路

R//C並列回路のインピーダンスは：

**Z = R/(1 + (ωRC)<sup>2</sup>) - j(ωR<sup>2</sup>C/(1 + (ωRC)<sup>2</sup>))**

と、実数部と虚数部に分けて表現されます。極限値は、lim<sub>ω→∞</sub>(Z) = 0 - j0 = 0、lim<sub>ω→0</sub>(Z) = R - j0 = R となり、lim<sub>ω→1/τ</sub>(Z) = R/2 - j(R/2) が半円弧の頂点に対応します。

**RC並列回路の時定数：τ = RC**

**頂点周波数：f = ω/2π = 1/(2πRC)**
**Z' = -Z'' = R/2**

例えばR = 100 Ω、C = 1×10<sup>-9</sup> Fの場合、f ≈ 3 MHz、τ = 50 nsとなります。これは「抵抗を通る電流」と「コンデンサを通る電流」が同程度になる時間スケールを表し、半円弧の頂点に対応します。

## CPE（Constant Phase Element）

**Z<sub>CPE</sub> = 1/(Q<sub>0</sub>(jω)<sup>α</sup>)**

ここで0 ≤ α ≤ 1

| α値 | 極限値 | 等価素子 |
|-----|--------|---------|
| α→0 | Z<sub>CPE</sub> = 1/Q<sub>0</sub> = R | レジスタ |
| α→1 | Z<sub>CPE</sub> = 1/(Q<sub>0</sub>jω) = 1/(jωC) | キャパシタ |
| α = 0.5 | Z<sub>CPE</sub> = 1/(Q<sub>0</sub>√(jω)) | - |

低周波数側の様々な成分をR//CPEで片付けることも多いです。ブロッキング電極ではあるものの、僅かに反応する場合などに使用されます。

## R//CPE並列回路

**Z = R/(1 + RQ<sub>0</sub>(jω)<sup>α</sup>)**

ここで0 ≤ α ≤ 1

極限値は、lim<sub>ω→∞</sub>(Z) = 0、lim<sub>ω→0</sub>(Z) = R となります。様々な理由で、R//CではなくR//CPEで解析されることもあります。

---

## バルク伝導を表すR//C並列回路

例：R = 200 Ω、C = 1×10<sup>-11</sup> Fの場合

| パラメータ | 値 |
|-----------|-----|
| 頂点周波数 f | ≈ 80 MHz |
| Z' = -Z'' | R/2 = 100 Ω |
| 時定数 τ | 2 ns |

**頂点周波数：f = ω/2π = 1/(2πRC)**

高周波数では変位のみ（イオンの微小変位による分極電流）が、低周波数ではイオン移動（イオンの移動による電流）が観測されます。その境界となる周波数がf = 1/(2πRC)であり、これが時定数（緩和時間）τ = RCとなります。

## 材料の誘電率とキャパシタンス

バルク成分のキャパシタンスは、次のように考えます：

**C = ε'ε<sub>0</sub>(A/d)**

ここで：
- C：capacitance（F）
- ε'：permittivity（比誘電率）
- ε<sub>0</sub>：permittivity of free space（真空の誘電率）= 8.854×10<sup>-14</sup> F cm<sup>-1</sup>
- A：area（cm<sup>2</sup>）
- d：length（cm）

### 各材料のキャパシタンス（A：1 cm<sup>2</sup>、d：0.1 cm）

| 分類 | 組成 | 比誘電率 | キャパシタンス / F |
|------|------|---------|-------------------|
| **Oxide** | SiO<sub>2</sub> | 4-5 | 3.5×10<sup>-12</sup> |
| | Al<sub>2</sub>O<sub>3</sub> | 9 | 8.0×10<sup>-12</sup> |
| **Ferroelectric** | BaTiO<sub>3</sub> | 100-2500 | 8.9×10<sup>-10</sup> |
| | PbTiO<sub>3</sub> | 200 | 1.8×10<sup>-10</sup> |
| **Ionic conductor** | YSZ | 26 | 2.3×10<sup>-11</sup> |
| | Li<sub>7</sub>La<sub>3</sub>Zr<sub>2</sub>O<sub>12</sub> | 40-60 | 3.5×10<sup>-11</sup> |
| | Li<sub>1.3</sub>Al<sub>0.3</sub>Ti<sub>1.7</sub>(PO<sub>4</sub>)<sub>3</sub> | 32-77 | 2.8×10<sup>-11</sup> |

バルク伝導を表すR//C並列回路のキャパシタンスは材料の誘電率により異なりますが、イオン伝導体の場合、約10<sup>-11</sup> F前後となります。

## 粒界成分を表すR//C並列回路のキャパシタンス

Brick layer（wall）modelに基づくと：

- **C<sub>b</sub> = ε'ε<sub>0</sub>(A/d<sub>b</sub>)**
- **C<sub>gb</sub> = ε'ε<sub>0</sub>(A/d<sub>gb</sub>)**
- **C<sub>gb</sub> = C<sub>b</sub>(d<sub>b</sub>/d<sub>gb</sub>)**

ここで：
- d<sub>b</sub>：バルク（粒内）の厚さ
- d<sub>gb</sub>：粒界の厚さ
- d<sub>e</sub>：電極の厚さ

つまり、粒界のキャパシタンスは、粒子バルクと粒界の空間スケールの比×バルクのキャパシタンスとなります。焼結試料では結晶粒が成長して結晶粒サイズが大きいため、粒界キャパシタンスは高く（～10<sup>-9</sup> F）なり、メカノケミカル合成試料では結晶粒サイズが小さいため、粒界キャパシタンスは小さく（10<sup>-10</sup> F）なります。

## 不均一接触に由来する粒界抵抗（Fleig and Maier）

有限要素法（Finite element method, FEM）によるポテンシャル分布計算の結果は以下の通りです：

| 周波数領域 | 電流分布 | 現象 |
|-----------|---------|------|
| 直流～低周波数 | 粒界近傍で電流集中 | current constriction |
| 高周波数（ω ≥ 1/RC） | 均一な電流密度分布 | 容量的に導通 |

**σ（S cm<sup>-1</sup>）/ ε（F cm<sup>-1</sup>）= 1/RC（Ω<sup>-1</sup> F<sup>-1</sup>）= ω（s<sup>-1</sup>）**

緩和周波数ω（=1/RC= τ<sup>-1</sup>）以上の高周波数では容量的に導通し、均一な電流密度分布となります。

Fleig and Maierは、見かけの粒界抵抗が粒子同士の部分接触によるバルク内界面近傍の電流集中による（≈ バルク伝導率と相関）と説明しました。これは、粒界伝導率とバルク伝導率の活性化エネルギーが等しいことを説明するモデルです。

## 交流電圧の周波数を変えながらインピーダンスを計測（再掲）

高周波数（短時間スケール）では、配線抵抗とバルク抵抗が観測されます。例えば100 MHz、10 MHz、1 MHzといった周波数域で、300 Ω、1×10<sup>-11</sup> F（バルク）といった成分に対応します。

中周波数（中時間スケール）では、これに粒界抵抗が加わります。例えば100 kHz、10 kHz、1 kHzといった周波数域で、1,000 Ω、1×10<sup>-8</sup> F（粒界）といった成分に対応します。

低周波数（長時間スケール）では、さらに電極界面抵抗が加わります。ノンブロッキング電極ではR<sub>ei</sub> = 200 Ω程度、ブロッキング電極ではR<sub>ei</sub> → ∞となり、キャパシタンスは1×10<sup>-4</sup> F程度です。

## イオン伝導率の解析：アレニウスプロット

イオン伝導率の温度依存性から活性化エネルギーを求めます。各温度におけるイオン伝導率を測定し、log(σT) vs 1000/Tでプロットします。

**Arrhenius equation：**
**σ = (σ<sub>0</sub>/T)exp(-E<sub>a</sub>/kT)**

変形すると：**log(σT) = log(σ<sub>0</sub>) - 2.303×E<sub>a</sub>/kT**

log(σT) vs 1000/Tの傾きから活性化エネルギーE<sub>a</sub>が求まり、slope = -2.303×E<sub>a</sub>/1000kの関係となります。例えば0.21 eVといった値が得られます（単位換算：1 eV = 96.485 kJ mol<sup>-1</sup>）。

固体ではy軸にlogσTを取る方が厳密ですが、狭い温度範囲では大差が無いので、簡便にlogσを用いても構いません。前指数項σ<sub>0</sub>が温度の逆数の影響を受けるかどうかの違いがあります。バルク・粒界成分が分離できたら、各成分ごとにもプロットします。

## Nernst Einstein式を用いて伝導度拡散係数を求める

**σ = (Z<sub>c</sub><sup>2</sup>e<sup>2</sup>C/k<sub>B</sub>T)D<sub>σ</sub>**

ここで：
- C = N<sub>c</sub>/V（格子体積中のキャリア数/格子体積）
- Z<sub>c</sub>：電荷
- e：電気素量
- N<sub>c</sub>/V：格子体積中のキャリア数/格子体積
- k<sub>B</sub>：ボルツマン定数
- T：絶対温度

PFG-NMRや分子動力学計算で得られるトレーサー拡散係数D<sub>tr</sub>との比である**ハーベン比：HR = D<sub>tr</sub>/D<sub>σ</sub>**も重要な指標となります。

## サンプルの作製

粒界成分を低減するために、相対密度を高めた緻密体を作製する必要があります。

**相対密度（%）= (ρ<sub>real</sub>/ρ<sub>theoretical</sub>) × 100**

ここで：
- ρ<sub>real</sub>：実測密度（g cm<sup>-3</sup>）
- ρ<sub>theoretical</sub>：真密度（g cm<sup>-3</sup>）

**ρ<sub>theoretical</sub>（g cm<sup>-3</sup>）= MW(g mol<sup>-1</sup>)×Multiplicity(-)/(N<sub>A</sub>(mol<sup>-1</sup>)×V(cm<sup>3</sup>))**

真密度は、組成・構造が既知の場合は構造(cif)データから計算し、新規組成の場合はXRDから格子定数を計算して求めます（CellCalc、簡易Rietveld、Le Bailのパターンフィッティング等）。

高温焼成やプレス等を経て、相対密度90%以上を目指します。新たな材料系を扱う場合、かつコールドプレス（室温プレス）で評価する場合は、加重-変位(相対密度)特性を押さえておくと良いでしょう。

## 電解質の電位窓測定

一定の速度（数mV sec<sup>-1</sup>等）で電圧を掃引しながら、電解質の酸化/還元分解に由来した応答電流を観測します。

### Cyclic Voltammetry（CV）から電位窓を測定

CVでは、以下の反応を観測します：

- Li溶解：Li → Li<sup>+</sup> + e<sup>-</sup>
- Li析出：Li<sup>+</sup> + e<sup>-</sup> → Li
- 電解質の酸化と還元

ピークの立ち上がりや、酸化還元電流の閾値を指標に電位窓を決定します。

### Linear Sweep Voltammetry（LSV）から電位窓を測定

酸化側と還元側の電位窓を個別に求めることもあります。その場合は一方向の電位掃引となるので、Liner Sweep Voltammetry（LSV）から電位窓を測定します。

## 定電流（CC; Constant Current）充放電測定

電極の性能（容量、反応電位）を調べることを目的とした測定です。ガルバノスタット（電流(Galvano)を一定に保つ(stat)）を用いて電流を流し、設定した上/下限電圧に到達するまでの時間・電圧を測定します。

**充電容量 q = ∫<sub>0</sub><sup>t<sub>1</sub></sup>|I(t)|dt（mA h）**
**放電容量 q = ∫<sub>t<sub>1</sub></sub><sup>t<sub>2</sub></sup>|I(t)|dt（mA h）**

プロセス：
1. 定電流印加
2. E ≥ E<sub>upper</sub>
3. 定電流印加
4. E ≤ E<sub>lower</sub>

容量をx軸にとり"充放電曲線"を作成します。不可逆容量も観測されます。

## 定電流定電圧（CCCV; Constant-Current Constat-Voltage）充放電測定

ガルバノスタットを用いて電流を流し、設定した上/下限電圧に到達した後に、ポテンショスタットを用いて電圧を保持して、一定電流値（I<sub>lim</sub>）以下（or 一定時間経過）になるまで時間・電流を測定します。

プロセス：
1. 定電流(CC)充電
2. E ≥ E<sub>upper</sub>
3. 定電圧(CV)充電
4. I ≤ I<sub>lim</sub>
5. 放電電流印加
6. E ≤ E<sub>lower</sub>

CVでの適切な電位制御で、高電位での分解反応を抑制可能です。

## 充放電曲線の形状からわかること：単相反応と二相共存反応

LiFePO<sub>4</sub>を例に、Phase AからPhase Bへの反応経路のエネルギーを考えます。ΔG = G<sub>B</sub> - G<sub>A</sub> = const.の場合は二相共存反応（E = const.）に対応し、ΔG = (∂G<sub>A</sub>/∂n)、ΔG = (∂G<sub>B</sub>/∂n)の場合は単相反応（Eは連続的に変化）に対応します。最安定な反応経路が赤破線の経路となります。

ポイントとして、分極が無視できる程度の小さい電流値で(充)放電する、もしくは充放電過程の緩和後のOCV（GITT等）から、平衡状態の熱力学的な反応電位を調べることができます。

## 定電流間欠滴定法（GITT）

パルス電流ステップと緩和測定を繰り返し、平衡状態から非平衡状態への緩和過程を観測することで、平衡電位や電極内のリチウムイオン拡散を調べる手法です。短時間の定電流パルスと長時間の休止期間を組み合わせます。

電流印加直後の短い時間（t ≪ L<sup>2</sup>/D<sub>s</sub>）の電位変化は：

**E = E<sub>0</sub> - IR - (2bIV<sub>m</sub>/√(πFS))√(τ/D<sub>s</sub>)**

ここで：
- E<sub>0</sub>：平衡電位
- R：抵抗
- V<sub>m</sub>：モル体積
- b：dE/dxの傾き
- S：反応面積
- F：ファラデー定数
- L：膜厚
- D<sub>s</sub>：化学拡散係数

試料形態が集電体上の厚さLの膜のとき、充(放)電過程の平衡状態の電位や、電極内のリチウムの化学拡散係数を調べることが可能です。これにより、熱力学的反応電位の理解や、二相反応か単相（固溶）反応かの判別ができます。

## 充放電曲線からわかること：dQ/dV、dV/dQ曲線

充放電曲線（Q-V曲線）からの変換による解析手法です。

---

### dQ/dV曲線（微分容量曲線）

容量Qを電圧Vで微分したもので、電圧変化に対する容量変化率を表します。ピーク位置は反応電位に、ピーク面積は反応容量に対応します。容量劣化の要因プラトーの推定に有効であり、充放電過程の反応機構の分離・識別ができます。また、サイクル間の差分解析で劣化機構の特定が可能です。

### dV/dQ曲線（微分電圧曲線）

電圧Vを容量Qで微分したもので、容量変化に対する電圧変化率を表します。電圧変化領域の特定や、電池の内部抵抗変化の検出に有効です。サイクル間の差分解析で劣化機構の特定が可能です。
