# 固体電解質と二次電池の電気化学測定 (工事中)

## イオン伝導率の定義

イオン伝導率σ（S cm<sup>-1</sup>）は比抵抗ρ（Ω cm）の逆数として定義され、イオンの流れやすさを表す指標です。この用語には広義と狭義があり、ここでは広義のイオン伝導率（ionic conductivity）を用います。狭義では超イオン導電率（superionic conductivity）と呼ばれ、超伝導（superconductivity）と区別されます。

イオン伝導率は、次式で表されます。

**σ = 1/ρ = d/A × 1/R**

ここで、各記号の意味は次の通りです。

- σ：イオン伝導率（S cm<sup>-1</sup>）
- ρ：比抵抗（Ω cm）
- A：表面積（cm<sup>2</sup>）
- d：長さ（cm）
- R：抵抗（Ω）

## 抵抗の測定方法

抵抗の測定には、交流インピーダンス法（電気化学インピーダンス分光法、EIS）を用います。

## 幾何サイズの測定

焼結体の場合は、両面を十分に研磨したうえで、ノギスやマイクロメータで幾何サイズを計測します。ペレットの形状がいびつな場合は、複数回計測した平均値を用います。一方、圧粉体の場合は、プレスで加圧成形したうえで、その高さ（厚さ）を計測します。

## 直流法による抵抗測定の難しさ

直流電圧（電流）を印加したときの電流（電圧）値から、オームの法則（V = IR）を用いて全抵抗R<sub>dc</sub>を算出することもできます。しかし、この方法で得られる抵抗は、次式のように複数の成分の和になっています。

**R<sub>dc</sub> = R<sub>wire</sub> + R<sub>ei</sub> + R<sub>b</sub> + R<sub>gb</sub>**

| 抵抗成分 | 説明 | 除外方法 |
|---------|------|---------|
| R<sub>wire</sub> | 配線抵抗 | ノンブロッキング電極、4端子電極で除外可能 |
| R<sub>ei</sub> | 電極界面抵抗 | ノンブロッキング電極、4端子電極で除外可能 |
| R<sub>b</sub> | 粒内抵抗（bulk） | 直流測定では分離不可 |
| R<sub>gb</sub> | 粒界抵抗（grain boundary） | 直流測定では分離不可 |

配線抵抗と電極界面抵抗は電極構成の工夫で除外できますが、粒内抵抗と粒界抵抗は直流測定では分離できません。また、測定に適した試料を作製すること自体が難しいことも課題となります。

## 交流法による抵抗測定

交流法では、交流電圧（電流）を印加し、その応答電流（電圧）からインピーダンスZを計測します。

**Z = Z<sub>wire</sub> + Z<sub>b</sub> + Z<sub>gb</sub> + Z<sub>ei</sub>**

交流電圧の周波数を変えながらインピーダンスを計測することで、次のように各成分を分離して観測できます。

| 周波数領域 | 時間スケール | 観測される成分 |
|-----------|------------|--------------|
| 高周波数 | 短時間スケール | 配線抵抗、バルク抵抗 |
| 中周波数 | 中時間スケール | ＋粒界抵抗 |
| 低周波数 | 長時間スケール | ＋電極界面抵抗 |

厳密さは別として直感的なイメージを述べると、高周波数ではイオンの変位のみが、低周波数ではイオンの移動が観測されます。

## 電気回路とインピーダンスの基礎

### 回路素子の特性

| 素子 | 変数 | リアクタンス | 関係式 | 位相差 |
|-----|------|------------|--------|--------|
| レジスタ | レジスタンス R（Ω） | - | V = IR | 0° |
| キャパシタ | キャパシタンス C（F） | 容量性リアクタンス X<sub>C</sub> | V = (1/C)∫Idt | -90° |
| インダクタ | インダクタンス L（H） | 誘導性リアクタンス X<sub>L</sub> | V = L(dI/dt) | +90° |

## レジスタ（R）の特性

**Z<sub>R</sub> = R**

レジスタ単体は、例えばR = 50 Ωのように、測定レンジより高周波数側に現れる配線抵抗やバルク抵抗の成分を表すのによく用いられます。

## キャパシタ（C）の特性

**Z<sub>C</sub> = 1/(jωC) = -j(1/ωC)**

極限値を考えると、高周波数側では lim<sub>ω→∞</sub>(-j(1/ωC)) = 0、低周波数側では lim<sub>ω→0</sub>(-j(1/ωC)) = -j∞ となります。キャパシタは、ブロッキング電極（キャリアと反応しない電極）を表すのに用いられます。

## R//C並列回路

R//C並列回路のインピーダンスは、実数部と虚数部に分けて次のように表されます。

**Z = R/(1 + (ωRC)<sup>2</sup>) - j(ωR<sup>2</sup>C/(1 + (ωRC)<sup>2</sup>))**

極限値は lim<sub>ω→∞</sub>(Z) = 0 - j0 = 0、lim<sub>ω→0</sub>(Z) = R - j0 = R となり、lim<sub>ω→1/τ</sub>(Z) = R/2 - j(R/2) が半円弧の頂点に対応します。

R//C並列回路の時定数は **τ = RC** であり、頂点周波数は **f = ω/2π = 1/(2πRC)** です。半円弧の頂点では **Z' = -Z'' = R/2** となります。

例えばR = 100 Ω、C = 1×10<sup>-9</sup> Fの場合、f ≈ 3 MHz、τ = 50 nsとなります。この時間スケールは「抵抗を通る電流」と「キャパシタを通る電流」が同程度になる時間スケールを表し、半円弧の頂点に対応します。

## CPE（Constant Phase Element）

**Z<sub>CPE</sub> = 1/(Q<sub>0</sub>(jω)<sup>α</sup>)**

ここで、αは0 ≤ α ≤ 1の値をとります。

| α値 | 極限値 | 等価素子 |
|-----|--------|---------|
| α→0 | Z<sub>CPE</sub> = 1/Q<sub>0</sub> = R | レジスタ |
| α→1 | Z<sub>CPE</sub> = 1/(Q<sub>0</sub>jω) = 1/(jωC) | キャパシタ |
| α = 0.5 | Z<sub>CPE</sub> = 1/(Q<sub>0</sub>√(jω)) | - |

低周波数側に現れるさまざまな成分を、まとめてR//CPEで表現することもよくあります。例えば、ブロッキング電極ではあるものの、キャリアと僅かに反応する場合などに用いられます。

## R//CPE並列回路

**Z = R/(1 + RQ<sub>0</sub>(jω)<sup>α</sup>)**

ここで、αは0 ≤ α ≤ 1の値をとります。

極限値は lim<sub>ω→∞</sub>(Z) = 0、lim<sub>ω→0</sub>(Z) = R となります。さまざまな理由から、R//CではなくR//CPEで解析されることもあります。

## バルク伝導を表すR//C並列回路

例えば、R = 200 Ω、C = 1×10<sup>-11</sup> Fの場合は次のようになります。

| パラメータ | 値 |
|-----------|-----|
| 頂点周波数 f | ≈ 80 MHz |
| Z' = -Z'' | R/2 = 100 Ω |
| 時定数 τ | 2 ns |

**頂点周波数：f = ω/2π = 1/(2πRC)**

高周波数ではイオンの変位のみ（イオンの微小変位による分極電流）が、低周波数ではイオンの移動（イオンの移動による電流）が観測されます。その境界となる周波数がf = 1/(2πRC)であり、これに対応する時間が時定数（緩和時間）τ = RCです。

## 材料の誘電率とキャパシタンス

バルク成分のキャパシタンスは、材料の誘電率から次式で見積もることができます。

**C = ε'ε<sub>0</sub>(A/d)**

ここで、各記号の意味は次の通りです。

- C：キャパシタンス（F）
- ε'：比誘電率（permittivity）
- ε<sub>0</sub>：真空の誘電率（permittivity of free space）= 8.854×10<sup>-14</sup> F cm<sup>-1</sup>
- A：面積（cm<sup>2</sup>）
- d：長さ（cm）

### 各材料のキャパシタンス（A：1 cm<sup>2</sup>、d：0.1 cm）

| 分類 | 組成 | 比誘電率 | キャパシタンス / F |
|------|------|---------|-------------------|
| **Oxide** | SiO<sub>2</sub> | 4-5 | 3.5×10<sup>-12</sup> |
| | Al<sub>2</sub>O<sub>3</sub> | 9 | 8.0×10<sup>-12</sup> |
| **Ferroelectric** | BaTiO<sub>3</sub> | 100-2500 | 8.9×10<sup>-10</sup> |
| | PbTiO<sub>3</sub> | 200 | 1.8×10<sup>-10</sup> |
| **Ionic conductor** | YSZ | 26 | 2.3×10<sup>-11</sup> |
| | Li<sub>7</sub>La<sub>3</sub>Zr<sub>2</sub>O<sub>12</sub> | 40-60 | 3.5×10<sup>-11</sup> |
| | Li<sub>1.3</sub>Al<sub>0.3</sub>Ti<sub>1.7</sub>(PO<sub>4</sub>)<sub>3</sub> | 32-77 | 2.8×10<sup>-11</sup> |

バルク伝導を表すR//C並列回路のキャパシタンスは材料の誘電率によって異なりますが、イオン伝導体の場合は10<sup>-11</sup> F前後となります。

## 粒界成分を表すR//C並列回路のキャパシタンス

Brick layer（wall）モデルに基づくと、バルクと粒界のキャパシタンスは次のように表されます。

- **C<sub>b</sub> = ε'ε<sub>0</sub>(A/d<sub>b</sub>)**
- **C<sub>gb</sub> = ε'ε<sub>0</sub>(A/d<sub>gb</sub>)**
- **C<sub>gb</sub> = C<sub>b</sub>(d<sub>b</sub>/d<sub>gb</sub>)**

ここで、各記号の意味は次の通りです。

- d<sub>b</sub>：バルク（粒内）の厚さ
- d<sub>gb</sub>：粒界の厚さ
- d<sub>e</sub>：電極の厚さ

つまり、粒界のキャパシタンスは、バルクのキャパシタンスに粒子バルクと粒界の空間スケールの比を掛けたものになります。焼結試料では結晶粒が成長して結晶粒サイズが大きいため、粒界キャパシタンスは大きく（～10<sup>-9</sup> F）なります。一方、メカノケミカル合成試料では結晶粒サイズが小さいため、粒界キャパシタンスは小さく（～10<sup>-10</sup> F）なります。

## 不均一接触に由来する粒界抵抗（Fleig and Maier）

有限要素法（finite element method, FEM）によるポテンシャル分布計算から、次のような結果が得られています。

| 周波数領域 | 電流分布 | 現象 |
|-----------|---------|------|
| 直流～低周波数 | 粒界近傍で電流集中 | current constriction |
| 高周波数（ω ≥ 1/RC） | 均一な電流密度分布 | 容量的に導通 |

**σ（S cm<sup>-1</sup>）/ ε（F cm<sup>-1</sup>）= 1/RC（Ω<sup>-1</sup> F<sup>-1</sup>）= ω（s<sup>-1</sup>）**

緩和周波数ω（= 1/RC = τ<sup>-1</sup>）以上の高周波数では容量的に導通し、電流密度分布が均一になります。

Fleig and Maierは、見かけの粒界抵抗は、粒子同士が部分的にしか接触していないために、バルク内の界面近傍で電流が集中することに起因する（そのためバルク伝導率と相関する）と説明しました。このモデルは、粒界伝導率とバルク伝導率の活性化エネルギーが等しくなることを説明できます。

## 交流電圧の周波数を変えながらインピーダンスを計測（再掲）

高周波数（短時間スケール）では、配線抵抗とバルク抵抗が観測されます。例えば100 MHz、10 MHz、1 MHzといった周波数域では、300 Ω、1×10<sup>-11</sup> F程度のバルク成分が観測されます。

中周波数（中時間スケール）では、これに粒界抵抗が加わります。例えば100 kHz、10 kHz、1 kHzといった周波数域では、1,000 Ω、1×10<sup>-8</sup> F程度の粒界成分が観測されます。

低周波数（長時間スケール）では、さらに電極界面抵抗が加わります。電極界面抵抗R<sub>ei</sub>は、ノンブロッキング電極では200 Ω程度、ブロッキング電極ではR<sub>ei</sub> → ∞となり、キャパシタンスは1×10<sup>-4</sup> F程度です。

## イオン伝導率の解析：アレニウスプロット

イオン伝導率の温度依存性から、活性化エネルギーを求めることができます。各温度でイオン伝導率を測定し、log(σT)を1000/Tに対してプロットします。

**Arrhenius equation：**
**σ = (σ<sub>0</sub>/T)exp(-E<sub>a</sub>/kT)**

これを変形すると、次式が得られます。

**log(σT) = log(σ<sub>0</sub>) - 2.303×E<sub>a</sub>/kT**

log(σT)–1000/Tプロットの傾きから活性化エネルギーE<sub>a</sub>が求まり、傾きとの間には slope = -2.303×E<sub>a</sub>/1000k の関係があります。例えば、0.21 eVといった値が得られます（単位換算：1 eV = 96.485 kJ mol<sup>-1</sup>）。

固体では縦軸にlog σTをとる方が厳密ですが、狭い温度範囲では大差がないため、簡便にlog σを用いても構いません。両者の違いは、前指数項σ<sub>0</sub>に温度の逆数の影響を含めるかどうかにあります。バルク成分と粒界成分が分離できた場合は、成分ごとにもプロットします。

## Nernst-Einstein式による伝導度拡散係数の算出

イオン伝導率σから、次のNernst-Einstein式を用いて伝導度拡散係数D<sub>σ</sub>を求めることができます。

**σ = (Z<sub>c</sub><sup>2</sup>e<sup>2</sup>C/k<sub>B</sub>T)D<sub>σ</sub>**

ここで、各記号の意味は次の通りです。

- C = N<sub>c</sub>/V：キャリア濃度（格子体積V中のキャリア数N<sub>c</sub>を格子体積で割ったもの）
- Z<sub>c</sub>：電荷
- e：電気素量
- k<sub>B</sub>：ボルツマン定数
- T：絶対温度

PFG-NMRや分子動力学計算で得られるトレーサー拡散係数D<sub>tr</sub>との比である**ハーベン比：HR = D<sub>tr</sub>/D<sub>σ</sub>**も重要な指標となります。

## サンプルの作製

粒界成分を低減するためには、相対密度の高い緻密体を作製する必要があります。

**相対密度（%）= (ρ<sub>real</sub>/ρ<sub>theoretical</sub>) × 100**

ここで、各記号の意味は次の通りです。

- ρ<sub>real</sub>：実測密度（g cm<sup>-3</sup>）
- ρ<sub>theoretical</sub>：真密度（g cm<sup>-3</sup>）

真密度は次式で計算します。

**ρ<sub>theoretical</sub>（g cm<sup>-3</sup>）= MW(g mol<sup>-1</sup>)×Multiplicity(-)/(N<sub>A</sub>(mol<sup>-1</sup>)×V(cm<sup>3</sup>))**

組成と構造が既知の場合は構造データ（cif）から真密度を計算し、新規組成の場合はXRDから格子定数を求めて計算します（CellCalc、簡易Rietveld解析、Le Bail法によるパターンフィッティングなど）。

高温焼成やプレスなどによって、相対密度90%以上を目指します。新しい材料系をコールドプレス（室温プレス）で評価する場合は、荷重と変位（相対密度）の関係を把握しておくとよいでしょう。

## 粉末の一軸成形

一軸成形で試料にかかる実効圧力は、次式で求められます。

**実効圧力 = (シリンダの受圧面積/試料断面積) × 表示圧**

理研精器製シリンダの受圧面積は次の通りです。

- MS1-*：14.52 cm<sup>2</sup>
- MS05-*：7.16 cm<sup>2</sup>

### 各種成形・処理方法

| 方法 | 温度範囲 | 特徴 |
|------|---------|------|
| 打ち抜きペレット試料 | r.t.～600℃ | 打ち抜き後に弾性変形でやや膨張し、粒子間の接触が悪化する。ラフなスクリーニング向け |
| 拘束ペレット試料（全固体セル） | -100～200℃ | 温度範囲は拘束治具とセルの耐熱温度で決まる。一定トルクで拘束圧をかけるため、弾性変形が少ない |
| ホットプレス | 100～600℃ | 可塑性の高い試料で特に有効 |
| 高温焼成 | 600～1200℃ | 焼結により粒界が低減し、粒子同士の接触が改善する |
| 通電焼結（SPS） | 400～1000℃ | 焼結により粒界が低減する。低温化・短時間焼成が可能 |

## 電解質の電位窓測定

電解質の電位窓は、一定の速度（数 mV s<sup>-1</sup>程度）で電圧を掃引しながら、電解質の酸化・還元分解に由来する応答電流を観測することで測定します。

### Cyclic Voltammetry（CV）による電位窓の測定

CVでは、次のような反応に由来する電流を観測します。

- Liの溶解：Li → Li<sup>+</sup> + e<sup>-</sup>
- Liの析出：Li<sup>+</sup> + e<sup>-</sup> → Li
- 電解質の酸化分解と還元分解

電流ピークの立ち上がりや、酸化・還元電流の閾値を指標として電位窓を決定します。

### Linear Sweep Voltammetry（LSV）による電位窓の測定

酸化側と還元側の電位窓を個別に求めることもあります。その場合は一方向のみの電位掃引となるため、Linear Sweep Voltammetry（LSV）で電位窓を測定します。

## 定電流（CC; Constant Current）充放電測定

定電流充放電測定は、電極の性能（容量、反応電位）を調べるための測定です。ガルバノスタット（電流（galvano）を一定に保つ（stat）装置）を用いて電流を流し、設定した上限・下限電圧に到達するまでの時間と電圧を測定します。

**充電容量 q = ∫<sub>0</sub><sup>t<sub>1</sub></sup>|I(t)|dt（mA h）**

**放電容量 q = ∫<sub>t<sub>1</sub></sub><sup>t<sub>2</sub></sup>|I(t)|dt（mA h）**

測定の手順は次の通りです。

1. 定電流を印加して充電する
2. 電位Eが上限電圧E<sub>upper</sub>に達したら（E ≥ E<sub>upper</sub>）充電を終了する
3. 定電流を印加して放電する
4. 電位Eが下限電圧E<sub>lower</sub>に達したら（E ≤ E<sub>lower</sub>）放電を終了する

容量を横軸にとって充放電曲線を作成します。充放電曲線からは、不可逆容量も観測されます。

## 定電流定電圧（CCCV; Constant-Current Constant-Voltage）充放電測定

CCCV測定では、ガルバノスタットで電流を流して設定した上限（下限）電圧に到達した後、ポテンショスタットで電圧を保持し、電流が一定値（I<sub>lim</sub>）以下になるまで（または一定時間が経過するまで）の時間と電流を測定します。

測定の手順は次の通りです。

1. 定電流（CC）で充電する
2. 電位Eが上限電圧E<sub>upper</sub>に達したら（E ≥ E<sub>upper</sub>）、定電圧（CV）充電に切り替える
3. 電流が設定値以下になったら（I ≤ I<sub>lim</sub>）充電を終了する
4. 放電電流を印加して放電する
5. 電位Eが下限電圧E<sub>lower</sub>に達したら（E ≤ E<sub>lower</sub>）放電を終了する

定電圧（CV）段階で電位を適切に制御することで、高電位での分解反応を抑制できます。

## 充放電曲線の形状からわかること：単相反応と二相共存反応

LiFePO<sub>4</sub>を例に、Phase AからPhase Bへの反応経路のエネルギーを考えます。ΔG = G<sub>B</sub> - G<sub>A</sub> = const.の場合は二相共存反応（E = const.）に、ΔG = (∂G<sub>A</sub>/∂n)、ΔG = (∂G<sub>B</sub>/∂n)の場合は単相反応（Eが連続的に変化）に対応します。最も安定な反応経路は、赤破線で示した経路となります。

なお、分極が無視できるほど小さい電流値で充放電するか、充放電過程を緩和させた後のOCV（GITTなど）を測定することで、平衡状態における熱力学的な反応電位を調べることができます。

## 定電流間欠滴定法（GITT）

GITTは、パルス電流の印加と緩和測定を繰り返し、平衡状態から非平衡状態への緩和過程を観測することで、平衡電位や電極内のリチウムイオン拡散を調べる手法です。短時間の定電流パルスと長時間の休止期間を組み合わせて測定します。

電流印加直後の短い時間（t ≪ L<sup>2</sup>/D<sub>s</sub>）における電位変化は、次式で表されます。

**E = E<sub>0</sub> - IR - (2bIV<sub>m</sub>/√(πFS))√(τ/D<sub>s</sub>)**

ここで、各記号の意味は次の通りです。

- E<sub>0</sub>：平衡電位
- R：抵抗
- V<sub>m</sub>：モル体積
- b：dE/dxの傾き
- S：反応面積
- F：ファラデー定数
- L：膜厚
- D<sub>s</sub>：化学拡散係数

試料が集電体上に形成された厚さLの膜である場合、充（放）電過程における平衡状態の電位や、電極内のリチウムの化学拡散係数を調べることができます。これにより、熱力学的な反応電位を理解したり、二相反応か単相（固溶）反応かを判別したりできます。

## 充放電曲線からわかること：dQ/dV、dV/dQ曲線

充放電曲線（Q-V曲線）を微分変換することで、反応をより詳しく解析できます。

---

### dQ/dV曲線（微分容量曲線）

dQ/dV曲線は容量Qを電圧Vで微分したもので、電圧変化に対する容量の変化率を表します。ピーク位置は反応電位に、ピーク面積は反応容量に対応します。容量劣化の要因となっているプラトーの推定に有効であり、充放電過程の反応機構を分離・識別できます。また、サイクル間の差分を解析することで、劣化機構を特定できます。

### dV/dQ曲線（微分電圧曲線）

dV/dQ曲線は電圧Vを容量Qで微分したもので、容量変化に対する電圧の変化率を表します。電圧が変化する領域の特定や、電池の内部抵抗変化の検出に有効です。こちらも、サイクル間の差分を解析することで劣化機構を特定できます。
